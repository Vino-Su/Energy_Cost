# 酷哇 APP - 车辆能耗成本管理

本项目为酷哇 APP 车辆能耗成本管理模块的高保真 HTML 原型，用于产品评审、需求落地与开发参考。

## 项目说明

- **产品名称**：酷哇 APP
- **模块**：车辆能耗成本管理
- **主要用户**：司机、项目经理、管理员
- **技术栈**：HTML5 + Tailwind CSS v3 + 原生 JavaScript
- **设计规范**：
  - 移动端：`.claude/UI_design_APP.md`
  - WEB 端：`.claude/UI_design_WEB.md`
- **需求来源**：`01-需求文档/车务管理-能耗成本上报需求文档.md`

## 本地预览

直接用浏览器打开根目录下的 `index.html`，即可进入原型导航页，分别预览移动端与 WEB 管理端。

推荐使用 VS Code 的 Live Server 插件，或 Python 简易服务器：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 设计规范

- 移动端设计基准宽度：375px
- WEB 端适配：1366×768 及以上，主内容区自适应
- 主色：`#1677ff`
- 顶部导航栏高度：44px（移动端）/ 64px（WEB 端）
- 底部 Tab 栏高度：56px（移动端）
- 输入框高度：44px（移动端）/ 32px（WEB 端）
- 主按钮高度：44px（移动端）/ 32px（WEB 端）

详见 `.claude/UI_design_APP.md` 与 `.claude/UI_design_WEB.md`。
