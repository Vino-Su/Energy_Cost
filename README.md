# 酷哇 APP - 车辆能耗成本管理

本项目为酷哇 APP 车辆能耗成本管理模块的高保真 HTML 原型，用于产品评审、需求落地与开发参考。

## 项目说明

- **产品名称**：酷哇 APP
- **模块**：车辆能耗成本管理
- **主要用户**：司机、项目经理、管理员
- **技术栈**：HTML5 + Tailwind CSS v3 + 原生 JavaScript
- **设计规范**：
  - 移动端：`.Codex/UI_design_APP.md`
  - WEB 端：`.Codex/UI_design_WEB.md`
  - 车机端：`.Codex/UI_design_CAR.md`（16:9 横屏，1280×720 基准）
- **需求来源**：`01-需求文档/车务管理-能耗成本上报需求文档-融合OCR版本.md`、`01-需求文档/车辆使用过程监管方案.md`

车机通话原型可通过 `car-home.html?call=requesting`、`?call=incoming`、`?call=connected`、`?call=history` 分别验证硬件请求、云端呼入、通话中默认收起和历史记录状态。
进入已绑定且存在进行中任务的任务执行页后，原型会在第3秒展示主动发起通话请求、第7秒模拟接通、第9.5秒模拟成员加入、第13秒模拟远端挂断，并在第17秒展示云端呼入；呼入保持至用户接听、挂断或超时。可直接打开 `car-task-running.html?callDemo=auto` 进入演示，传入 `callDemo=off` 可关闭自动剧情；传入 `callDemo=requesting|incoming|connected|history` 可直达指定状态。

页面加载后可在浏览器控制台或自动化脚本中使用全局 `CAR_CALL_DEMO` 触发完整流程：

```javascript
CAR_CALL_DEMO.hardwareRequest(); // 外部硬件发起请求
CAR_CALL_DEMO.connect();         // 调度中心接听硬件请求
CAR_CALL_DEMO.updateParticipants([{ name: '陈志远' }, { name: '王莉' }, { name: '李工' }]); // 更新成员和人数
CAR_CALL_DEMO.hangup();          // 车机挂断

CAR_CALL_DEMO.cloudIncoming();   // 云端发起呼入
CAR_CALL_DEMO.accept();          // 车机接听
CAR_CALL_DEMO.expand();          // 展开通话浮窗
CAR_CALL_DEMO.remoteHangup();    // 模拟调度中心挂断

CAR_CALL_DEMO.cancel();          // 取消未接通的硬件请求
CAR_CALL_DEMO.reject();          // 拒接云端呼入
CAR_CALL_DEMO.openHistory();     // 打开历史通话
CAR_CALL_DEMO.reset();           // 重置当前通话演示状态
CAR_CALL_DEMO.snapshot();        // 读取当前通话和历史记录
CAR_CALL_DEMO.startTaskTimeline(); // 手动重放任务页通话剧情
CAR_CALL_DEMO.stopTaskTimeline();  // 停止未触发的剧情节点
```

外部硬件和云端事件模拟也可通过 `window.dispatchEvent(new CustomEvent('car:hardware-call-request', { detail }))` 与 `car:cloud-call-request` 触发。需要在通话组件就绪后运行的外部脚本，可监听 `car:call-ready` 事件。

## 导出 Figma 流程

将本项目页面复制到 Figma 时**无需任何特殊操作**——页面已默认保证 AXhub 复制无忧（毛玻璃用半透明白底模拟，不依赖 `backdrop-filter`；滚动条全局隐藏）。

1. 打开目标页面（如 `03-高保真页面/map-workbench.html`）。
2. （强烈建议）F12 → Ctrl+Shift+M → 选 iPhone 6/7/8（375×667）。
3. 启动 AXhub 框选目标区域 → 复制 → 粘贴到 Figma。

**禁止**：
- 在 HTML 中直接写 `backdrop-filter`（AXhub 会丢失）
- 装饰元素 `left + width > 375`（触发 AXhub 缩放）

详见 [`05-参考文件/导出figma注意事项.md`](05-参考文件/导出figma注意事项.md)。

## 设计规范

- 输入框高度：44px（移动端）/ 32px（WEB 端）
- 主按钮高度：44px（移动端）/ 32px（WEB 端）
