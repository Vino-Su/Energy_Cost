# 酷哇 APP - 能耗管理

本项目为酷哇 APP 能耗管理模块的高保真 HTML 原型，用于产品评审、需求落地与开发参考。

## 项目说明

- **产品名称**：酷哇 APP
- **模块**：能耗管理
- **主要用户**：司机、项目经理
- **技术栈**：HTML5 + Tailwind CSS v3 + 原生 JavaScript
- **设计规范**：`.claude/UI_design.md`（移动端 APP 通用规范）
- **需求来源**：`01-需求文档/能耗管理需求文档.md`

## 页面清单

| 页面      | 文件                            | 说明                      |
| :------ | :---------------------------- | :---------------------- |
| 首页/上报入口 | `03-高保真页面/home.html`          | 项目切换、加油/加水/充电入口、最近记录    |

## 本地预览

直接用浏览器打开根目录下的 `index.html` 即可在桌面端模拟手机预览效果。

推荐使用 VS Code 的 Live Server 插件，或 Python 简易服务器：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。
