# 酷哇 APP - 车辆能耗成本管理

本项目为酷哇 APP 车辆能耗成本管理模块的高保真 HTML 原型，用于产品评审、需求落地与开发参考。

## 项目说明

- **产品名称**：酷哇 APP
- **模块**：车辆能耗成本管理
- **主要用户**：司机、项目经理、管理员
- **技术栈**：HTML5 + Tailwind CSS v3 + 原生 JavaScript
- **设计规范**：
  - 移动端：`.claude/UI_design_APP.md`
  - WEB 端：`.claude/UI_design_WEB.md`
  - 车机端：`.claude/UI_design_CAR.md`（16:9 横屏，1280×720 基准）
- **需求来源**：`01-需求文档/车务管理-能耗成本上报需求文档-融合OCR版本.md`、`01-需求文档/车辆使用过程监管方案.md`

## 本地预览

直接用浏览器打开根目录下的 `index.html`，即可进入原型导航页，分别预览移动端与 WEB 管理端。

推荐使用 VS Code 的 Live Server 插件，或 Python 简易服务器：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 导出 Figma 流程

将本项目页面复制到 Figma 时**无需任何特殊操作**——页面已默认保证 AXhub 复制无忧（毛玻璃用半透明白底模拟，不依赖 `backdrop-filter`；滚动条全局隐藏）。

1. 打开目标页面（如 `03-高保真页面/map-workbench.html`）。
2. （强烈建议）F12 → Ctrl+Shift+M → 选 iPhone 6/7/8（375×667）。
3. 启动 AXhub 框选目标区域 → 复制 → 粘贴到 Figma。

**禁止**：
- 在 HTML 中直接写 `backdrop-filter`（AXhub 会丢失）
- 装饰元素 `left + width > 375`（触发 AXhub 缩放）

详见 [`05-参考文件/导出figma注意事项.md`](05-参考文件/导出figma注意事项.md)。

## 设计规范

- 移动端设计基准宽度：**375px**（代码层面已统一为 `max-width: 375px`；如发现 430/其他值即为 bug）
- WEB 端适配：1366×768 及以上，主内容区自适应（保持 1300px min-width，不动）
- 车机端适配：16:9 横屏，基准 1280×720，兼容 1024×576 / 1366×768 / 1920×1080；左右分屏 64:36，触控区 ≥56×56px，禁止 vw 字号与 backdrop-filter
- 主色：`#1677ff`
- 顶部导航栏高度：44px（移动端）/ 64px（WEB 端）
- 底部 Tab 栏高度：56px（移动端）
- 输入框高度：44px（移动端）/ 32px（WEB 端）
- 主按钮高度：44px（移动端）/ 32px（WEB 端）

详见 `.claude/UI_design_APP.md` 与 `.claude/UI_design_WEB.md`。
