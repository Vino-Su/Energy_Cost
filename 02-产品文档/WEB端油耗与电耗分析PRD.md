## 名词解释

| 名词/缩写 | 解释 |
| ---------- | ---- |
| 统计周期 | 用户当前选择的开始日期至结束日期，开始日与结束日均计入统计范围 |
| 有效记录 | 未删除、属于当前数据权限范围且核心统计字段满足本 PRD 校验规则的加油或充电记录 |
| 候选能耗区间 | 同一车辆按业务时间排序后，由前后相邻两条补能记录形成且区间结束时间位于统计周期内的区间；统计开始日期前最近一条记录可作为首个区间基线 |
| 完整能耗区间 | 同一车辆按业务时间顺序排列后，由前后两条有效里程记录组成且里程差大于 0 的区间；区间结束记录的能耗量和金额归入该区间 |
| 有效区间 | 候选能耗区间取得大于 0 的轨迹里程，或前后记录里程均有效且里程差大于 0 时，认定为有效区间并参与能效计算；页面按“有效区间数/候选区间数”展示 |
| 有效行驶里程 | 当前统计周期内全部完整能耗区间的里程差之和，单位为 km |
| 区间估算 | 使用相邻补能记录的里程差与区间结束记录的补能量估算能耗；因缺少油量或荷电状态边界，结果不等同于车辆实时消耗量 |
| 轨迹校准 | 使用车辆轨迹里程替代或校验里程表区间后得到的能耗结果；本期允许接入但不作为上线前置条件 |
| 综合油价 | 当前统计范围内加油总金额除以加油总量，单位为元/L |
| 综合充电单价 | 当前统计范围内充电总金额除以充电度数，包含电费和服务费，单位为元/度 |
| 同车型基准 | 当前项目、统计周期和车型内，具备可分析数据的车辆百公里能耗中位数 |
| 偏差率 | 单车百公里能耗相对同车型基准的差异比例，计算公式为“（单车值－基准值）÷基准值×100%” |
| 可计算车辆占比 | 能够计算百公里能耗的车辆数除以当前筛选范围内存在对应补能记录的车辆数 |

## 1. 业务背景与使用角色
### 1.1 业务背景
- 模块定位：在现有加油、充电费用采集和记录治理基础上，面向项目管理人员提供能耗总量、成本结构、单车效率和异常偏差分析。
- 当前现状：现有 WEB 端加油、充电记录页支持按项目查看记录并汇总数量与金额，但不计算综合单价、百公里能耗、每公里成本、车型基准或单车偏差。
- 业务痛点：项目经理需要导出记录后自行加工，无法快速判断项目能耗趋势、定位高能耗车辆，也无法确认分析结论的数据覆盖情况。
- 建设方式：在能耗管理下新增“油耗分析”和“电耗分析”两个独立页面；每个页面包含“统计分析”和“单车明细”两个 Tab，统计分析负责判断整体情况，单车明细负责定位具体车辆。
- 关联模块关系：从加油记录和充电记录读取有效业务数据，从项目及权限上下文确定数据范围，从 basis 平台读取车型信息；用户可从单车明细下钻到现有原始记录页核查凭证与变更记录。
### 1.2 使用角色

| 角色 | 该模块中的职责 | 客户端 |
| ---- | ------------ | ------ |
| 项目经理 | 查看本人负责项目的油耗、电耗及单车偏差，定位需要核查的车辆 | WEB 端 |
| 车队长 | 协助项目经理分析车辆能耗，核查单车原始补能记录 | WEB 端 |
| 管理员 | 查看权限系统授权项目的分析数据，处理跨项目数据治理问题 | WEB 端 |

### 1.3 核心目标与价值

| 目标维度 | 说明 |
| -------- | ---- |
| 项目经营判断 | 在统一统计周期内了解油量、电量、费用、综合价格和变化趋势 |
| 单车效率分析 | 形成百公里油耗、百公里电耗和每公里能耗成本，定位高偏差车辆 |
| 同类公平比较 | 按项目和车型形成基准，避免直接比较不同车型造成错误判断 |
| 数据底数可见 | 展示每辆车的有效区间数和候选区间数，帮助用户判断能效结果的数据基础，并定位无效区间 |
| 问题追溯 | 从分析结果下钻至对应车辆、项目和时间范围的原始记录 |
| 统一口径 | 确保统计分析、单车明细和导出数据使用相同范围与计算规则 |

## 3. 功能详细设计
### 3.1 F01 分析入口与统一查询上下文
#### 3.1.1 功能目标与范围

| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 用户在有权项目内进入油耗或电耗分析，并使用统一条件查询统计分析与单车明细 |
| 使用角色 | 项目经理、车队长、管理员 |
| 触发条件 | 用户从能耗管理进入“油耗分析”或“电耗分析” |
| 功能边界 | 提供两个独立页面；每页仅包含“统计分析”和“单车明细”两个 Tab，不在同一页面混合油、电指标 |
| 成功结果 | 当前页面按有效查询条件加载统计结果，两个 Tab 共享相同项目、日期、车型和车辆上下文 |

#### 3.1.2 使用条件与权限

| 角色 | 可执行操作 | 数据范围 | 前置条件 |
| ---- | ---------- | -------- | -------- |
| 项目经理 | 查询、切换 Tab、查看单车明细、下钻记录、导出 | 本人负责且权限有效的项目 | 已登录且至少具有一个项目权限 |
| 车队长 | 查询、切换 Tab、查看单车明细、下钻记录、导出 | 本人关联且权限有效的项目 | 已登录且具有能耗数据查看权限 |
| 管理员 | 查询、切换 Tab、查看单车明细、下钻记录、导出 | 权限系统授权的全部项目 | 已登录且具有能耗分析权限 |

#### 3.1.3 数据与字段规则

**油耗分析查询条件：**

| 字段/条件 | 业务含义 | 取值方式或数据来源 | 默认值 | 校验/匹配规则 |
| --------- | -------- | -------------------- | ------ | ------------- |
| 当前项目 | 确定数据隔离范围 | 项目及权限上下文 | 上次成功选择的项目；无历史时取默认有权项目 | 仅允许选择有权项目；切换后重新查询并清空车辆条件 |
| 加油日期 | 加油记录及完整能耗区间的结束日期范围 | 用户选择 | 当前自然月首日至当前日期 | 开始日期不得晚于结束日期，结束日期不得晚于当前日期；按加油时间匹配 |
| 统计粒度 | 趋势数据的时间分组方式 | 用户选择；枚举值：日、周、月 | 日 | 仅影响趋势分组，不改变总量和单车汇总口径 |
| 车型 | 限定车型范围 | basis 平台车辆与车型关系 | 全部 | 仅匹配当前项目车辆；无车型车辆归入“车型未知” |
| 车牌号 | 限定单车范围 | 当前项目车辆 | 全部 | 支持按完整车牌选择和车牌号模糊检索 |

**电耗分析查询条件：**

| 字段/条件 | 业务含义 | 取值方式或数据来源 | 默认值 | 校验/匹配规则 |
| --------- | -------- | -------------------- | ------ | ------------- |
| 当前项目 | 确定数据隔离范围 | 项目及权限上下文 | 上次成功选择的项目；无历史时取默认有权项目 | 仅允许选择有权项目；切换后重新查询并清空车辆条件 |
| 充电日期 | 充电记录及完整能耗区间的结束日期范围 | 用户选择 | 当前自然月首日至当前日期 | 开始日期不得晚于结束日期，结束日期不得晚于当前日期；按充电结束时间匹配 |
| 统计粒度 | 趋势数据的时间分组方式 | 用户选择；枚举值：日、周、月 | 日 | 仅影响趋势分组，不改变总量和单车汇总口径 |
| 车型 | 限定车型范围 | basis 平台车辆与车型关系 | 全部 | 仅匹配当前项目车辆；无车型车辆归入“车型未知” |
| 车牌号 | 限定单车范围 | 当前项目车辆 | 全部 | 支持按完整车牌选择和车牌号模糊检索 |

#### 3.1.4 业务规则与状态变化

| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| BR-F01-01 | 用户进入分析页面 | 默认进入“统计分析”Tab 并加载默认查询条件 | 生成当前查询上下文 |
| BR-F01-02 | 用户切换同一页面的 Tab | 保留全部公共查询条件和已选项目 | 仅切换结果视图，不重新初始化条件 |
| BR-F01-03 | 用户在油耗分析与电耗分析间切换 | 保留当前项目、日期范围、统计粒度和可匹配的车型、车辆；无法匹配的条件自动清空 | 按目标页面业务时间重新查询 |
| BR-F01-04 | 用户切换项目 | 清空原项目的车型和车辆条件，保留日期与统计粒度 | 防止跨项目条件串用 |
| BR-F01-05 | 当前项目权限失效 | 停止展示该项目数据并切换至其他可用默认项目 | 原项目分析结果清空 |

#### 3.1.5 交互流程
1. 用户从能耗管理进入油耗分析或电耗分析。
2. 系统读取登录用户、当前项目及数据权限，并加载默认统计周期。
3. 系统校验查询条件并读取当前有效业务数据。
4. 用户修改项目、日期、统计粒度、车型或车牌号后发起查询。
5. 处理结果：
   - 成功 → 刷新当前 Tab 结果并同步保存公共查询上下文，用户可切换 Tab、下钻或导出。
   - 失败 → 保留用户已填写条件，清空旧结果并说明失败原因，用户可重试或调整条件。
#### 3.1.6 异常处理

| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 无可用项目 | 用户没有任何项目权限 | 不查询分析数据 | 提示联系管理员分配项目权限 | 权限生效后重新进入 |
| 查询日期非法 | 开始日期晚于结束日期或结束日期晚于当前日期 | 不执行查询并保留原结果 | 明确提示日期问题 | 修改日期后重新查询 |
| 项目上下文加载失败 | 项目或权限服务不可用 | 不展示其他项目数据 | 提示项目上下文加载失败 | 允许重试或重新登录 |
| 查询结果为空 | 当前条件没有有效业务记录 | 展示空结果，所有不可计算指标显示“—” | 提示当前条件暂无数据 | 调整筛选条件 |

#### 3.1.7 外部依赖

| 依赖模块/服务 | 输入 | 输出 | 调用时机 | 失败处理 |
| ----------- | ---- | ---- | -------- | -------- |
| 权限及用户系统 | 当前登录用户 | 角色、项目权限、功能权限 | 进入页面和切换项目时 | 不加载越权数据并提示权限异常 |
| 项目上下文 | 当前用户及已选项目 | 当前项目、可选项目 | 进入页面和项目切换时 | 保留非项目条件并允许重试 |
| basis 平台 | 项目、车辆标识 | 车牌号、车型、车辆能源类型 | 查询条件和结果加载时 | 车型显示“未知”，相关车辆不参与同车型基准 |

### 3.2 F02 油耗统计分析
#### 3.2.1 功能目标与范围

| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 汇总当前项目和统计周期的加油规模、成本、效率、趋势及车型差异 |
| 使用角色 | 项目经理、车队长、管理员 |
| 触发条件 | 用户进入油耗分析的“统计分析”Tab 或更新查询条件 |
| 功能边界 | 仅分析加油记录；不展示逐笔交易，不将加水或充电数据计入油耗指标 |
| 成功结果 | 用户能够判断项目油耗和油费变化，并可定位高偏差车型或车辆 |

#### 3.2.3 数据与字段规则

**统计指标：**

| 字段 | 业务含义 | 数据来源 | 格式/口径规则 | 空值处理 |
| ---- | -------- | -------- | ------------- | -------- |
| 加油车辆数 | 当前筛选范围内存在有效加油记录的去重车辆数 | 加油记录 | 按车辆标识去重 | 无记录显示 0 |
| 加油次数 | 当前筛选范围内有效加油记录数 | 加油记录 | 不包含已删除记录 | 无记录显示 0 |
| 加油量 | 当前筛选范围内有效记录的加油量合计 | 加油记录 | 单位 L | 无记录显示“—” |
| 加油金额 | 当前筛选范围内有效记录的加油金额合计 | 加油记录 | 单位元，以记录金额为准 | 无记录显示“—” |
| 综合油价 | 当前筛选范围内加油金额与加油量的加权结果 | 加油记录 | 加油金额÷加油量，单位元/L | 加油量为 0 时显示“—” |
| 有效行驶里程 | 可计算完整能耗区间的里程合计 | 加油记录或轨迹里程 | 单位 km | 无完整区间显示“—” |
| 百公里油耗 | 项目加权油耗水平 | 完整能耗区间 | 参与计算的区间加油量÷有效行驶里程×100，单位 L/100km | 无有效里程显示“—” |
| 每公里油费 | 项目加权行驶油费 | 完整能耗区间 | 参与计算的区间加油金额÷有效行驶里程，单位元/km | 无有效里程显示“—” |
| 可计算车辆占比 | 当前分析结论的数据覆盖情况 | 加油记录 | 可计算车辆数÷加油车辆数×100% | 加油车辆数为 0 时显示“—” |
| 关注车辆数 | 百公里油耗高于同车型基准 10% 且不高于 20% 的车辆数 | 分析结果 | 仅统计至少存在 1 个有效区间且具备车型基准的车辆 | 无基准时显示 0 |
| 异常车辆数 | 百公里油耗高于同车型基准 20% 的车辆数 | 分析结果 | 仅统计至少存在 1 个有效区间且具备车型基准的车辆 | 无基准时显示 0 |

**分析输出：**

| 分析项 | 业务含义 | 维度 | 输出规则 | 空值处理 |
| ------ | -------- | ---- | -------- | -------- |
| 加油规模趋势 | 观察加油量与加油金额随时间变化 | 统计粒度 | 按加油时间将有效记录归入日、周或月 | 无数据周期显示 0 |
| 油耗效率趋势 | 观察百公里油耗与每公里油费随时间变化 | 统计粒度 | 在完整查询周期构建能耗区间，再按区间结束记录的加油时间归入日、周或月并按加权口径计算 | 无有效区间显示“—” |
| 车型油耗对比 | 比较不同车型能耗差异 | 车型 | 展示各车型百公里油耗、每公里油费、可计算车辆数 | 车型未知单独归类但不生成基准 |

### 3.7 F07 有效区间与数据质量判定
#### 3.7.1 功能目标与范围

| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 在现有补能记录条件下形成可解释的能耗指标，并让用户通过有效区间数和候选区间数判断分析底数 |
| 使用角色 | 项目经理、车队长、管理员 |
| 触发条件 | 系统计算油耗、电耗统计分析或单车明细 |
| 功能边界 | 本期不推断车辆实际剩余油量或荷电状态；未接入相关边界数据时，百公里能耗均按区间估算解释 |
| 成功结果 | 每辆车获得有效区间数、候选区间数和无效原因，项目汇总只使用满足条件的有效区间 |

#### 3.7.3 数据与字段规则

| 数据项 | 有效条件 | 无效条件 | 无效后的业务处理 |
| ------ | -------- | -------- | ---------------- |
| 车辆标识 | 能唯一关联当前项目车辆 | 缺失或无法关联车辆 | 不生成单车结果；原始记录保留治理 |
| 业务时间 | 加油时间或充电结束时间存在且合法 | 缺失或格式非法 | 不进入时间统计和区间计算 |
| 能耗量 | 加油量或充电度数大于等于 0 | 缺失、非数字或小于 0 | 记录不参与能耗量及价格计算 |
| 记录金额 | 加油金额或充电金额大于等于 0 | 缺失、非数字或小于 0 | 记录不参与金额和单位成本计算 |
| 当前里程 | 非负数且可按时间排序 | 缺失、非数字或小于 0 | 可计入经营总量，不参与区间计算 |
| 车型 | 可关联 basis 平台当前有效车型 | 缺失或关联失败 | 归入车型未知，不参与同车型基准 |
| 充电费用结构 | 电费、服务费均不小于 0，且二者之和与充电金额差额不超过 0.01 元 | 任一缺失、为负数或差额超过 0.01 元 | 充电金额仍计入经营成本，记录不参与服务费占比计算 |

#### 3.7.4 业务规则与状态变化

| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| BR-F07-01 | 构建候选能耗区间 | 同车同能耗类型记录按业务时间升序排列；相邻两条记录形成候选区间，统计开始日期前最近一条记录只作为首个区间基线，不计入周期经营总量 | 候选区间数增加 1 |
| BR-F07-02 | 候选区间取得大于 0 的轨迹里程 | 使用轨迹里程作为区间里程，区间结束记录的能耗量和金额参与百公里能耗及每公里成本计算 | 有效区间数增加 1 |
| BR-F07-03 | 无有效轨迹，但前后记录里程均有效且里程差大于 0 | 使用里程表差值作为区间里程 | 有效区间数增加 1 |
| BR-F07-04 | 前后任一记录缺少里程且无有效轨迹里程 | 不跨过中间补能记录拼接区间，避免能耗量与里程错误匹配 | 当前候选区间无效，记录原因为里程缺失 |
| BR-F07-05 | 相邻里程差等于 0 且无有效轨迹里程 | 无法证明车辆产生有效行驶里程 | 当前候选区间无效，记录原因为里程未增长 |
| BR-F07-06 | 后一条记录里程小于前一条记录且无有效轨迹里程 | 判定里程回退 | 当前候选区间无效，记录原因为里程回退 |
| BR-F07-07 | 同一车辆同时存在有效区间和无效区间 | 有效区间继续参与计算，个别异常记录不否定整辆车 | 分别累计有效区间数和候选区间数，并保留无效原因 |
| BR-F07-08 | 车辆有效区间数为 0 | 不输出百公里能耗、每公里成本和偏差率 | 经营总量继续统计，偏差状态为无基准 |
| BR-F07-09 | 汇总项目能耗 | 仅汇总有效区间；经营总量仍统计全部有效业务记录 | 防止无效里程污染能效指标 |

#### 3.7.5 交互流程
1. 系统取得当前筛选范围内的业务记录，并额外取得各车辆统计开始日期前最近一条有效里程记录作为可选基线。
2. 系统校验车辆、时间、能耗量、金额、里程和车型数据。
3. 系统按车辆和能耗类型排序记录，构建相邻区间并判断里程有效性。
4. 系统逐个判定候选区间，优先使用有效轨迹里程，否则校验里程表差值；不得跨过中间补能记录拼接区间。
5. 系统汇总有效区间，生成项目指标、单车指标、有效区间数、候选区间数和无效原因。
6. 处理结果：
   - 存在有效区间 → 输出能效指标并按“有效区间数/候选区间数”展示分析底数。
   - 无有效区间 → 仅输出可用经营总量，能效指标显示“—”，展示“0/候选区间数”和无效原因。
#### 3.7.6 异常处理

| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 基线记录不存在 | 统计开始日期前没有有效里程记录 | 从周期内首条有效里程记录开始构建后续区间 | 首个周期区间不参与计算 | 扩大日期范围或等待后续记录 |
| 轨迹里程服务不可用 | 无法取得轨迹数据 | 回退使用里程表区间 | 标记区间估算 | 服务恢复后重新查询 |
| 车辆存在多种能源记录 | 同车既有加油又有充电记录 | 两个分析页面分别按对应能耗类型计算，不交叉合并 | 不生成综合百公里能耗 | 分别查看油耗和电耗分析 |
| 原始记录发生纠错 | 用户修改里程、能耗量、金额或时间 | 下次查询重新构建全部受影响区间 | 提示分析结果以最新记录为准 | 重新查询 |

#### 3.7.7 外部依赖

| 依赖模块/服务 | 输入 | 输出 | 调用时机 | 失败处理 |
| ----------- | ---- | ---- | -------- | -------- |
| 加油及充电记录模块 | 项目、车辆、统计周期 | 有效业务记录及统计期前基线记录 | 每次分析查询 | 无数据时不生成分析结果 |
| basis 平台 | 车辆标识 | 车型、项目归属、能源类型 | 数据校验和车型基准计算 | 车型未知且不参与基准 |
| 车辆轨迹模块 | 车辆、区间开始及结束时间 | 区间轨迹里程 | 区间计算时按可用性调用 | 回退区间估算，不阻断基础分析 |

## 4. 业务规则汇总
### 4.1 数据范围与权限规则

| 规则项 | 业务规则 |
| ------ | -------- |
| 项目隔离 | 所有查询、统计、下钻和导出必须限制在用户当前有权项目，不允许跨项目合并 |
| 记录状态 | 已逻辑删除记录不参与任何分析；新增、编辑成功的记录在下一次查询中按最新值参与分析 |
| 分析对象 | 油耗页面仅使用加油记录，电耗页面仅使用可归属单车的充电记录 |
| 车型范围 | 车型来自 basis 平台；车型未知车辆计入项目经营总量但不参与车型基准 |
| 页面权限 | 具有能耗分析权限且拥有项目数据权限的用户方可查询、下钻和导出 |

### 4.2 计算规则

| 指标 | 计算公式 | 数据范围 | 说明 |
| ---- | -------- | -------- | ---- |
| 加油量 | Σ有效加油记录的加油量 | 当前筛选记录 | 经营总量 |
| 加油金额 | Σ有效加油记录的加油金额 | 当前筛选记录 | 以业务记录金额为准 |
| 综合油价 | 加油金额÷加油量 | 当前筛选记录 | 加油量为 0 时不计算 |
| 百公里油耗 | Σ完整区间加油量÷Σ有效行驶里程×100 | 当前筛选完整能耗区间 | 项目、车型汇总均使用加权公式 |
| 每公里油费 | Σ完整区间加油金额÷Σ有效行驶里程 | 当前筛选完整能耗区间 | 不使用全部经营金额代替区间金额 |
| 充电度数 | Σ有效充电记录的充电度数 | 当前筛选记录 | 经营总量 |
| 充电总金额 | Σ有效充电记录的充电金额 | 当前筛选记录 | 以业务记录金额为准 |
| 综合充电单价 | 充电总金额÷充电度数 | 当前筛选记录 | 包含电费和服务费 |
| 电费单价 | 充电电费÷充电度数 | 费用结构可核对记录 | 不包含服务费 |
| 服务费占比 | 充电服务费÷（充电电费＋充电服务费）×100% | 费用结构可核对记录 | 分母为 0 时不计算 |
| 百公里电耗 | Σ完整区间充电度数÷Σ有效行驶里程×100 | 当前筛选完整能耗区间 | 项目、车型汇总均使用加权公式 |
| 每公里电费 | Σ完整区间充电金额÷Σ有效行驶里程 | 当前筛选完整能耗区间 | 不使用全部经营金额代替区间金额 |
| 平均充电时长 | Σ有效充电时长÷有效时长记录数 | 当前筛选记录 | 仅统计结束时间不早于开始时间的记录 |
| 同车型基准 | 同车型可分析车辆百公里能耗的中位数 | 当前项目、周期、车型 | 可分析车辆不少于 3 辆时计算 |
| 偏差率 | （单车百公里能耗－同车型基准）÷同车型基准×100% | 可比较车辆 | 基准为 0 或不存在时不计算 |
| 可计算车辆占比 | 可计算百公里能耗车辆数÷存在对应补能记录车辆数×100% | 当前筛选车辆 | 分母为 0 时不计算 |

### 4.3 偏差状态规则

| 状态 | 判定条件 | 业务含义 |
| ---- | -------- | -------- |
| 正常 | 偏差率大于等于－20% 且小于等于 10% | 当前周期能耗未达到关注阈值 |
| 关注 | 偏差率大于 10% 且小于等于 20% | 高于同车型基准，需要持续观察 |
| 异常 | 偏差率大于 20% | 明显高于同车型基准，需要核查原始记录及车辆使用情况 |
| 偏低待核验 | 偏差率小于－20% | 可能节能，也可能存在漏报、里程或能耗量异常，不直接认定为优秀 |
| 无基准 | 车型可分析车辆少于 3 辆、数据不足、数据异常或车型未知 | 不作横向评价 |

### 4.4 有效区间规则

| 区间结果 | 判定条件 | 是否计入有效区间 | 管理解释 |
| -------- | -------- | ---------------- | -------- |
| 轨迹里程有效 | 候选区间取得大于 0 的轨迹里程 | 是 | 使用轨迹里程计算，里程表数据保留用于核查 |
| 表显里程有效 | 无有效轨迹里程，前后记录里程均有效且差值大于 0 | 是 | 使用里程表差值计算，结果用于趋势和偏差分析 |
| 里程数据不足 | 前后任一记录缺少里程且无有效轨迹里程 | 否 | 仅排除受影响候选区间，不否定车辆其他有效区间 |
| 里程数据异常 | 里程不增长、回退或字段非法且无有效轨迹里程 | 否 | 仅排除受影响候选区间，并保留原因供原始记录核查 |
| 无候选区间 | 当前周期记录不足且统计期前无可用基线记录 | 否 | 页面显示“0/0”，不输出能效及偏差指标 |

有效区间字段统一按“有效区间数/候选区间数”输出。本期不设置统一的最低有效比例，不因单个无效区间自动屏蔽整车结果；用户结合区间数量、偏差结果和原始记录判断是否采用分析结论。

### 4.5 查询、联动与更新规则

| 场景 | 规则 |
| ---- | ---- |
| Tab 切换 | 同一分析页面的两个 Tab 共享项目、日期、车型和车辆条件 |
| 页面切换 | 油耗与电耗页面保留可复用条件，不可匹配的车辆条件自动清空 |
| 统计联动 | 统计分析选择车型、车辆或偏差状态后，单车明细按相同数据范围查询 |
| 原始记录下钻 | 传递项目、业务日期范围和车牌号；目标页仍按用户权限重新校验 |
| 数据更新 | 每次发起查询均读取当前有效记录；本期不要求记录变化后实时推送刷新 |
| 分页 | 单车明细默认每页 10 条，支持 20、50、100 条；切换分页不改变统计总量 |

### 4.6 导出规则

| 规则项 | 说明 |
| ------ | ---- |
| 数据范围 | 导出当前全部有效筛选条件命中的单车结果，不受当前页码影响 |
| 指标口径 | 导出字段、公式、偏差状态、有效区间数和候选区间数必须与页面一致 |
| 权限校验 | 导出执行时重新校验用户功能权限和项目数据权限 |
| 数据快照 | 文件使用导出执行时的最新有效数据，并记录生成时间 |
| 空结果 | 无匹配车辆时不生成空文件，提示调整筛选条件 |

### 4.7 验收规则

| 编号 | 验收项 |
| ---- | ------ |
| AC01 | 能耗管理下存在油耗分析和电耗分析两个独立入口，且各自仅包含统计分析、单车明细两个 Tab |

| AC05 | 电耗统计正确展示充电度数、电费、服务费、总金额、综合单价、服务费占比、有效里程、百公里电耗、每公里电费和可计算车辆占比 |

| AC09 | 只有一条里程记录、里程回退或里程不增长时，不输出该区间百公里能耗，经营总量仍按有效记录统计 |
| AC10 | 单车明细按“有效区间数/候选区间数”展示；个别里程缺失或异常仅排除受影响区间，其他有效区间继续参与计算 |
| AC11 | 电费与服务费之和同充电金额差额超过 0.01 元时，总金额仍计入经营成本，但该记录不参与服务费占比计算 |
| AC12 | 从统计分析选择车型、车辆或偏差状态后，可进入带对应条件的单车明细 |
| AC13 | 从油耗或电耗单车明细查看原始记录时，正确带入项目、日期和车牌号，且返回后恢复分析上下文 |
| AC14 | 单车明细导出覆盖当前全部筛选结果，不受当前页码影响，导出指标与页面一致 |
| AC15 | 用户无项目权限、查询失败、空结果、数据不足和数据异常时均有明确结果，且不展示其他项目数据 |
| AC16 | 原始记录新增、修改或删除后，重新查询可得到按最新有效数据计算的分析结果 |
