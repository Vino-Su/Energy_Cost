## 2 名词解释

| 名词/缩写 | 解释 |
| ---------- | ---- |
| 今日用车 | 司机在城市管家 APP 中开始当天车辆使用与任务执行的主入口 |
| 地图工作台 | 以地图为主体承载待办任务、导航路线、实时轨迹、异常提醒和辅助操作的司机工作界面 |
| 人车绑定 | 驾驶员与车辆在一定时间范围内建立的使用关系，是进入今日用车主流程的前置状态 |
| 接车 | 驾驶员开始使用车辆时，通过扫码等绑定动作建立人车绑定关系 |
| 交车 | 驾驶员结束使用车辆时，通过交车确认解除人车绑定关系 |
| 动态任务 | 作业过程中由系统识别、调度或异常事件触发并临时推送给司机处理的任务 |
| 阻断项 | 未处理前不允许继续执行关键动作的事项，如未结束任务、车辆不可用 |
| 提醒项 | 需要提示司机关注但不强制阻断当前动作的事项，如异常待确认、照片待补充 |

## 3 业务背景与使用角色
### 3.1 业务背景
- 模块定位：今日用车地图工作台是车辆使用过程监管方案在司机端 APP 的主流程承载模块，用于把接车状态、任务执行、轨迹导航、动态任务、异常提醒、水电油上报、一键报修、结束任务和交车收口串联到一个以地图为核心的工作界面。
- 核心特点：司机打开 APP 后进入“今日用车”，系统先校验司机是否已绑定车辆；已绑定则直接进入地图工作台，未绑定则展示未绑定提示并引导完成车辆绑定；本期不建设单独司机展示二维码页面或入口。
- 业务痛点：原车辆使用动作分散在多个功能中，司机需要自行查找任务、报修、补给等入口；管理侧难以稳定追踪人车关系、任务路线、轨迹偏差、异常响应和交车闭环。
- 关联模块关系：模块从 basis 平台读取车辆信息，从环卫云平台读取排班任务、动态任务、轨迹和异常记录，从售后平台同步维修工单，从能耗成本模块复用水电油上报能力。
### 3.2 使用角色

| 角色 | 该模块中的职责 | 客户端 |
| ---- | ------------ | ------ |
| 作业车辆驾驶员 | 进入今日用车、完成绑定状态校验、查看地图工作台、查看任务、调用外部地图导航、开始/结束任务、处理动态任务、上报水电油、发起一键报修、完成交车 | 移动端 APP |
| 项目经理/管理员 | 查看异常记录、核查车辆使用异常、处理合规异常、调整任务或维修资源 | 管理端/环卫云平台 |
| 系统服务 | 判断绑定状态、同步车辆可用性、聚合任务待办、接收轨迹数据、生成异常记录、保存接车/交车留痕 | 后端服务 |

### 3.3 核心目标与价值

| 目标维度 | 说明 |
| -------- | ---- |
| 司机操作效率 | 将司机高频工作收敛到地图工作台，减少多入口跳转和学习成本 |
| 主流程清晰 | 形成“今日用车校验 - 地图任务 - 结束任务 - 交车”的稳定路径 |
| 监管留痕 | 自动沉淀人员、车辆、时间、位置、轨迹、异常、上报和交车记录 |
| 风险控制 | 对未绑定车辆、车辆不可用、未结束任务、阻断项等关键场景进行提示或拦截 |
| 业务融合 | 将水电油上报和一键报修作为工作台辅助动作，支持任务执行期间穿插处理 |

## 5 功能详细设计
### 5.1 F01 今日用车入口校验与未绑定引导
#### 5.1.1 页面布局

页面包含“今日用车入口”和“未绑定引导页/状态”两个层级：

1. **今日用车入口**：位于城市管家首页或工作台应用入口区，按钮文案为“今日用车”。
	- 如果已绑定车辆，卡片右侧显示绑定的车辆牌照
	- 如果未绑定车辆，卡片右侧显示当前未绑定车辆
2. **校验反馈区**：点击入口后展示加载状态，校验司机绑定状态和当前绑定车辆可用状态。
3. **未绑定引导区**：司机无有效绑定车辆时展示未绑定提示、绑定说明、主操作按钮和辅助说明。
4. **异常提示区**：绑定失效、车辆不可用、车辆被占用、司机账号异常等情况展示明确原因。
#### 5.1.2 数据展示字段

| 区域    | 字段/元素 | 示例              | 说明               |
| ----- | ----- | --------------- | ---------------- |
| 入口    | 入口名称  | 今日用车            | 司机进入当天用车主流程的唯一入口 |
| 入口    | 入口说明  | 接车、任务、轨迹、上报、交车  | 概括核心能力           |
| 加载态   | 校验文案  | 正在校验车辆绑定状态      | 点击入口后展示          |
| 未绑定状态 | 主标题   | 暂未绑定车辆          | 明确无法进入地图工作台的原因   |
| 未绑定状态 | 说明    | 请先完成车辆绑定后开始今日任务 | 引导司机完成绑定         |
| 未绑定状态 | 主按钮   | 去绑定车辆           | 跳转或唤起既有绑定/扫码能力   |
| 未绑定状态 | 次按钮   | 返回首页            | 退出当前引导           |

#### 5.1.3 前置校验

| 校验条件             | 提示信息             | 阻断操作       |
| ---------------- | ---------------- | ---------- |
| 当前司机已绑定有效车辆      | 无需提示             | 允许进入地图工作台  |
| 当前司机未绑定车辆        | 暂未绑定车辆，请先完成车辆绑定  | 不允许进入地图工作台 |
| 当前绑定关系已失效        | 绑定状态已失效，请重新绑定车辆  | 不允许进入地图工作台 |
| 当前绑定车辆被标记为维修中    | 当前车辆维修中，暂不可用车    | 不允许进入地图工作台 |
| 当前绑定车辆证照/保险/年检到期 | 车辆不满足用车条件，请联系管理员 | 不允许进入地图工作台 |
| 当前司机账号无今日用车权限    | 暂无今日用车权限         | 不允许进入地图工作台 |

#### 5.1.4 交互流程
1. 司机打开 APP，进入城市管家首页或工作台。
2. 司机点击“今日用车”。
3. 系统查询司机当前人车绑定状态和车辆可用状态：
   - 已绑定且车辆可用 → Toast 提示“进入今日用车”，跳转地图工作台。
   - 未绑定车辆 → 展示未绑定引导页/状态，不进入地图工作台。
   - 已绑定但车辆不可用 → 展示不可用原因，不进入地图工作台。
4. 司机在未绑定引导页点击“去绑定车辆”：
   - 成功唤起既有绑定/扫码能力 → 绑定完成后重新校验并进入地图工作台。
   - 唤起失败 → Toast 提示“绑定入口暂不可用，请稍后重试”，停留当前页。
5. 司机点击“返回首页” → 返回城市管家首页或上一层工作台。
#### 5.1.5 弹窗规格

| 属性 | 值 |
| ---- | -- |
| 弹窗名称 | 车辆不可用提示弹窗 |
| 触发入口 | 点击今日用车后校验失败 |
| 位置 | 居中弹出或页面内提示，移动端按设计规范选用 |
| 标题 | 无法进入今日用车 |
| 内容 | 车辆不可用或绑定异常的具体原因 |
| 主按钮 | 知道了 |
| 次按钮 | 联系管理员/返回首页，按项目配置展示 |

### 5.2 F02 地图工作台
#### 5.2.1 页面布局

地图工作台为司机已绑定车辆后的主页面，页面自上而下/由外到内分为 6 个区域：

1. **地图主体区**：全屏或近全屏展示地图，显示车辆当前位置、任务路线、实时轨迹、目标点、异常点和动态任务点；高保真原型采用内置 SVG/CSS 仿地图底图承载路线与车辆移动，真实开发可按地图供应商能力替换底图层。
2. **顶部状态栏**：以车辆执行状态条呈现，展示返回入口、车牌号主信息、车型/今日任务副信息、车辆状态。
3. **右侧悬浮工具组**：提供定位回正、图层切换、异常提醒、水电油上报、一键报修、交车等快捷操作。
4. **底部待办任务抽屉**：默认半展开，展示当前任务、待办任务和任务状态；上滑展开完整待办列表。
5. **任务执行状态条**：执行中展示任务进度、已作业时长、路线覆盖提示和结束任务按钮。
6. **消息提醒层**：用于展示动态任务推送、异常播报、强提醒和轻提示；行驶中系统派发的新任务以地图上方 banner 轻提醒呈现，宽度与顶部车牌信息卡一致，信息靠左排列，右侧固定“查看”按钮，内容格式为“新动态任务 任务名称-距离 查看”，点击后聚焦对应待办任务。
#### 5.2.2 数据展示字段

| 区域    | 字段/元素 | 示例          | 说明                                    |

| 顶部状态栏 | 车牌号   | 粤 B·D2856   | 当前绑定车辆；与车辆图标同一行，图标在左                                |
| 顶部状态栏 | 车型    | 洗扫车         | 副标题第一项，与车牌不同行展示                            |

| 顶部状态栏 | 今日任务  | 今日 6 项任务       | 副标题第二项，统计今日待执行、执行中、已完成任务总量             |
| 顶部状态栏 | 已完成任务 | 已完成 0 项      | 副标题第三项，统计今日已完成任务数                     |

#### 5.2.3 前置校验

| 校验条件 | 提示信息 | 阻断操作 |
| -------- | -------- | -------- |
| 未绑定车辆访问地图工作台 | 请先绑定车辆 | 阻断访问并跳转未绑定引导 |

#### 5.2.4 交互流程

1. 进入地图工作台后，此时还未开始任务，地图中默认显示当前车辆位置，底部显示该车辆今日的待办任务卡片，默认仅展示前三个，支持拉起显示全部（可覆盖地图，也支 持收起），应急任务排在排班任务前。
	- 存在执行中任务 → 默认选中执行中任务。
	- 存在应急任务 → 应急任务优先展示并高亮。
	- 仅存在常规任务 → 按计划开始时间排序展示。
	- 无待办任务 → 展示空任务状态和交车引导。
2.  驾驶员选中某任务时，地图上显示该任务路线信息（在地图上绘制蓝色虚线表示计划路段信息），卡片变为该任务的详细信息，有以下按钮：
	- 导航按钮：以小图标按钮呈现，点击后调用高德地图 API 进行外部导航；
	- 开始任务：点击后进入需要校验是否满足开始任务条件。满足条件后，进入任务执行
		- 校验车辆的位置是否在路段范围
		- 是否有其他正在执行的任务
3. 任务执行状态下，地图上显示任务的计划路线信息（蓝色虚线）和车辆的实际移动轨迹（红色实线），原型中当前执行任务使用约 25 个计划路线点和 26 个实际轨迹点，轨迹需覆盖较长路段并带适度曲折，避免呈现为单一斜向直线；实际轨迹可与计划路线存在轻微不一致，用于模拟绕行、偏离或现场作业偏差。车辆位置点按 1.8 秒/点的演示间隔沿实际轨迹移动，并同步刷新车辆标记位置、覆盖度、已作业时长和红色实际轨迹；起点和终点图标需贴合计划路线两端，并通过折线路径布局避开地图上方 banner 遮挡。底部卡片显示执行中的任务信息（作业路段、计划时间、作业要求、已作业时间、路线覆盖度），有以下按钮：
	- 结束任务：主按钮，点击后进行未完成事项校验，通过后结束任务，未通过则无法结束
	- 任务详情：弱化为次要文字或小按钮，查看详细要求，不作为主操作
4. 司机收到动态任务提醒：
   - 轻提醒 → 地图上方 banner 提示，宽度与顶部车牌信息卡一致，信息靠左排列，右侧固定“查看”按钮；内容格式为“新动态任务 任务名称-距离 查看”，支持快捷跳转并查看动态任务；动态任务同步进入底部待办任务列表，任务卡片支持导航、开始任务、结束任务
5. 司机点击辅助按钮 → 打开水电油上报类型选择器、一键报修弹窗或交车检查弹窗/抽屉。
### 5.3 F03 任务详情与执行抽屉
#### 5.3.1 页面布局

#### 5.3.4 交互流程
1. 司机在底部抽屉点击“展开任务”查看今日任务列表；列表展开后按钮文案变为“收起任务”，再次点击或点击列表内“收起任务”可收起列表。
2. 司机点击任务卡片 → 地图显示该任务路线、起终点和当前位置。
3. 任务卡片内展示导航图标按钮；司机点击后调用高德地图导航 API，跳转外部地图导航至任务路段，不在 APP 内承载导航过程。
4. 当被查看任务处于未开始状态时，底部当前任务卡片下方展示“开始任务”主按钮；任务详情按钮弱化为次要文字/小按钮。
5. 司机点击”开始任务”：
   - 校验成功 → 任务状态变为”执行中”，开始采集实际轨迹；若开始前任务列表处于展开状态，则自动收起列表，仅展示当前执行任务（聚焦作业注意力，避免多任务视觉干扰）。
   - 校验失败 → 展示定位或时间校验原因。
6. 执行中系统持续展示实际轨迹和异常提醒。
7. 司机完成作业后点击“结束任务”：
   - 校验通过 → 当前任务状态变为“已完成”，记录路线覆盖度、时间校验和异常信息。
   - 存在阻断项 → 提示具体阻断原因，任务保持执行中。
8. 当前任务结束后，系统自动检查下一条待办任务：
   - 存在下一任务 → 自动选中并推送下一任务卡片，展示“开始任务”按钮。
   - 无下一任务 → 展示返场交车提示。

### 5.6 F06 结束任务校验与推送
#### 5.6.1 页面布局

2. **结束任务按钮**：执行中任务展示主按钮“结束任务”。
3. **校验反馈区**：点击结束任务后，以 Toast、轻提示或卡片内提示展示校验结果。

#### 5.6.2 数据展示字段

   - 存在下一任务 → 自动推送下一任务卡片。

| -------- | -------- | -------- |
| 当前无绑定车辆 | 当前无可交车辆 | 阻断交车 |
| 存在进行中未结束任务 | 存在未结束任务，无法交车，请结束任务或异常关闭 | 阻断交车，并在地图工作台高亮该任务 |
| 仅存在未开始任务或无未完成任务 | —— | 允许交车，进入二维码交车 |

#### 5.7.4 交互流程
交车检查可从地图工作台右侧工具组、任务全部完成后的提示或底部抽屉进入：
1. 点击交车按钮，系统先进行校验，看是否存在未完成任务
	- 如果有未完成任务，toast提示存在未结束任务，无法交车，请结束任务或异常关闭，地图工作台待办任务高亮显示该任务（如果有未开始的任务，支持交车）
	- 如果任务均完成，则调用个人二维码页面，支持车端扫描司机的二维码或者司机扫描车端的二维码，完成交车（解除司机与车辆的使用关系）
2. 交车完成后，页面自动跳转今日回顾+明日待办页
	- 今日回顾：展示任务完成数、轨迹里程、出车时长、水电油上报数、报修数
	- 明日待办：以卡片形式展示明日的任务；如无，则显示暂无明日待办任务
#### 5.7.5 二维码交车与页面规格

> 本期取消「交车检查弹窗」，改为二维码交车 + 今日回顾页。

| 环节 | 规格 |
| ---- | ---- |
| 交车入口 | 地图工作台右侧工具组「交车」按钮，点击先做前置校验 |
| 阻断反馈 | 存在进行中未结束任务时，toast 提示并高亮该待办任务，不进入二维码 |
| 二维码交车 | 复用个人二维码页面（scene=handover），支持车端扫司机码 / 司机扫车端码 |
| 成功反馈 | 扫码成功 toast「交车成功，已解除人车绑定」，随后跳转今日回顾页 |
| 今日回顾页 | 顶部交车成功横幅 + 今日回顾 5 项指标 + 明日待办卡片/空态 + 返回首页 |

## 6 业务规则汇总
### 6.1 今日用车入口分流规则

| 当前状态 | 系统行为 |
| -------- | -------- |
| 司机已绑定车辆且车辆可用 | 进入地图工作台 |
| 司机未绑定车辆 | 展示未绑定引导，不进入地图工作台 |
| 绑定关系失效 | 提示重新绑定车辆 |
| 车辆不可用 | 展示不可用原因，不进入地图工作台 |

### 6.2 本期二维码能力边界

| 规则项 | 说明 |
| ------ | ---- |
| 独立司机二维码 | 本期不建设独立入口、独立页面或个人中心展示能力 |
| 未绑定引导 | 仅提示司机需要完成车辆绑定，并可跳转或唤起既有绑定/扫码能力 |
| 外部扫码能力 | 如车辆端扫码司机二维码由其他系统提供，本模块仅接收绑定结果并重新校验 |
| 页面验收 | 不验收司机展示二维码页面、动态码刷新、二维码有效期等能力 |

### 6.3 人车绑定与可用性规则

| 场景 | 规则 |
| ---- | ---- |
| 无绑定车辆进入今日用车 | 阻断进入地图工作台，提示先绑定 |
| 已绑定车辆进入今日用车 | 查询车辆可用状态，可用则进入地图工作台 |
| 车辆已被他人绑定 | 不允许当前司机使用 |
| 当前司机已绑定其他车辆 | 不允许自动换车，需先完成原车辆交车 |
| 车辆故障未修复或维修中 | 不允许进入今日用车主流程 |
| 年检/保险/牌照到期 | 按车辆不可用处理，接车或进入今日用车时强拦截 |

### 6.4 状态流转规则

```text
未绑定
  -> 今日用车校验
      -> 未绑定：展示引导
      -> 已绑定且可用：进入地图工作台
地图工作台
  -> 查看任务
  -> 可选调用高德地图导航
  -> 开始任务
  -> 执行任务
      -> 动态任务/异常提醒/水电油上报/一键报修
  -> 结束任务
      -> 有下一任务：推送下一任务
      -> 无下一任务：引导返场交车
  -> 交车（前置校验）
      -> 存在进行中未结束任务：toast 提示 + 高亮待办，不可交车
      -> 仅未开始任务或无未完成任务：进入二维码交车 -> 扫码成功解除绑定 -> 今日回顾+明日待办页
```

### 6.5 任务执行规则

| 规则项 | 说明 |
| ------ | ---- |
| 任务优先级 | 执行中任务优先，其次应急任务，其次常规任务 |
| 任务查看 | 司机点击任务卡片后，地图切换至该任务路线，卡片展示开始任务、导航图标和弱化任务详情入口 |
| 外部导航 | 司机点击导航图标后调用高德地图 API，不在 APP 内承载导航过程 |
| 开始任务 | 需校验车辆位置是否在任务路段范围，计划时间校验按项目配置 |
| 执行任务 | 实时上传位置、速度、轨迹等数据至环卫云平台；原型中当前执行任务使用约 25 个计划路线点和 26 个实际轨迹点表现较长、曲折路线，实际轨迹可与计划路线存在轻微偏离，演示动效按 1.8 秒/点推进 |
| 结束任务 | 在地图工作台内校验路线覆盖度、时间完成情况和动态任务闭环状态，校验通过后直接结束 |
| 任务推送 | 上一任务结束后自动检查并推送下一任务 |

### 6.6 动态任务规则

| 规则项 | 说明 |
| ------ | ---- |
| 触发来源 | 摄像头识别、调度派发、异常事件等 |

### 6.7 异常监控规则

| 异常大类 | 异常事件 | 司机端处理 | 管理端处理 |
| -------- | -------- | ---------- | ---------- |

| 使用异常 | 车辆长时间未交车 | 提醒交车 | 推送项目经理核查 |

| 安全异常 | 超速、限行区行驶 | 强提醒自纠 | 多次可推送项目经理核查 |

## 10 验收标准
### 10.1 F01 今日用车入口校验与未绑定引导验收
- [ ] 城市管家首页或工作台存在“今日用车”入口。
- [ ] 点击“今日用车”后系统校验司机绑定状态。
- [ ] 已绑定车辆且车辆可用时进入地图工作台。
- [ ] 未绑定车辆时展示“暂未绑定车辆”提示。
- [ ] 未绑定状态下不展示地图工作台。
- [ ] 未绑定状态提供“去绑定车辆”引导。
- [ ] 车辆不可用时展示具体原因，不进入地图工作台。
- [ ] 本模块不出现独立司机展示二维码入口或页面。
### 10.2 F02 地图工作台验收
- [ ] 地图为页面主体，展示当前车辆位置。
- [ ] 地图视觉参照执行态控制台示意，包含仿地图底图、蓝色计划路线、红色实际轨迹、起终点、异常点、动态任务点和顶部车辆状态卡；起点和终点图标贴合计划路线两端。
- [ ] 底部展示待办任务抽屉，支持展开和收起。
- [ ] 当前任务栏任务列表触发按钮默认展示“展开任务”，展开后展示“收起任务”。
- [ ] 任务列表展开后，地图车辆图标不得覆盖在任务面板上方。
- [ ] 选中任务后地图展示对应任务路线和目标点。
- [ ] 执行中任务展示实时轨迹，车辆标记可沿实际轨迹持续移动，实际轨迹允许与计划路线存在轻微偏离，并同步刷新覆盖度和已作业时长。
- [ ] 右侧或地图上提供水电油、报修、交车等辅助按钮。
- [ ] 无今日任务时展示空任务状态和交车引导。
- [ ] 行驶中收到系统派发动态任务时，地图上方展示轻提醒 banner，点击可打开待办列表并高亮该“动态”任务。
- [ ] 异常或动态任务推送时地图和任务抽屉能高亮提示。
### 10.3 F03 任务详情与执行抽屉验收
- [ ] 任务列表展示任务名称、类型、计划时间、作业路段和状态。
- [ ] 执行中任务优先展示，应急任务优先级高于常规任务。
- [ ] 司机点击任务卡片后，地图可切换到该任务路线、起终点和当前位置。
- [ ] 未开始任务卡片下方展示“开始任务”主按钮。
- [ ] 任务卡片内提供导航小图标按钮，点击后调用高德地图 API。
- [ ] 开始任务前校验定位是否在任务路段范围。
- [ ] 执行中持续展示任务状态、实际移动轨迹和异常提醒。
- [ ] 任务详情入口弱化为次要文字或小按钮。
- [ ] 点击结束任务后在地图工作台内完成未完成事项校验，不跳转单独结束任务确认页。
### 10.4 F04 水电油上报跳转验收
- [ ] 地图工作台可打开水电油上报类型选择器。
- [ ] 类型选择器展示加油、加水、充电三个入口。
- [ ] 选择加油后跳转既有加油上报页。
- [ ] 选择加水后跳转既有加水上报页。
- [ ] 选择充电后跳转既有充电上报页。
- [ ] 从地图工作台跳转目标上报页时带入当前车辆 ID、车牌号和返回地址。
- [ ] 目标上报页车辆字段默认填充当前绑定车辆且原则上不可修改。
- [ ] 加水支持填写水量、估算水费和当前里程。
- [ ] 充电支持填写充电量、单价、费用、当前里程和充电完成时间。
- [ ] 加油支持填写加油量、单价、费用、当前里程和加油时间。
- [ ] 必填项未填写时不允许提交。
- [ ] 目标上报页提交成功后返回地图工作台。
- [ ] 当前车辆信息缺失或失效时，目标上报页禁止提交并提示重新进入今日用车。
### 10.5 F05 一键报修弹窗验收
- [ ] 地图工作台可打开一键报修弹窗。
- [ ] 报修弹窗默认带入当前车辆和当前位置。
- [ ] 支持选择故障影响程度。
- [ ] 支持填写故障类型、故障描述、是否现场维修、期望维修时间。
- [ ] 提交成功后创建售后维修工单。
- [ ] 不同故障影响程度对应不同主流程提示。
### 10.6 F06 结束任务校验与推送验收
- [ ] 点击结束任务后展示任务完成校验结果。
- [ ] 展示路线覆盖度、时间校验、动态任务闭环和异常记录。
- [ ] 存在阻断项时不可结束任务。
- [ ] 仅存在提醒项时司机确认后可结束并记录异常。
- [ ] 任务结束后自动检查下一任务。
### 10.7 F07 交车与今日回顾验收
- [ ] 地图工作台「交车」按钮可发起交车。
- [ ] 存在进行中未结束任务时不可交车，toast 提示并高亮该待办任务。
- [ ] 仅存在未开始任务或无未完成任务时允许交车。
- [ ] 允许交车后进入个人二维码页面（车端/司机端双向扫码）。
- [ ] 扫码成功后解除人车绑定并跳转今日回顾+明日待办页。
- [ ] 今日回顾展示完成任务数、轨迹里程、出车时长、水电油上报数、报修数。
- [ ] 明日待办以卡片展示，无任务时展示"暂无明日待办任务"。
### 10.8 业务规则验收
- [ ] 进入今日用车时必须校验绑定状态。
- [ ] 未绑定时只能引导绑定，不进入地图工作台。
- [ ] 本期不验收独立司机二维码展示能力。
- [ ] 任务执行异常仅在任务执行期间校验计划路线和实际轨迹。
- [ ] 水电油上报和一键报修可在任务期间穿插处理。
- [ ] 存在进行中未结束任务时不允许交车。

## 11 附录 A：统一组件规范
### 11.1 A.1 移动端顶部状态栏组件

| 配置项 | 规则 |
| ------ | ---- |
| 高度 | 约 64px，可根据状态信息在 60-72px 内微调 |
| 内容 | 返回/关闭入口、车辆图标（跨两行高度）、车牌号、车型、今日任务数、已完成数、车辆状态 |
| 信息层级 | 车牌号为主信息；车型、今日任务数、已完成数为副信息（同一行展示）；车辆图标跨两行高度强化视觉锚点；状态使用带圆点的浅底标签，垂直居中于信息栏 |
| 背景 | 可半透明悬浮于地图上，需保证文字对比度；建议使用白色半透明磨砂浮层和 12px 圆角 |
| 点击区 | 图标按钮点击区不小于 32px |

### 11.2 A.2 地图标记组件

| 类型 | 规则 |
| ---- | ---- |
| 当前位置 | 蓝色定位点，支持方向指示 |
| 计划路线 | 蓝色虚线 |
| 任务起点 | 绿色定位图标，使用已选定的起点 SVG |
| 实时轨迹 | 红色实线 |
| 异常点 | 红色标记，点击展示异常摘要 |
| 动态任务点 | 橙色或高亮标记，优先级高于常规任务点 |

### 11.3 A.3 底部抽屉组件

| 配置项 | 规则 |
| ------ | ---- |
| 状态 | 收起、半展开、全展开 |
| 手势 | 支持上滑展开、下滑收起 |
| 圆角 | 顶部圆角 |
| 遮挡规则 | 半展开时不得遮挡当前车辆位置和主路线关键点 |
| 使用场景 | 待办任务、任务详情、执行状态 |
