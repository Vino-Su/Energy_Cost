| 名词/缩写 | 解释                                      |
| ----- | --------------------------------------- |
| 今日用车  | 司机在城市管家 APP 中开始当天车辆使用与任务执行的主入口          |
| 地图工作台 | 以地图为主体承载待办任务、导航路线、实时轨迹、异常提醒和辅助操作的司机工作界面 |

| 阻断项   | 未处理前不允许继续执行关键动作的事项，如未结束任务、车辆不可用         |
| 提醒项   | 需要提示司机关注但不强制阻断当前动作的事项，如异常待确认、照片待补充      |

## 3 业务背景与使用角色
### 3.1 业务背景
- 模块定位：今日用车地图工作台是车辆使用过程监管方案在司机端 APP 的主流程承载模块，用于把接车状态、任务执行、轨迹导航、动态任务、异常提醒、水电油上报、故障报修、结束任务和交车收口串联到一个以地图为核心的工作界面。
- 核心特点：司机打开 APP 后进入“今日用车”，系统先校验司机是否已绑定车辆；已绑定则直接进入地图工作台，未绑定则展示未绑定提示并引导完成车辆绑定；本期不建设单独司机展示二维码页面或入口。
- 业务痛点：原车辆使用动作分散在多个功能中，司机需要自行查找任务、报修、补给等入口；管理侧难以稳定追踪人车关系、任务路线、轨迹偏差、异常响应和交车闭环。
- 关联模块关系：模块从 basis 平台读取车辆信息，从环卫云平台读取常规任务、动态任务、轨迹和异常记录，从售后平台同步维修工单，从能耗成本模块复用水电油上报能力。
### 3.2 使用角色

| 角色       | 该模块中的职责                                                                | 客户端       |
| -------- | ---------------------------------------------------------------------- | --------- |
| 作业车辆驾驶员  | 进入今日用车、完成绑定状态校验、查看地图工作台、查看任务、调用外部地图导航、开始/结束任务、处理动态任务、上报水电油、发起故障报修、完成交车 | 移动端 APP   |
| 项目经理/管理员 | 查看异常记录、核查车辆使用异常、处理合规异常、调整任务或维修资源                                       | 管理端/环卫云平台 |
| 系统服务     | 判断绑定状态、同步车辆可用性、聚合任务待办、接收轨迹数据、生成异常记录、保存接车/交车留痕                          | 后端服务      |

### 3.3 核心目标与价值

| 目标维度   | 说明                                 |
| ------ | ---------------------------------- |
| 司机操作效率 | 将司机高频工作收敛到地图工作台，减少多入口跳转和学习成本       |
| 主流程清晰  | 形成“今日用车校验 - 地图任务 - 结束任务 - 交车”的稳定路径 |

### 5.1 F01 今日用车卡片

#### 5.1.3 前置校验

	- 如果已绑定车辆，卡片右侧显示绑定的车辆牌照
	- 如果未绑定车辆，卡片右侧显示：“当前未绑定车辆”

	- 已绑定但车辆不可用 → 展示不可用原因，不进入地图工作台。
4. 未绑定引导弹窗展示内容：
	- 提示文字
	- 去绑定车辆：唤起既有绑定/扫码能力 → 绑定完成后重新校验并进入地图工作台。
	- 关闭：点击后关闭引导页。

### 5.2 F02 地图工作台
#### 5.2.1 页面布局

地图工作台为司机已绑定车辆后的主页面，页面自上而下/由外到内分为 6 个区域：

1. **地图主体区**：全屏或近全屏展示地图，显示车辆当前位置、任务路线、实时轨迹、目标点、异常点和动态任务点；动态任务派发后，任务点可点击并与今日任务列表中的同一任务保持选中联动；高保真原型采用内置 SVG/CSS 仿地图底图承载路线与车辆移动，真实开发可按地图供应商能力替换底图层。
2. **顶部状态栏**：以车辆执行状态条呈现，展示返回入口、车牌号主信息、车型/今日任务副信息、车辆状态。
3. **右侧悬浮工具组**：按顺序提供定位回正、图层、水电油上报、故障报修、交车等 5 个快捷操作，固定显示在地图右侧悬浮区域，按钮排列顺序自上而下依次为：复位、图层、水电油上报、故障报修、交车。
4. **底部待办任务抽屉**：默认半展开，展示当前任务、待办任务和任务状态；上滑展开完整待办列表。
5. **任务执行状态条**：进行中展示任务进度、已作业时长、路线覆盖提示和结束任务按钮。
6. **消息提醒层**：用于展示动态任务推送、异常播报、强提醒和轻提示；行驶中系统派发的新任务以地图上方 banner 轻提醒呈现，宽度与顶部车牌信息卡一致，信息靠左排列，右侧固定“查看”按钮，内容格式为“新动态任务 任务名称 - 距离 查看”，点击后聚焦对应待办任务。

#### 5.2.4 交互流程

**当日有待办任务**

1. 进入地图工作台后，此时还未开始任务，底部显示任务卡片，默认显示该车辆 + 该司机时间排序在第一位的任务，当前车辆地图中默认显示当前车辆位置 + 该任务计划路线，任务卡片支持拉起显示全部今日待办任务（可覆盖地图，也支持收起），也可以通过点击右侧“展开任务”达到相同的效果。清单中进行中任务优先，其次依次展示应急任务、动态任务、常规任务；已完成任务统一移动至列表底部。
	- 存在进行中任务 → 默认选中进行中任务。
	- 存在动态任务 → 动态任务优先展示，排在执行者任务后。
	- 仅存在常规任务、应急任务 → 按计划开始时间排序展示。
	- 无待办任务 → 展示空任务状态和交车引导。
2.  驾驶员选中某任务时，地图上显示该任务计划路线信息，卡片变为该任务的详细信息，任务卡片按任务类型分两套字段展示（与需求 6.2.1 对齐）：
	- 常态任务/临时任务（常规、应急任务）：
		- 第 1 行：路线名称 - 任务状态 + 任务详情
		- 第 2 行：任务车牌号 - 任务类型 - 作业类型 - 计划时间段
		- 第 3 行（横排）：开始任务时间（HH:MM） · 作业里程（单位 km，保留 2 位小数，开始任务时间至当前轨迹长度） · 作业时长（单位 min，保留整数，当前时间 - 开始任务时间）
	- 动态任务：
		- 第 1 行：问题地点 - 任务状态 + 任务详情
		- 第 2 行：任务车牌号 - 任务类型 - 问题类型 - 派发时间
		- 第 3 行（横排）：开始任务时间（HH:MM） · 作业里程（单位 km，保留 2 位小数） · 作业时长（单位 min，保留整数）
	- 待开始任务：第 3 行的开始任务时间、作业里程、作业时长统一占位为「-」。
	- 卡片有以下按钮：
	- 导航按钮：以小图标按钮呈现，点击后调用高德地图 API 进行外部导航；
	- 开始任务：点击后进入需要校验是否满足开始任务条件。满足条件后，进入任务执行
		- 校验车辆的位置是否在路段范围：若不通过，toast 提示“当前车辆距离任务路段过远”
		- 是否有其他正在执行的任务：若不通过，toast 提示“请先结束当前任务”，任务卡片跳转为正在进行中的任务
	- 详情：次按钮，查看详细要求，不作为主操作
	- 更多按钮：点击后显示暂停任务、转派任务、关闭任务按钮
		- 暂停任务：将当前正在进行中的任务暂停，在此状态下，用户可以开始执行其他任务
		- 转派任务：将当前选中的任务转派给其他司机/车辆执行
		- 关闭任务：将选中的任务予以关闭
3. 任务执行状态下，地图上显示任务的计划路线信息（蓝色虚线）和车辆的实际移动轨迹（红色实线）。车辆位置点实时刷新，并更新作业里程、已作业时长。底部卡片显示进行中的任务信息（作业路段、计划时间、已作业时间、作业里程），有以下按钮：
	- 结束任务：主按钮，点击后进行未完成事项校验，通过后结束任务，未通过则无法结束
	- 任务详情
	- 导航
4. 司机收到新任务提醒：
   - 轻提醒 → 地图上方 banner 提示，宽度与顶部车牌信息卡一致，信息靠左排列，右侧固定“查看”按钮；
   - 内容格式为“新动态任务 任务名称 - 距离 查看”，支持快捷跳转并查看动态任务
   动态任务同步进入底部待办任务列表，任务卡片支持导航、开始任务、结束任务；地图同步展示动态任务点和图例，司机点击该点后，结果等同于在今日任务列表中选中同一动态任务：更新当前任务卡片与地图路线、展开任务列表并高亮对应任务。
5. 司机点击辅助按钮 → 打开水电油上报类型选择器、故障报修弹窗或交车检查弹窗
6. 司机点击「图层」按钮 → 工具按钮进入激活态，地图上叠加渲染全部 8 类 POI 标记，顶部出现分类筛选条（默认全部选中）。司机通过筛选条可独立切换每类 POI 的显隐。司机点击地图上任一 POI 标记 → 地图自动放大并将该点位居中，底部弹出该类型对应的信息详情弹窗（按 §5.2.2 辅助设施字段表渲染），司机可在详情弹窗内发起导航至该位置，或根据 POI 类型联动水电油上报、故障报修。关闭详情弹窗后，地图视角回到点击前的状态
### 5.3 F03 任务详情与执行抽屉
#### 5.3.1 页面布局

任务详情与执行抽屉承载在地图底部，按任务状态展示不同内容：

1. **收起态**：展示任务名称、时间、状态和主按钮。
2. **半展开态**：展示任务路线、开始时间、作业里程、作业时长、导航按钮和任务操作。
3. **全展开态**：任务抽屉展示完整当日任务列表，支持切换任务；展开后地图车辆图标层级低于任务面板，不得浮在面板上方。
4. **执行态**：展示执行进度、实际轨迹、路线覆盖提示、异常提醒和结束任务按钮。

**任务清单入口唯一标题规则（V1.8 起）：**
- 入口按钮承担"任务清单分组标题"职责，是页面内任务清单的唯一标题。文案固定为「今日任务」+「N 项」：收起态 N 为待办任务数（不含已完成），展开态 N 为今日任务总数。
- 任务清单面板头部（位于入口按钮正下方）不再展示重复的"今日任务"标题与任务总数；改为状态分布统计行，固定三段：🟠 待开始 N · 🔵 进行中 N · 🟢 已完成 N，颜色圆点与各状态色保持一致；进行中为 0 时该段隐藏不展示，避免冗余占位。
- 入口点击与抽屉把手上滑/下滑手势共用同一开关状态，规则见 5.3.4。
#### 5.3.2 数据列表区

| 序号 | 任务类型 | 左侧第一行 | 左侧第二行 | 最右侧 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 1 | 常规任务 | 路线名称 + 任务类型 | 路段 + 作业时间 | 任务状态 | 任务类型使用独立标签；状态枚举值：待开始、进行中、已完成、异常关闭 |
| 2 | 应急任务 | 路线名称 + 任务类型 | 路段 + 作业时间 | 任务状态 | 应急任务类型使用错误色浅底标签，但不得替代任务状态 |
| 3 | 动态任务 | 问题类型 + 问题重要程度 + 任务类型 | 问题地点 | 任务状态 | 动态任务类型使用警告色浅底标签；问题地点超长时单行省略 |

**排序规则：**

1. 已完成任务统一排列在所有未完成任务之后；多条已完成任务保持原业务顺序。
2. 未完成任务中，进行中任务优先，其次依次为应急任务、动态任务、常规任务。
3. 同类型待开始任务按计划开始时间升序；无明确计划时间的任务保持原业务顺序。
4. 动态任务派发进入清单、任务开始或结束后，立即按上述规则重新排序。

#### 5.3.3 前置校验

| 校验条件 | 提示信息 | 阻断操作 |
| -------- | -------- | -------- |
| 开始任务时当前司机未绑定车辆 | 请先绑定车辆后再开始任务 | 阻断开始，toast 后跳转**车辆绑定二维码页**（`qrcode.html?scene=bind&returnUrl=vehicle-management.html`） |
| 开始任务时当前车辆与任务分配车辆不一致 | 当前车辆与任务分配车辆不一致，请检查 | 阻断开始，打开**更换车辆确认弹窗**（见 5.3.4 第 5 步） |
| 开始任务时定位不在任务路段范围 | 当前未到达任务路段，暂不可开始 | 阻断开始 |
| 开始任务时不在计划时间窗口 | 当前不在计划任务时间内，请确认后再开始 | 按项目规则提醒或阻断 |
| 存在进行中任务时开始另一任务 | 请先结束当前任务 | 阻断新任务开始 |

#### 5.3.4 交互流程
1. 司机点击任务抽屉的轻量入口，或在抽屉把手区域上滑，查看今日任务列表；列表展开后，再次点击入口或在把手区域下滑可收起。入口仅切换任务清单，不改变当前选中任务；展开后入口按钮作为唯一标题，文案固定为「今日任务 共 N 项」，面板头部改为状态分布统计。每张任务卡片按任务类型展示差异化字段，任务类型显示在左侧内容区，任务状态统一固定在卡片最右侧。
2. 司机点击任务卡片 → 地图显示该任务路线、起终点和当前位置；司机点击已派发动态任务的地图点位 → 执行同一任务选中流程，展开任务列表并高亮对应动态任务。
3. 任务卡片内展示导航图标按钮；司机点击后调用高德地图导航 API，跳转外部地图导航至任务路段，不在 APP 内承载导航过程。
4. 当被查看任务处于未开始状态时，底部当前任务卡片下方展示“开始任务”主按钮；详情按钮弱化为次要文字/小按钮。
5. 司机点击”开始任务”：
   - 未绑定车辆 → Toast 提示”请先绑定车辆后再开始任务”，约 1.2 秒后跳转车辆绑定二维码页（`qrcode.html?scene=bind&returnUrl=vehicle-management.html`）；扫码绑定成功后回到地图工作台重新校验。
   - 当前车辆与任务分配车辆不一致 → 打开**更换车辆确认弹窗**（居中卡片）：
     - 提示文字「当前车辆与任务分配车辆不一致，请检查」，并对照展示「当前车辆」与「任务车辆」两个车牌；
     - 「关闭」→ 关闭弹窗，不进入下一步；
     - 「申请更换本车执行」→ 将当前任务的实际执行车辆变更为本车（后台记录该变更），Toast 反馈「已更换为本车执行，变更已记录」，关闭弹窗后立即继续后续校验（在线、位置）并通过则进入执行；
   - 校验成功 → 任务状态变为”进行中”，开始采集实际轨迹；若开始前任务列表处于展开状态，则自动收起列表，仅展示当前执行任务（聚焦作业注意力，避免多任务视觉干扰）。
   - 校验失败 → 展示定位或时间校验原因。
6. 进行中系统持续展示实际轨迹和异常提醒。
7. 用户点击“任务详情”，打开对应任务详情页面
8. 司机完成作业后点击“结束任务”：
   - 校验通过 → 当前任务状态变为“已完成”，记录作业里程、时间校验和异常信息。
   - 存在阻断项 → 提示具体阻断原因，任务保持进行中。
8. 当前任务结束后，系统自动检查下一条待办任务：
   - 存在下一任务 → 自动选中并推送下一任务卡片，展示“开始任务”按钮。
   - 无下一任务 → 展示返场交车提示。

### 5.6 F06 结束任务校验与推送
#### 5.6.1 页面布局

4. **下一任务推送区**：结束成功后自动选中下一条待办任务；无下一任务时展示返场交车提示。

#### 5.6.4 交互流程
1. 司机在进行中任务卡片点击“结束任务”。
2. 系统校验作业里程、时间完成情况、动态任务闭环状态和阻断项：
   - 校验成功 → 任务状态变为“已完成”，Toast 提示“任务已结束”。
   - 存在提醒项 → 记录提醒项，允许结束任务。

3. 系统检查是否存在下一待办任务：
   - 存在下一任务 → 自动推送下一任务卡片。
   - 无下一任务 → 展示可返回场地并交车的提示。

#### 5.7.4 交互流程

交车检查可从地图工作台右侧工具组、任务全部完成后的提示或底部抽屉进入：

1. 点击交车按钮，系统先进行校验，看是否存在未完成任务
	- 如果有未完成任务，toast 提示存在未结束任务，无法交车，请结束任务或异常关闭，地图工作台待办任务高亮显示该任务（如果有未开始的任务，支持交车）
	- 如果任务均完成，则调用个人二维码页面，支持车端扫描司机的二维码或者司机扫描车端的二维码，完成交车（解除司机与车辆的使用关系）
2. 交车完成后，页面自动跳转今日回顾 + 明日待办页

	- 明日待办：以卡片形式展示明日的任务；如无，则显示暂无明日待办任务；V1.5 起每条任务支持点击查看详情（见 5.7.8）

##### 5.7.6.3 未完成状态枚举与排序

| 状态枚举 | 中文标签 | 颜色规范 | 排序优先级 |
| -------- | -------- | -------- | ---------- |
| pending | 待开始 | 浅蓝 #e6f4ff / 主色 #1677ff | 2 |
| running | 进行中 | 浅绿 #f6ffed / 成功 #52c41a | 1（最高） |
| abnormal | 异常关闭 | 浅红 #fff1f0 / 错误 #ff4d4f | 3（最低） |

**排序规则：**

1. 分组内任务按"进行中 → 待开始 → 异常关闭"优先级排序；
2. 同状态任务按计划开始时间升序排列；
3. 计划开始时间为空的任务保持原业务顺序。

#### 5.8.4 交互流程

1. 司机在地图工作台点击右侧工具栏「图层」按钮 → 底部弹出辅助设施图层控制弹窗。
2. 弹窗内容：
   - 标题「辅助设施图层」+ 当前筛选结果摘要 + 关闭按钮
   - 站点类型：全部站点、自营站点、协议站点、其他站点，默认全部站点
   - 设施类型：全选与 8 类复选列表
   - 8 类复选列表：每行显示类型图标 + 类型名称 + 「共 N 个」+ 复选框；点击行整体可切换复选状态
   - 当前任务最小摘要，司机可返回任务控制台
3. 司机在弹窗内操作：
   - 全选切换 → 8 类复选同步全选/全不选；部分选择时点击全选恢复全部选择
   - 单类复选切换 → 仅该类显隐变化并立即更新地图；至少一类选中时工具栏「图层」按钮进入激活态
   - 选择自营站点、协议站点或其他站点 → 地图仅保留当前已选类别中站点类型匹配的点位；选择“全部站点” → 恢复当前已选类别中的全部站点
   - 关闭面板 → 保留当前选择并回到任务控制台
4. 司机点击地图上任一 POI 标记：
   - 地图自动放大并将该 POI 居中
   - 打开对应类型的信息详情；在站点名称后展示对应的站点类型标签，并依次呈现位置、相对距离、关键能力与其余字段
5. 司机在详情弹窗内可执行：
   - 导航 → 调起高德地图外部导航至该 POI 位置（所有类型均支持）
   - 联动操作 → 清水补给点/加油站/充电点联动对应水电油上报；维修点联动故障报修；其他设施等其余类型无联动按钮
6. 司机关闭详情弹窗：
   - 弹窗收起
   - 地图视角平滑恢复到点击 POI 前的状态
   - 工具栏「图层」按钮保持激活态
7. 司机再次点击「图层」按钮 → 再次打开图层控制弹窗，可调整已选类型
8. 校验失败：地图工作台不可用时，「图层」按钮置灰不可点击。

#### 5.8.5 异常处理

| 异常场景 | 系统处理 | 用户反馈 |
| --- | --- | --- |
| 辅助设施 POI 数据为空 | 图层按钮置灰不可点击 | 按钮展示不可用态 |
| 辅助设施 POI 数据加载失败 | 图层按钮置灰不可点击 | 轻提示「辅助设施加载失败，请稍后重试」 |
| 详情弹窗打开时切换图层关闭 | 详情弹窗同步关闭，地图恢复当前车辆视角 | 无 |
| 详情弹窗打开时切换其他工具（上报、报修、交车） | 详情弹窗关闭后再打开目标面板 | 无 |
| 司机点击 POI 时网络异常 | 详情弹窗展示字段为本地缓存或占位 | 字段区域显示「加载失败，点击重试」 |
| 司机未绑定车辆时进入地图 Tab | 沿用 §5.2.3 未绑定态规则，「图层」按钮可用，仅影响 POI 标记的展示范围 | 无 |

#### 5.8.7 验收标准

1. 右侧工具栏自上而下依次显示：复位、图层、水电油上报、故障报修、交车
2. 点击「图层」按钮后，底部弹出辅助设施图层控制弹窗（与水电油上报类型选择弹窗风格一致）
3. 弹窗内按站点类型与设施类型分组；站点类型支持全部站点、自营站点、协议站点、其他站点单选，设施类型支持全选与 8 类复选列表（每行图标+名称+数量+复选框）
4. 任一筛选条件变化后，地图立即按站点类型与设施类型的交集更新 POI；至少一类设施选中时工具栏「图层」按钮进入激活态，关闭面板后选择结果保持
5. 8 类 POI 在地图上以独立色相的方形标识呈现，自营站点显示“自”角标，协议站点显示“协”角标，其他站点不显示角标
6. POI 标记位于任务路线、实时轨迹、起终点与车辆标记的下方，不遮挡上述关键元素
7. 点击任一 POI 后，地图自动放大并将该 POI 居中，底部弹出信息详情
8. 点位详情在名称后展示“自营站点”“协议站点”或“其他站点”标签；详情继续优先展示位置、相对当前车辆的距离和适用的关键能力，再按 §5.8.2 表展示适配车型、现场图片及其余字段，字段顺序、命名与口径与需求文档一致
9. 详情内始终可执行「导航」，点击后调起高德地图外部导航
10. 清水补给点/加油站/充电点详情底部包含对应水电油上报联动按钮；维修点详情包含故障报修联动按钮；其余类型不展示联动按钮
11. 关闭详情弹窗后地图视角恢复至点击 POI 前状态
12. POI 数据为空时「图层」按钮置灰；数据加载失败时给出轻提示
13. 图层控制弹窗与详情弹窗、底部任务抽屉互斥：一次仅展示其一
14. 图层控制或点位详情打开期间，当前任务最小摘要持续可见，司机可直接返回任务控制台

| ----------- | ---------------------- |

### 7.4 状态流转规则

```text
未绑定
  -> 今日用车校验
      -> 未绑定：展示引导
      -> 已绑定且可用：进入地图工作台
地图工作台
  -> 查看任务
  -> 可选调用高德地图导航
  -> 开始任务
  -> 执行任务
      -> 动态任务/异常提醒/水电油上报/故障报修
  -> 结束任务
      -> 有下一任务：推送下一任务
      -> 无下一任务：引导返场交车
  -> 交车（前置校验）
      -> 存在进行中未结束任务：toast 提示 + 高亮待办，不可交车
      -> 仅未开始任务或无未完成任务：进入二维码交车 -> 扫码成功解除绑定 -> 今日回顾+明日待办页
```

### 7.5 任务执行规则

| 外部导航  | 司机点击导航图标后调用高德地图 API，不在 APP 内承载导航过程                                                                |
| 开始任务  | 需校验车辆位置是否在任务路段范围，计划时间校验按项目配置                                                                      |
| 执行任务  | 实时上传位置、速度、轨迹等数据至环卫云平台；原型中当前执行任务使用约 25 个计划路线点和 26 个实际轨迹点表现较长、曲折路线，实际轨迹可与计划路线存在轻微偏离，演示动效按 1.8 秒/点推进 |
| 结束任务  | 在地图工作台内校验作业里程、时间完成情况和动态任务闭环状态，校验通过后直接结束                                                           |
| 任务推送  | 上一任务结束后自动检查并推送下一任务                                                                                |

### 7.6 动态任务规则

| 规则项 | 说明 |
| ------ | ---- |
| 触发来源 | 摄像头识别、调度派发、异常事件等 |
| 展示方式 | 地图上方 banner 轻提醒、地图高亮点位、底部任务抽屉置顶、语音播报；原型示例包含 1 条行驶中派发的动态任务 |
| 与主线关系 | 可作为常规任务中的插曲，处理后回到原常规任务 |
| 闭环机制 | 按“开始 - 执行 - 结束”处理，是否必须闭环见待确认项 |

### 7.7 异常监控规则

| 异常大类 | 异常事件 | 司机端处理 | 管理端处理 |
| -------- | -------- | ---------- | ---------- |
| 使用异常 | 车辆行驶未关联驾驶员 | 本模块在今日用车入口阻断未绑定使用 | 推送项目经理核查 |
| 使用异常 | 车辆长时间未交车 | 提醒交车 | 推送项目经理核查 |
| 合规异常 | 年检/保险/牌照到期 | 今日用车强拦截 | 推送管理处置 |
| 日检异常 | 行驶车辆未日检 | 提醒并记录 | 后台复核 |
| 任务异常 | 轨迹偏差、作业里程不足 | 轻微提醒，严重记录 | 任务完成复核 |
| 安全异常 | 超速、限行区行驶 | 强提醒自纠 | 多次可推送项目经理核查 |
| 停靠异常 | 超时停靠 | 提醒并记录 | 按项目规则处理 |
| 动态任务异常 | 未响应/未闭环 | 提醒处理 | 推送项目经理核查 |

### 7.8 水电油上报规则

| 类型 | 规则 |

| 加油 | 支持上传加油小票和里程照片，OCR 解析失败后允许手填 |
| 已绑定状态 | 从地图工作台跳转既有上报页时，必须带入当前车辆 ID、车牌号和返回地址 |

### 7.9 故障报修规则

| 故障影响 | 主流程处理 | 报修处理 |
| -------- | ---------- | -------- |
| 影响作业且无法自行返回 | 作业终止，等待维修 | 创建现场维修工单 |
| 影响作业但可自行返回 | 作业终止，引导导航至维修场地 | 创建维修工单 |
| 不影响作业 | 可继续任务 | 创建预约维修工单 |

### 7.10 交车规则

> 本期按「仅拦截未完成任务」处理：仅进行中未结束任务强阻断，其余不阻断交车。

| 事项类型 | 是否允许交车 | 处理方式 |
| -------- | ------------ | -------- |
| 进行中未结束任务 | 否 | 阻断交车，toast 提示并高亮该任务，要求先结束或异常关闭 |
| 未开始任务 | 是 | 不阻断交车 |
| 无未完成事项 | 是 | 解除人车绑定并生成今日回顾 |

### 7.11 留痕规则

| 轨迹采集 | 任务执行期间的时间、经纬度、速度、方向 |
| 水电油上报 | 类型、车辆、费用、里程、附件、提交时间 |
| 报修 | 故障类型、影响程度、位置、照片、工单状态 |
| 交车 | 司机、车辆、时间、位置、未完成事项、交车结果 |
### 人车关系校验规则
出现以下情况，视为车辆可用性校验失败，不建立司机与车辆的使用关系
- 当前车辆已与其他司机绑定
- 当前司机已与其他车辆绑定
也就是说同一时段内，一辆车只能与一个司机建立使用关系
