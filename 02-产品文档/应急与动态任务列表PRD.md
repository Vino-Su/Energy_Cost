## 名词解释
| 名词/缩写 | 解释 |
| ---------- | ---- |
| 应急任务 | 因突发污染、道路障碍或临时调度产生，需要驾驶员按时处置的任务 |
| 动态任务 | 作业过程中由智能识别、巡查或调度派发的问题处置任务 |
| 独立任务查询 | 从用车管理入口查询当前驾驶员名下任务，不以当前绑定车辆作为过滤条件 |
| 任务所属车辆 | 任务被分配执行的车辆，可能与驾驶员当前绑定车辆不同 |

## 1. 业务背景与使用角色
### 1.1 业务背景
- 模块定位：作为用车管理下应急任务、动态任务的独立查询入口，帮助驾驶员查看本人名下不同车辆关联的任务。
- 核心特点：独立任务查询按当前驾驶员过滤，允许结果包含多辆任务车辆；地图工作台仍按当前驾驶员与当前车辆共同过滤，两者数据范围不同。
- 业务痛点：应急任务与动态任务入口此前为占位状态，驾驶员无法脱离当前车辆查看本人全部任务，也无法识别每条任务对应的车辆。
- 关联模块关系：任务数据来自环卫云平台；任务详情复用任务详情模块；入口来自用车管理。
### 1.2 使用角色
| 角色 | 该模块中的职责 | 客户端 |
| ---- | ------------ | ------ |
| 作业车辆驾驶员 | 查询本人应急任务与动态任务，按状态和时间定位任务，查看任务所属车辆及详情 | 移动端 APP |
### 1.3 核心目标与价值
| 目标维度 | 说明 |
| -------- | ---- |
| 数据完整性 | 展示当前驾驶员名下跨车辆任务，避免只看到当前绑定车辆任务 |
| 任务识别 | 在列表和详情中明确任务所属车牌号，避免混淆车辆对象 |
| 分类查询 | 分别承载应急任务和动态任务，按各自业务字段展示关键信息 |
| 操作安全 | 独立查询详情仅供查看，不允许直接开始、结束或导航其他车辆任务 |

## 3. 功能详细设计
### 3.1 F09 应急任务查询
#### 3.1.1 功能目标与范围
| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 驾驶员查看本人全部应急任务及其所属车辆 |
| 使用角色 | 当前登录的作业车辆驾驶员 |
| 触发条件 | 驾驶员从用车管理进入应急任务 |
| 功能边界 | 包含查询、筛选、列表和只读详情；不包含任务执行操作 |
| 成功结果 | 返回符合驾驶员、状态和时间条件的应急任务 |
#### 3.1.2 使用条件与权限
| 角色 | 可执行操作 | 数据范围 | 前置条件 |
| ---- | ---------- | -------- | -------- |
| 作业车辆驾驶员 | 查询、切换状态、筛选时间、查看详情 | 当前驾驶员名下应急任务，不限制任务所属车辆 | 已登录且具备用车管理权限 |
#### 3.1.3 数据与字段规则
**输入与查询条件：**
| 字段/条件 | 业务含义 | 取值方式或数据来源 | 默认值 | 校验/匹配规则 |
| --------- | -------- | -------------------- | ------ | ------------- |
| 当前驾驶员 | 数据权限主体 | 当前登录账号 | 当前用户 | 必须匹配任务驾驶员标识 |
| 任务状态 | 任务当前阶段 | 用户选择 | 待开始 | 枚举值：待开始、进行中、已完成 |
| 时间范围 | 任务日期查询范围 | 用户选择 | 今天 | 支持今天、近7天、近30天、全部、自定义起止日期 |
**展示与输出字段：**
| 字段 | 业务含义 | 数据来源 | 格式/口径规则 | 空值处理 |
| ---- | -------- | -------- | ------------- | -------- |
| 任务名称 | 应急任务识别名称 | 环卫云任务数据 | 展示任务当前名称 | 空值显示“未命名任务” |
| 车牌号 | 任务所属车辆 | 任务车辆关系 | 展示任务分配车辆，不使用当前绑定车辆覆盖 | 未分配时显示“未分配车辆” |
| 任务状态 | 当前执行阶段 | 任务状态 | 枚举值：待开始、进行中、已完成 | 无状态按待开始处理并记录异常 |
| 任务日期 | 计划执行日期 | 任务计划 | YYYY-MM-DD | 空值显示“日期待确认” |
| 作业时间 | 计划执行时段 | 任务计划 | 起止时间 | 空值显示“时间待确认” |
| 路线名称 | 应急作业路线 | 任务路线 | 使用任务关联路线 | 空值显示“路线待确认” |
| 应急要求 | 处置要求和时限 | 任务要求 | 展示有效要求 | 空值显示“暂无补充作业要求” |
#### 3.1.4 业务规则与状态变化
| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| E01 | 加载列表 | 仅按当前驾驶员过滤，不按当前绑定车辆过滤 | 无 |
| E02 | 查看详情 | 详情显示被点击任务的驾驶员和所属车牌号 | 无 |
| E03 | 从独立列表进入详情 | 详情仅供查看，不提供任务执行操作 | 无 |
#### 3.1.5 交互流程
1. 驾驶员从用车管理进入应急任务。
2. 系统按当前驾驶员、默认状态和默认时间范围加载任务。
3. 驾驶员切换状态或时间范围，系统刷新任务列表和数量。
4. 驾驶员点击任务，系统打开对应只读详情并展示任务所属车辆。
5. 驾驶员返回后回到应急任务列表并可继续查询。
#### 3.1.6 异常处理
| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 无查询结果 | 当前条件无任务 | 展示空结果，不改变筛选条件 | 提示当前范围暂无对应任务 | 调整状态或时间范围 |
| 任务车辆缺失 | 任务未分配车辆 | 保留任务并标记未分配 | 显示“未分配车辆” | 等待调度分配车辆 |
| 任务不存在 | 详情任务已撤回或标识无效 | 不展示错误任务数据 | 提示任务不存在 | 返回应急任务列表 |
#### 3.1.7 外部依赖
| 依赖模块/服务 | 输入 | 输出 | 调用时机 | 失败处理 |
| ----------- | ---- | ---- | -------- | -------- |
| 环卫云平台 | 驾驶员标识、状态、时间范围 | 应急任务及车辆关系 | 加载或切换查询条件时 | 保留已加载结果并提示加载失败 |
| 任务详情模块 | 任务标识、来源、状态 | 只读任务详情 | 点击任务时 | 展示任务不存在并返回列表 |
### 3.2 F10 动态任务查询
#### 3.2.1 功能目标与范围
| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 驾驶员查看本人全部动态问题任务及其所属车辆 |
| 使用角色 | 当前登录的作业车辆驾驶员 |
| 触发条件 | 驾驶员从用车管理进入动态任务 |
| 功能边界 | 包含查询、筛选、列表、问题信息和只读详情；不包含任务执行操作 |
| 成功结果 | 返回符合驾驶员、状态和时间条件的动态任务 |
#### 3.2.2 使用条件与权限
| 角色 | 可执行操作 | 数据范围 | 前置条件 |
| ---- | ---------- | -------- | -------- |
| 作业车辆驾驶员 | 查询、切换状态、筛选时间、查看详情 | 当前驾驶员名下动态任务，不限制任务所属车辆 | 已登录且具备用车管理权限 |
#### 3.2.3 数据与字段规则
**输入与查询条件：**
| 字段/条件 | 业务含义 | 取值方式或数据来源 | 默认值 | 校验/匹配规则 |
| --------- | -------- | -------------------- | ------ | ------------- |
| 当前驾驶员 | 数据权限主体 | 当前登录账号 | 当前用户 | 必须匹配任务驾驶员标识 |
| 任务状态 | 任务当前阶段 | 用户选择 | 待开始 | 枚举值：待开始、进行中、已完成 |
| 时间范围 | 派发时间查询范围 | 用户选择 | 今天 | 按派发时间匹配今天、近7天、近30天、全部或自定义范围 |
**展示与输出字段：**
| 字段 | 业务含义 | 数据来源 | 格式/口径规则 | 空值处理 |
| ---- | -------- | -------- | ------------- | -------- |
| 任务名称 | 动态任务识别名称 | 动态任务数据 | 展示任务当前名称 | 空值显示“未命名任务” |
| 车牌号 | 任务所属车辆 | 任务车辆关系 | 展示任务分配车辆，不使用当前绑定车辆覆盖 | 未分配时显示“未分配车辆” |
| 任务状态 | 当前执行阶段 | 任务状态 | 枚举值：待开始、进行中、已完成 | 无状态按待开始处理并记录异常 |
| 派发时间 | 动态任务生成时间 | 动态任务数据 | YYYY-MM-DD HH:mm:ss | 空值显示“派发时间待确认” |
| 问题地点 | 问题发生位置描述 | 动态任务数据 | 展示有效地址 | 空值显示“问题地点待确认” |
| 问题类型 | 智能识别或人工确认的问题分类 | 动态任务数据 | 支持多个问题类型 | 空值显示“问题类型待确认” |
| 重要程度 | 问题处置优先级 | 动态任务数据 | 枚举值：一般、紧急 | 空值显示“一般” |
| 问题经纬度 | 问题位置坐标 | 动态任务数据 | 支持一组或多组坐标 | 无坐标时仅展示地点描述 |
| 问题图片 | 问题现场凭证 | 动态任务数据 | 支持多张 | 无图片时显示暂无图片 |
#### 3.2.4 业务规则与状态变化
| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| D01 | 加载列表 | 仅按当前驾驶员过滤，不按当前绑定车辆过滤 | 无 |
| D02 | 筛选时间 | 以派发时间作为动态任务时间过滤依据 | 无 |
| D03 | 查看详情 | 详情展示问题信息、任务所属车辆和完成信息 | 无 |
| D04 | 从独立列表进入详情 | 详情仅供查看，不提供任务执行操作 | 无 |
#### 3.2.5 交互流程
1. 驾驶员从用车管理进入动态任务。
2. 系统按当前驾驶员、默认状态和派发时间范围加载任务。
3. 驾驶员切换状态或时间范围，系统刷新动态任务列表和数量。
4. 驾驶员点击任务，系统打开对应只读详情并展示问题信息和任务所属车辆。
5. 驾驶员返回后回到动态任务列表并可继续查询。
#### 3.2.6 异常处理
| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 无查询结果 | 当前条件无任务 | 展示空结果，不改变筛选条件 | 提示当前范围暂无对应任务 | 调整状态或时间范围 |
| 问题信息不完整 | 地点、类型或图片缺失 | 展示已有字段并对缺失字段使用空值规则 | 展示对应待确认或暂无信息 | 等待数据补充后刷新 |
| 任务不存在 | 详情任务已撤回或标识无效 | 不展示错误任务数据 | 提示任务不存在 | 返回动态任务列表 |
#### 3.2.7 外部依赖

## 4. 业务规则汇总
### 4.1 数据范围规则
| 查询入口 | 驾驶员条件 | 车辆条件 | 说明 |
| -------- | ---------- | -------- | ---- |
| 地图工作台 | 当前驾驶员 | 当前绑定车辆 | 用于当前车辆的任务执行 |
| 应急任务独立查询 | 当前驾驶员 | 不限制车辆 | 用于查询本人全部应急任务 |
| 动态任务独立查询 | 当前驾驶员 | 不限制车辆 | 用于查询本人全部动态任务 |
### 4.2 状态与排序规则
| 状态 | 列表含义 | 排序规则 |
| ---- | -------- | -------- |
| 待开始 | 尚未开始的任务 | 时间正序 |
| 进行中 | 已开始且未结束的任务 | 时间正序 |
| 已完成 | 已结束并保存结果的任务 | 时间倒序 |
### 4.3 车辆信息规则
| 场景 | 业务规则 |
| ---- | -------- |
| 列表展示 | 每条任务展示任务所属车牌号，不展示当前绑定车辆替代值 |
| 详情展示 | 作业资源和完成信息均使用被点击任务的车辆信息 |
| 未分配车辆 | 任务保留在列表中并显示“未分配车辆” |
### 4.4 详情操作规则
| 来源 | 允许操作 | 返回目标 |
| ---- | -------- | -------- |
| 地图工作台 | 按任务状态执行开始、结束和导航 | 地图工作台 |
| 应急任务独立查询 | 仅查看 | 应急任务列表 |
| 动态任务独立查询 | 仅查看 | 动态任务列表 |
### 4.5 时间筛选规则
| 时间范围 | 匹配口径 |
| -------- | -------- |
| 今天 | 当前自然日 |
| 近7天 | 含今天在内的最近7个自然日 |
| 近30天 | 含今天在内的最近30个自然日 |
| 全部 | 不限制时间 |
| 自定义 | 起始日期与结束日期均包含；起始日期不得晚于结束日期 |
### 4.6 同级任务查询一致性规则
| 能力 | 常规任务、应急任务、动态任务的统一规则 |
| ---- | -------------------------------------- |
| 状态查询 | 均使用待开始、进行中、已完成三种状态，默认查询待开始 |
| 时间查询 | 均支持今天、近7天、近30天、全部和自定义时间范围 |
| 查询反馈 | 切换状态或时间后同步更新任务数量和列表；无结果时保留当前条件并提示当前范围无任务 |
| 详情联动 | 点击任务进入对应只读详情，返回时回到原任务类型列表 |
