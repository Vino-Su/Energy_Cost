## 1. 业务背景与使用角色
### 1.1 业务背景
- 模块定位：巡查员查看任务信息后，直接对本人任务执行开始、结束或返回操作。
- 核心特点：同一任务详情在地图和服务入口均使用统一的状态化操作规则。
- 关联模块关系：开始任务和结束任务复用巡查地图的任务校验、状态流转和完成确认能力。
### 1.2 使用角色
| 角色 | 该模块中的职责 | 客户端 |
| ---- | ------------ | ------ |
| 品质巡查员 | 查看本人任务详情并按任务状态执行任务操作。 | 移动端 APP |
### 1.3 核心目标与价值
| 目标维度 | 说明 |
| -------- | ---- |
| 操作效率 | 巡查员无需先返回地图或任务列表，即可从详情进入当前任务的下一步操作。 |
| 操作准确性 | 仅提供与任务当前状态匹配的操作，避免重复开始或重复结束。 |

## 3. 功能详细设计
### 3.1 F01 任务详情状态化操作
#### 3.1.1 功能目标与范围
| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 使巡查员在查看本人任务详情时，能够执行当前状态允许的任务操作。 |
| 使用角色 | 品质巡查员。 |
| 触发条件 | 巡查员从巡查地图或巡查任务列表进入任务详情。 |
| 功能边界 | 本功能仅定义任务详情的状态化操作与结果；任务信息、执行信息和关联事件的展示规则沿用既有任务详情规则。 |
| 成功结果 | 系统按任务状态展示正确操作，并在开始或结束任务成功后更新任务状态。 |
#### 3.1.2 使用条件与权限
| 角色 | 可执行操作 | 数据范围 | 前置条件 |
| ---- | ---------- | -------- | -------- |
| 品质巡查员 | 开始任务、结束任务、返回 | 本人被分配的巡查任务 | 已进入对应任务详情。 |
#### 3.1.3 数据与字段规则
| 字段/条件 | 业务含义 | 取值方式或数据来源 | 默认值 | 校验/匹配规则 |
| --------- | -------- | ---------------- | ------ | ------------- |
| 任务状态 | 决定任务详情可执行操作。枚举值：待接收、进行中、已完成；其他终态沿用只返回规则。 | 任务当前状态 | 以任务实际状态为准 | 状态变化后刷新任务详情的可执行操作。 |
| 当前操作 | 任务详情可提供的业务操作。 | 由任务状态计算 | 返回 | 待接收显示开始任务和返回；进行中显示结束任务和返回；已完成显示返回。 |
#### 3.1.4 业务规则与状态变化
| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| F01-R1 | 查看待接收任务详情 | 提供开始任务和返回。开始任务进入既有开始任务校验流程。 | 校验通过后任务变更为进行中；校验失败时保持待接收。 |
| F01-R2 | 查看进行中任务详情 | 提供结束任务和返回。结束任务进入既有结束任务确认和完成校验流程。 | 确认且校验通过后任务变更为已完成；取消或校验失败时保持进行中。 |
| F01-R3 | 查看已完成任务详情 | 仅提供返回，不提供开始任务或结束任务。 | 任务状态不变。 |
| F01-R4 | 查看已转派、已终止或已失效任务详情 | 沿用只返回规则。 | 任务状态不变。 |
#### 3.1.5 交互流程
1. 巡查员从地图或服务入口打开本人任务详情。
2. 系统读取任务当前状态并计算可执行操作。
3. 任务为待接收时，巡查员可选择开始任务；系统进入开始任务校验流程。
4. 任务为进行中时，巡查员可选择结束任务；系统展示结束确认并进入完成校验流程。
5. 处理结果：开始或结束校验成功时，更新任务状态并展示对应后续操作；校验失败或取消时，保留原状态并反馈原因。
6. 巡查员选择返回时，系统回到进入任务详情前的地图或任务列表上下文。
#### 3.1.6 异常处理
| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 开始任务校验失败 | 不满足既有开始任务校验条件 | 不变更任务状态。 | 展示校验失败原因。 | 巡查员处理失败原因后重新发起。 |
| 结束任务校验失败 | 不满足既有任务完成校验条件 | 不变更任务状态。 | 展示校验失败原因。 | 巡查员补充执行后重新发起。 |
| 结束确认取消 | 巡查员取消结束任务确认 | 关闭确认，保持任务进行中。 | 无需额外提示。 | 巡查员可继续执行任务或再次发起结束。 |
#### 3.1.7 外部依赖
| 依赖模块/服务 | 输入 | 输出 | 调用时机 | 失败处理 |
| ----------- | ---- | ---- | -------- | -------- |
| 巡查地图任务执行 | 任务标识、开始或结束操作 | 开始任务校验、结束确认、任务状态结果 | 巡查员在任务详情发起开始或结束时 | 由巡查地图任务执行流程反馈校验失败或保持原状态。 |

## 4. 业务规则汇总
### 4.1 状态流转
待接收 --开始任务校验通过--> 进行中 --结束确认且完成校验通过--> 已完成
任务处于待接收、进行中和已完成以外的状态时，不提供开始任务或结束任务。
### 4.2 操作映射规则
| 任务状态 | 可执行操作 | 操作结果 |
| -------- | ---------- | -------- |
| 待接收 | 开始任务、返回 | 开始任务通过校验后转为进行中；返回不改变任务状态。 |
| 进行中 | 结束任务、返回 | 结束任务确认且通过校验后转为已完成；返回不改变任务状态。 |
| 已完成 | 返回 | 返回不改变任务状态。 |
### 4.3 校验规则
| 操作 | 校验规则 | 校验失败结果 |
| ---- | -------- | ------------ |
| 开始任务 | 复用既有开始时间、未完成任务、车辆位置和人员位置校验。 | 保持待接收并反馈失败原因。 |
| 结束任务 | 复用既有任务完成情况校验，并在提交前要求巡查员确认结束。 | 保持进行中并反馈失败原因或关闭确认。 |
