## 1. 业务背景与使用角色
### 1.1 业务背景
- 模块定位：巡查员查看任务信息后，直接对本人任务执行开始、结束或返回操作。
- 核心特点：同一任务详情在地图和服务入口均使用统一的状态化操作规则。
- 关联模块关系：开始任务和结束任务复用巡查地图的任务校验、状态流转和完成确认能力；转派任务和终止任务复用巡查地图的原因填写与状态流转能力。
### 1.2 使用角色
| 角色 | 该模块中的职责 | 客户端 |
| ---- | ------------ | ------ |
| 品质巡查员 | 查看本人任务详情并按任务状态执行任务操作。 | 移动端 APP |
### 1.3 核心目标与价值
| 目标维度 | 说明 |
| -------- | ---- |
| 操作效率 | 巡查员无需先返回地图或任务列表，即可从详情进入当前任务的下一步操作。 |
| 操作准确性 | 仅提供与任务当前状态匹配的操作，避免重复开始或重复结束。 |

## 3. 功能详细设计
### 3.1 F01 任务详情状态化操作
#### 3.1.1 功能目标与范围
| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 使巡查员在查看本人任务详情时，能够执行当前状态允许的任务操作。 |
| 使用角色 | 品质巡查员。 |
| 触发条件 | 巡查员从巡查地图或巡查任务列表进入任务详情。 |
| 功能边界 | 本功能仅定义任务详情的状态化操作与结果；任务信息、执行信息和关联事件的展示规则沿用既有任务详情规则。 |
| 成功结果 | 系统按任务状态展示正确操作，并在开始或结束任务成功后更新任务状态。 |
#### 3.1.2 使用条件与权限
| 角色 | 可执行操作 | 数据范围 | 前置条件 |
| ---- | ---------- | -------- | -------- |
| 品质巡查员 | 开始任务、结束任务、返回、转派任务、终止任务 | 本人被分配的巡查任务 | 已进入对应任务详情；转派与终止仅适用于待接收或进行中任务。 |
#### 3.1.3 数据与字段规则
| 字段/条件 | 业务含义 | 取值方式或数据来源 | 默认值 | 校验/匹配规则 |
| --------- | -------- | ---------------- | ------ | ------------- |
| 任务状态 | 决定任务详情可执行操作。枚举值：待接收、进行中、已完成、已转派、已终止、已失效。 | 任务当前状态 | 以任务实际状态为准 | 状态变化后刷新任务详情的可执行操作。 |
| 当前操作 | 任务详情可提供的业务操作。 | 由任务状态计算 | 返回 | 待接收显示更多、开始任务和返回；进行中显示更多、结束任务和返回；其余终态仅显示返回。 |
| 操作原因 | 转派或终止任务时提交的业务原因。 | 巡查员填写 | 空 | 必填；转派记录为转派原因，终止记录为终止原因，最多 200 字。 |
| 操作时间 | 转派或终止任务的提交时刻。 | 系统记录 | 空 | 与操作原因一并记录，用于任务信息区回显。 |
#### 3.1.4 业务规则与状态变化
| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| F01-R1 | 查看待接收任务详情 | 提供开始任务和返回。开始任务进入既有开始任务校验流程。 | 校验通过后任务变更为进行中；校验失败时保持待接收。 |
| F01-R2 | 查看进行中任务详情 | 提供结束任务和返回。结束任务进入既有结束任务确认和完成校验流程。 | 确认且校验通过后任务变更为已完成；取消或校验失败时保持进行中。 |
| F01-R3 | 查看已完成任务详情 | 仅提供返回，不提供开始任务或结束任务。 | 任务状态不变。 |
| F01-R4 | 查看已转派、已终止或已失效任务详情 | 沿用只返回规则。 | 任务状态不变。 |
| F01-R5 | 待接收或进行中任务选择更多操作 | 提供"转派任务"与"终止任务"两项，二者互斥；已完成、已转派、已终止、已失效任务不提供该操作。 | 任务状态不变。 |
| F01-R6 | 选择转派任务 | 打开转派原因填写流程，说明转派后任务不再由本人执行。 | 提交成功后任务变更为已转派，记录操作原因与操作时间。 |
| F01-R7 | 选择终止任务 | 打开终止原因填写流程，明示终止不可恢复；提交按钮使用危险色区分。 | 提交成功后任务变更为已终止，记录操作原因与操作时间。 |
| F01-R8 | 转派或终止提交成功 | 就地收敛当前上下文：优先选中下一条待接收任务；无待接收任务时打开今日任务清单查看结果。 | 当前任务退出可执行状态，今日任务统计同步刷新。 |
| F01-R9 | 查看已转派或已终止任务 | 任务卡片与任务信息回显操作原因与操作时间。 | 任务状态不变。 |
#### 3.1.5 交互流程
1. 巡查员从地图或服务入口打开本人任务详情。
2. 系统读取任务当前状态并计算可执行操作。
3. 任务为待接收时，巡查员可选择开始任务；系统进入开始任务校验流程。
4. 任务为进行中时，巡查员可选择结束任务；系统展示结束确认并进入完成校验流程。
5. 待接收或进行中任务可展开"更多"选择转派任务或终止任务；系统打开对应原因填写弹窗，原因不能为空。
6. 处理结果：开始或结束校验成功时，更新任务状态并展示对应后续操作；校验失败或取消时，保留原状态并反馈原因；转派或终止提交成功后分别更新为已转派或已终止，记录操作原因与操作时间，并就地选中下一条待接收任务。
7. 巡查员选择返回时，系统回到进入任务详情前的地图或任务列表上下文。
#### 3.1.6 异常处理
| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 开始任务校验失败 | 不满足既有开始任务校验条件 | 不变更任务状态。 | 展示校验失败原因。 | 巡查员处理失败原因后重新发起。 |
| 结束任务校验失败 | 不满足既有任务完成校验条件 | 不变更任务状态。 | 展示校验失败原因。 | 巡查员补充执行后重新发起。 |
| 结束确认取消 | 巡查员取消结束任务确认 | 关闭确认，保持任务进行中。 | 无需额外提示。 | 巡查员可继续执行任务或再次发起结束。 |
| 操作原因为空 | 转派或终止提交时未填写原因 | 阻止提交并保留已填写内容 | 提示必须填写对应操作原因 | 补充原因后重新提交。 |
| 任务状态已变化 | 提交前任务已被其他流程更新为终态 | 阻止本次操作并提示刷新 | 提示任务状态已变化 | 关闭弹窗后按最新状态重新查看任务。 |
| 终止进行中任务 | 对进行中的任务提交终止 | 先停止本次作业的轨迹采集与时长计时，再更新任务状态 | 提示任务已终止 | 任务进入已终止终态，不可恢复。 |
#### 3.1.7 外部依赖
| 依赖模块/服务 | 输入 | 输出 | 调用时机 | 失败处理 |
| ----------- | ---- | ---- | -------- | -------- |
| 巡查地图任务执行 | 任务标识、开始或结束操作 | 开始任务校验、结束确认、任务状态结果 | 巡查员在任务详情发起开始或结束时 | 由巡查地图任务执行流程反馈校验失败或保持原状态。 |
| 巡查地图任务操作 | 任务标识、转派或终止操作 | 原因填写弹窗、任务状态结果 | 巡查员在任务详情选择转派或终止时 | 由巡查地图任务操作流程保留原状态或提示任务状态已变化。 |

### 3.2 F02 任务转派与终止
#### 3.2.1 功能目标与范围
| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 使巡查员能够对无法继续执行的本人任务做异常流转，并留下可追溯的业务原因。 |
| 使用角色 | 品质巡查员。 |
| 触发条件 | 巡查员在地图任务卡片或任务详情展开"更多"操作。 |
| 功能边界 | 本功能仅定义转派与终止的入口、原因填写、状态流转与结果记录；任务的开始、结束流程沿用既有规则。 |
| 成功结果 | 任务变更为已转派或已终止，操作原因与操作时间被记录并可在任务卡片与任务信息中回看。 |

#### 3.2.2 使用条件与权限
| 角色 | 可执行操作 | 数据范围 | 前置条件 |
| ---- | ---------- | -------- | -------- |
| 品质巡查员 | 转派任务、终止任务 | 本人被分配的巡查任务 | 任务状态为待接收或进行中；已完成、已转派、已终止、已失效任务不提供该操作。 |

#### 3.2.3 数据与字段规则
| 字段/条件 | 业务含义 | 取值方式或数据来源 | 默认值 | 校验/匹配规则 |
| --------- | -------- | ---------------- | ------ | ------------- |
| 操作类型 | 本次任务操作的类别。枚举值：转派、终止。 | 巡查员选择 | 无 | 二者互斥，一次仅提交一种。 |
| 操作原因 | 转派或终止的业务原因。 | 巡查员填写 | 空 | 必填，最多 200 字；为空时阻止提交。 |
| 操作时间 | 操作提交时刻。 | 系统记录 | 空 | 与操作原因一并记录。 |
| 操作人 | 发起操作的巡查员。 | 任务作业资源 | 当前巡查员 | 随操作记录一并保存。 |

#### 3.2.4 业务规则与状态变化
| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| F02-R1 | 展开更多操作 | 仅展示"转派任务"与"终止任务"两项；点击页面其他区域、按返回键或打开弹窗时菜单收起。 | 任务状态不变。 |
| F02-R2 | 点击转派任务 | 弹窗标题为"转派任务"，说明任务将转派给其他巡查员，要求填写转派原因，提交按钮使用主色。 | 弹窗打开，任务状态不变。 |
| F02-R3 | 点击终止任务 | 弹窗标题为"终止任务"，说明终止不可恢复，要求填写终止原因，提交按钮使用危险色。 | 弹窗打开，任务状态不变。 |
| F02-R4 | 提交转派或终止 | 原因非空且任务仍为待接收或进行中时提交成功，依次完成作业收尾（进行中任务先停止轨迹与计时）、记录操作原因与操作时间、更新任务状态。 | 转派后变为已转派；终止后变为已终止；记录操作原因与操作时间。 |
| F02-R5 | 提交成功后的页面反馈 | 提示"任务已转派"或"任务已终止"，并就地选中下一条待接收任务；无待接收任务时打开今日任务清单。 | 今日任务分组与统计同步刷新。 |
| F02-R6 | 查看已转派或已终止任务 | 任务卡片展示操作原因与操作时间；任务信息区同步展示；不再提供开始任务、转派或终止操作。 | 任务状态不变。 |

#### 3.2.5 交互流程
1. 巡查员在待接收或进行中任务的"更多"入口展开菜单。
2. 巡查员选择转派任务或终止任务，系统打开对应原因填写弹窗并关闭菜单。
3. 巡查员填写原因后提交；原因非空且任务状态未变化时提交成功，否则阻止提交并提示。
4. 提交成功后系统记录操作原因与操作时间，更新任务状态，提示结果并选中下一条待接收任务。
5. 取消按钮、点击遮罩或按返回键关闭弹窗，任务保持原状态。

#### 3.2.6 异常处理
| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 操作原因为空 | 提交时未填写原因 | 不关闭弹窗，保留已填写内容 | 提示"请填写转派原因"或"请填写终止原因" | 补充原因后重新提交。 |
| 任务状态已变化 | 提交前任务已被其他流程置为终态 | 阻止本次操作，不写入任何状态 | 提示任务状态已变化 | 关闭弹窗，按最新状态重新查看任务。 |
| 重复提交 | 短时间内连续点击提交 | 提交按钮置为"提交中…"并禁用 | 无额外提示 | 首次提交完成后按钮恢复。 |

#### 3.2.7 外部依赖
| 依赖模块/服务 | 输入 | 输出 | 调用时机 | 失败处理 |
| ----------- | ---- | ---- | -------- | -------- |
| 巡查地图任务操作 | 任务标识、转派或终止类型、操作原因 | 任务状态结果与操作记录 | 巡查员在地图任务卡片或任务详情发起转派或终止时 | 由巡查地图任务操作流程反馈失败原因或保持原状态。 |

## 4. 业务规则汇总
### 4.1 状态流转
待接收 --开始任务校验通过--> 进行中 --结束确认且完成校验通过--> 已完成
待接收或进行中 --转派--> 已转派；待接收或进行中 --终止--> 已终止
已完成、已转派、已终止、已失效为终态，不再提供开始任务、结束任务、转派任务或终止任务；任务处于终态时仅提供返回。
### 4.2 操作映射规则
| 任务状态 | 可执行操作 | 操作结果 |
| -------- | ---------- | -------- |
| 待接收 | 开始任务、更多（转派、终止）、返回 | 开始任务通过校验后转为进行中；转派后转为已转派；终止后转为已终止；返回不改变任务状态。 |
| 进行中 | 结束任务、更多（转派、终止）、返回 | 结束任务确认且通过校验后转为已完成；转派后转为已转派；终止后转为已终止；返回不改变任务状态。 |
| 已完成、已转派、已终止、已失效 | 返回 | 返回不改变任务状态。 |
### 4.3 校验规则
| 操作 | 校验规则 | 校验失败结果 |
| ---- | -------- | ------------ |
| 开始任务 | 复用既有开始时间、未完成任务、车辆位置和人员位置校验。 | 保持待接收并反馈失败原因。 |
| 结束任务 | 复用既有任务完成情况校验，并在提交前要求巡查员确认结束。 | 保持进行中并反馈失败原因或关闭确认。 |
| 转派任务 | 任务为待接收或进行中，且转派原因非空。 | 保持原状态，提示转派原因必填或任务状态已变化。 |
| 终止任务 | 任务为待接收或进行中，且终止原因非空。 | 保持原状态，提示终止原因必填或任务状态已变化。 |
