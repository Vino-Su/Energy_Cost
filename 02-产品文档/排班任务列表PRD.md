## 名词解释

| 名词/缩写 | 解释 |
| ---------- | ---- |
| 常规任务 | 服务任务管理中的路线任务集合，包含常态任务与临时任务两种类型；含计划时间、作业路段和作业类型等信息 |
| 临时任务 | 需临时处置的路线任务，在常规任务列表中以「临时任务」标签展示 |
| 动态任务 | 由摄像头识别、调度派发等触发的非常规任务，本期不在本页面承载 |
| 时间筛选 | 用于按时间范围过滤任务列表的能力，包括快捷范围（今天 / 近7天 / 近30天 / 全部）与自定义起止日期 |
| 任务卡片 | 用于展示单个任务的关键信息（名称、车牌、时间、路段、状态）的载体样式 |

## 1. 业务背景与使用角色
### 1.1 业务背景
- 模块定位：作为酷哇 APP 司机端「用车管理 - 常规任务」入口下的任务查询能力，按当前驾驶员查找本人全部常规任务，不以当前绑定车辆作为过滤条件。
- 核心特点：以三状态查询（待开始 / 进行中 / 已完成）和时间筛选为骨架，以任务卡片为信息载体；查询和反馈行为与应急、动态任务保持一致，但不混合展示其他任务类型，也不展示任务执行进度。
- 业务痛点：当前 `vehicle-management.html` 中「常规任务」「应急任务」「动态任务」三个入口均跳占位页，司机无法在地图工作台之外快速了解全天任务分布与历史完成情况。
- 建设必要性：在不破坏既有入口结构的前提下，把高频入口「常规任务」落地为真实列表页，提升司机对排班计划的感知度，并为后续与任务详情、异常记录等模块联动预留入口。
- 关联模块关系：从环卫云平台读取常规任务及任务车辆关系，与地图工作台复用任务字段口径；独立查询详情仅供查看，不直接操作任务执行流程。
### 1.2 使用角色

| 角色 | 该模块中的职责 | 客户端 |
| ---- | ------------ | ------ |
| 作业车辆驾驶员 | 通过「用车管理 - 常规任务」入口进入页面，按状态与时间查看本人常规任务，点击任务卡片尝试查看详情 | 移动端 APP |

### 1.3 核心目标与价值

| 目标维度 | 说明 |
| -------- | ---- |
| 信息获取效率 | 让司机一眼定位到「接下来该做什么」「现在进行中的」「已经做完的」三类任务 |
| 任务感知度 | 通过自定义时间筛选支持日 / 周 / 月 / 自定义视角，帮助司机掌握近期任务分布 |
| 体验一致性 | 与应急任务、动态任务统一状态切换、时间筛选、数量反馈、空结果和详情返回规则，并复用地图工作台任务字段口径 |
| 边界清晰 | 不替代地图工作台、不承载应急与动态任务；详情仅供查看，不执行开始、结束或导航 |
| 跨车辆识别 | 列表与详情均展示任务所属车牌号，避免与当前绑定车辆混淆 |

## 3. 功能详细设计

> **整体编排说明：** 本期仅含 F08 一个功能点；以页面 `schedule-tasks.html` 为维度编写 3.1 章节。Tab 页签虽简单但按模板统一展开为 `#### 3.1.x.y {Tab 名称}` 四级标题，便于后续扩展时按 Tab 增补字段。前置校验因列表页无强校验，仅给出软校验项，故省略 3.1.x.4 章节以保证编号连续。

### 3.1 F08 常规任务列表页
#### 3.1.1 页面布局

页面自上而下分为 5 个区域：

1. **顶部导航栏**：左侧返回按钮（`<` 图标）→ `vehicle-management.html`，居中标题「常规任务」（16px Semibold），右侧无操作位，固定定位高度 44px，背景 #ffffff，底部 1px 分割线 #e8e8e8。
2. **Tab 区**：含「待开始 / 进行中 / 已完成」三个状态入口并展示对应任务数量，默认选中「待开始」。
3. **筛选条**：紧贴 Tab 下方，高度 36px，浅灰 #f5f5f5 圆角 18px chip 形态，内容形如「今天 ▾」可点击；本期不放任何次级操作按钮。
4. **任务列表区**：可滚动，卡片纵向排列，卡片间距 12px，左右 16px padding，卡片底部留 24px 安全区。空状态时显示居中空态插画 + 文案。
5. **全局浮层**：Toast 层（页面居中弹出，rgba(0,0,0,0.7) 底白字 14px，1.8s 自动消失，见附录 A.5）、底部 ActionSheet 浮层（时间筛选选择）、自定义日期小弹层。

> 整体布局严格遵循附录 A.1～A.6 移动端组件规范与 `.claude/UI_design_APP.md`，首屏最大宽度 430px。

#### 3.1.2 查询筛选区

**筛选条元素：**

| 元素 | 类型 | 配置说明 |
| ---- | ---- | -------- |
| 当前时间范围 chip | 按钮 | 默认「今天」，三角箭头朝下，点击展开底部 ActionSheet |
| 车牌 chip | 按钮 | 默认「全部车牌」，点击展开底部车牌选择 ActionSheet，支持筛选任务所属车辆 |
| 全部结果 chip | 按钮 | 仅在「已结束」Tab 显示，默认「全部结果」，可选「已完成 / 已转派 / 已终止 / 已失效」细分已结束任务；待开始、进行中 Tab 不展示该 chip |

**筛选条件定义：**

| 条件名 | 取值范围 | 默认值 | 说明 |
| ------ | -------- | ------ | ---- |
| 时间范围 | 今天 / 近7天（含今天） / 近30天（含今天） / 全部 / 自定义（起止日期） | 今天 | 决定当前列表展示哪些时间区间内的任务 |
| Tab 状态 | 待开始 / 进行中 / 已结束 | 待开始 | 决定卡片显示的任务状态 |
| 车牌 | 全部车牌 / 具体车牌号 | 全部车牌 | 按任务所属车辆过滤 |
| 已结束结果 | 全部结果 / 已完成 / 已转派 / 已终止 / 已失效 | 全部结果 | 仅在「已结束」Tab 参与过滤，切换其他 Tab 时保留选择但不参与过滤 |

**操作按钮：**

| 按钮         | 触发行为                                                    | 可见角色    |
| ---------- | ------------------------------------------------------- | ------- |
| 时间范围 chip  | 打开底部 ActionSheet，可选今天 / 近7天 / 近30天 / 全部 / 自定义；选中后关闭弹层并刷新列表 | 作业车辆驾驶员 |
| 自定义面板 - 确定 | 校验起止日期后应用筛选并刷新列表，关闭面板                                   | 作业车辆驾驶员 |
| 自定义面板 - 取消 | 关闭面板，不应用筛选                                              | 作业车辆驾驶员 |

**查询条件显示规则：**

- 默认仅显示当前范围 chip，不展开弹层。
- 弹层模式下，选中项右侧打勾，主色高亮当前选中态。
- 自定义面板打开时叠加在 ActionSheet 上方，含起止日期输入 + 确定 / 取消。
#### 3.1.3 数据列表区

**列表显示字段（卡片通用，对齐《用车管理模块 PRD-地图版本》7.3.1，三行式布局）：**

| 行 | 序号 | 字段名 | 字段标识 | 宽度建议 | 说明 |
| -- | ---- | ------ | -------- | -------- | ---- |
| 第一行 | 1 | 路线名称 | routeName | flex:1 自适应 | 16px Semibold 主信息，左对齐单行省略 |
| 第一行 | 2 | 任务状态 | statusTag | 自适应 chip | 卡片右侧展示待开始 / 进行中 / 已结束状态 |
| 第二行 | 3 | 车牌号 | plateNo | 自适应徽章 | 展示任务所属车牌号；缺失时显示“未分配车辆” |
| 第二行 | 4 | 任务类型 | taskType | 自适应标签 | 枚举：常态任务、临时任务 |
| 第二行 | 5 | 作业类型 | workType | 自适应标签 | 展示任务作业类别 |
| 第三行 | 6 | 计划日期 | date | 自适应 | 灰色 12px，「YYYY-MM-DD」格式 |
| 第三行 | 7 | 计划时间 | timeRange | 自适应 | 「HH:mm-HH:mm」，等宽数字 |

**字段说明：**

- 不在卡片展示任务执行进度、作业要求、任务 ID 或回顾摘要字段；
- 路线名称取任务路线名称，任务名称不在服务任务卡片重复展示；
- 车牌号（plateNo）取自任务绑定的作业车辆，位于第二行首位；任务类型使用「常态任务」或「临时任务」标签展示。
- 任务类型标签按类型差异化配色，与地图工作台保持一致：常态任务为蓝底蓝字（#e6f4ff / #1677ff 系），临时任务为浅黄底棕字（#fffbe6 / #ad6800），与地图工作台任务卡片「临时任务」标签同色。

**排序规则：** 当前 Tab 内按计划开始时间升序排列；已完成 Tab 按计划开始时间倒序排列（最近完成的优先）。

**行交互规则：** 整张卡片可点击，打开对应任务的只读详情；详情携带任务标识、任务状态和常规任务来源，返回时回到常规任务列表。

**特殊设计：**

- 卡片背景统一为 #ffffff，**不再按状态显示底色**（V1.1 调整为扁平卡片风格），通过状态标签自身颜色区分状态。
- 卡片边框 1px 统一为 #e8e8e8；圆角 12px、内边距 14px×16px、阴影 0 2px 8px rgba(0,0,0,0.04)（遵循 UI_design_APP 6.3.1 卡片列表规范）。
- 状态标签分别展示待开始、进行中、已完成，并与应急任务、动态任务使用相同状态语义。
- 第三行内计划日期与时间以 1px×10px 竖线（#e8e8e8）分隔，竖线两侧各留 6px 间距。
- 空态：在各 Tab 无任务时显示空态（图标 + 文案），避免空白列表给司机造成疑惑。

#### 3.1.4 交互流程

1. 用户从 `vehicle-management.html` 点击「常规任务」入口 → 跳转到 `schedule-tasks.html`。
2. 页面加载完成，默认展示「待开始」Tab，时间筛选为「今天」。
3. 用户点击 Tab（如切换到「进行中」）→ Tab 高亮切换、卡片列表刷新，列表区域平滑替换。
4. 用户点击时间筛选 chip → 底部 ActionSheet 弹出，可选 今天 / 近7天 / 近30天 / 全部 / 自定义：
   - 用户选中 4 个快捷项之一 → 关闭弹层，chip 文案更新，列表刷新。
   - 用户选中「自定义」→ 弹层不关闭，上方叠加自定义日期小面板，含起始日期 / 结束日期两个输入控件、确定 / 取消按钮。
     - 用户填写起止日期并点击「确定」→ 校验起止日期（见 3.1.5）→ 关闭弹层，chip 文案更新为「自定义 YYYY-MM-DD ~ YYYY-MM-DD」，列表刷新。
     - 用户点击「取消」→ 关闭自定义面板，保留弹层仍处于打开状态，已选项不变。
5. 用户点击任务卡片 → 系统按任务标识打开共享任务详情，展示被点击任务的驾驶员和所属车辆；详情仅供查看，返回后回到常规任务列表。
6. 用户下拉刷新（页面顶部手势）→ 触发数据加载动画（演示用 Toast「已刷新」），列表重新渲染。
7. 用户点击左上角返回按钮 → 回到 `vehicle-management.html`。

## 4. 业务规则汇总
### 4.1 时间筛选规则

| 时间范围 | 起始时间计算 | 截止时间计算 | 包含项说明 |
| -------- | ------------ | ------------ | ---------- |
| 今天 | 当天 00:00 | 当天 23:59 | 当天的所有常规任务 |
| 近7天 | 当前日期 -6 天 00:00 | 当天 23:59 | 含今天在内的 7 天区间 |
| 近30天 | 当前日期 -29 天 00:00 | 当天 23:59 | 含今天在内的 30 天区间 |
| 全部 | — | — | 不限时间区间 |
| 自定义 | 起始日期 00:00 | 结束日期 23:59 | 用户自定义区间；结束日期不得晚于今天；起始不得晚于结束 |

### 4.2 Tab 与状态映射规则

| Tab 名 | 任务状态枚举值 | 排序规则 |
| ------ | -------------- | -------- |
| 待开始 | 待开始 | 计划开始时间升序 |
| 进行中 | 进行中 | 计划开始时间升序 |
| 已完成 | 已完成 | 计划开始时间降序 |

### 4.3 卡片点击规则

| 条件 | 行为 |
| ---- | ---- |
| 点击「待开始」卡片 | 打开对应只读详情，展示计划路线与任务所属车辆 |
| 点击「进行中」卡片 | 打开对应只读详情，展示执行轨迹、完成信息与任务所属车辆 |
| 点击「已完成」卡片 | 打开对应只读详情，展示完整轨迹、完成信息与任务所属车辆 |
| 任务不存在 | 展示任务不存在状态并允许返回常规任务列表 |

### 4.4 字段联动规则

| 触发字段 | 触发条件 | 联动行为 |
| -------- | -------- | -------- |
| 时间筛选 chip | 用户切换时间范围 | 列表与计数同步刷新 |
| Tab | 用户切换 Tab | 列表与计数同步刷新 |

### 4.5 计算规则

| 规则项 | 计算逻辑 |
| ------ | -------- |
| Tab 计数 | 当前筛选条件下对应状态的任务总数 |
| 已完成卡片「耗时」 | 任务结束时间 − 开始时间（如取自后端回传数据，原型可用静态示例值） |
| 已完成卡片「用水量」 | 后端记录的本次任务用水量（原型使用示例值） |

### 4.6 校验规则

| 校验条件 | 提示信息 | 阻断操作 |
| -------- | -------- | -------- |
| 自定义起止日期均未填 | 请选择起止日期 | 阻断应用筛选 |
| 结束日期早于起始日期 | 结束日期不能早于起始日期 | 阻断应用筛选 |
| 结束日期晚于今天 | 结束日期不能晚于今天 | 阻断应用筛选 |

### 4.7 卡片字段缺失兜底规则

| 字段缺失场景 | 兜底展示 |
| ------------ | -------- |
| 任务名称为空 | 展示「未命名任务」 |
| 车牌号为空 | 显示“未分配车辆”，任务仍保留在当前查询结果中 |
| 计划时间为空 | 仅展示「作业要求」 |
| 作业路段为空 | 不展示该字段 |
| 已完成无回顾数据 | 不展示耗时 / 用水量小字 |

### 4.8 同级任务查询一致性规则

| 能力 | 常规任务、应急任务、动态任务的统一规则 |
| ---- | -------------------------------------- |
| 状态查询 | 均使用待开始、进行中、已完成三种状态，默认查询待开始 |
| 时间查询 | 均支持今天、近7天、近30天、全部和自定义时间范围 |
| 查询反馈 | 切换状态或时间后同步更新任务数量和列表；无结果时保留当前条件并提示当前范围无任务 |
| 详情联动 | 点击任务进入对应只读详情，返回时回到原任务类型列表 |

| 指标 | 要求 |
| ---- | ---- |
| 数据隔离 | 司机仅可查看本人常规任务，不展示他人任务 |
| 操作留痕 | 时间筛选与 Tab 切换仅本地缓存，不写入日志；后续接入真实接口后需按权限校验 |
| 越权访问 | 后续接入接口时需校验人车绑定关系，未绑定车辆不应请求数据 |

| 指标 | 要求 |
| ---- | ---- |

| 系统兼容 | 兼容 iOS / Android WebView 与 APP 内嵌页 |
| 弱网兼容 | 加载失败时 Toast「数据加载失败，请重试」，保留已加载卡片数据 |
| 字体兼容 | PingFang SC / Microsoft YaHei 兜底 |
