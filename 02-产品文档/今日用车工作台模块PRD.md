## 名词解释

| 名词/缩写 | 解释 |
| ---------- | ---- |
| 今日用车 | 面向作业车辆驾驶员的一日用车场景入口，用于承载接车状态、当前车辆、今日流程、待办任务、异常提醒、常用功能与交车检查 |
| 人车绑定 | 驾驶员与车辆在一定时间范围内建立的使用关系，是进入场景化主流程的基础 |
| 接车 | 驾驶员开始使用某车辆时，通过展示个人码或扫描车辆码建立人车绑定关系的动作 |
| 交车 | 驾驶员结束使用某车辆时，通过扫码或个人码触发解除人车绑定关系的动作 |
| 个人码 | 驾驶员用于车辆端识别身份的二维码，可根据车辆当前绑定状态触发接车或交车动作 |
| 阻断项 | 未处理前不允许进入下一业务动作或不允许交车的事项，如禁止出车日检项、未结束任务 |
| 提醒项 | 需要提示司机关注或补充处理，但不强制阻断当前动作的事项，如异常待确认、照片待补充 |

## 1. 业务背景与使用角色
### 1.1 业务背景
- 模块定位：今日用车工作台是车辆使用过程监管方案在司机端 APP 的场景化承载页，用于把接车、日检、任务、动态事项、异常提醒、补给上报、故障报修、交车等动作组织成一天的工作链路。
- 核心特点：以“当前司机是否已绑定车辆”为入口分流条件，未绑定时引导扫码接车，已绑定时展示完整今日用车工作台。
- 业务痛点：原车辆使用动作分散在多个功能中，司机需要自行找入口；管理侧难以稳定追踪人车关系、日检状态、任务执行状态、异常处理状态和交车闭环。
- 建设必要性：通过轻量工作台将关键动作串联，降低司机操作复杂度，同时为后续监管、异常记录、考核留痕提供统一入口。
### 1.2 使用角色

| 角色 | 该模块中的职责 | 客户端 |
| ---- | ------------ | ------ |
| 作业车辆驾驶员 | 进入今日用车、完成扫码接车、查看当前车辆、执行日检、接受任务、处理异常/动态事项、进行水电油上报、发起交车检查 | 移动端 APP |
| 项目经理/管理员 | 查看异常记录、核查车辆使用异常、处理合规或任务执行异常、根据阻断项调整任务或车辆安排 | 管理端/环卫云平台 |
| 系统服务 | 判断人车绑定状态、同步车辆可用性、同步任务排班、生成异常记录、记录接车/交车留痕 | 后端服务 |

### 1.3 核心目标与价值

| 目标维度 | 说明 |
| -------- | ---- |
| 司机操作效率 | 将当天用车动作集中到一个工作台，减少“人找功能” |
| 流程规范 | 明确接车绑定、日检、任务、动态事项、交车的先后关系 |
| 监管留痕 | 记录人车绑定、异常提醒、未完成事项、交车检查等关键动作 |
| 风险控制 | 对未绑定车辆、禁止出车、未结束任务等关键场景进行阻断 |
| 模块融合 | 将已开发能耗成本上报能力作为常用功能接入今日用车场景 |

## 3. 功能详细设计
### 3.1 F01 首页入口与未绑定车辆状态页
#### 3.1.1 页面层级与页面布局

该功能点覆盖 `home.html` 与 `vehicle-unbound.html` 两个页面，属于司机进入今日用车主流程前的入口分流层。

| 页面 | 页面定位 | 页面组成 | 说明 |
| ---- | -------- | -------- | ---- |
| `home.html` | 工作台入口页 | 用车监管分组、今日用车入口、未绑定车辆状态演示入口、车务管理分组 | 正式产品建议仅保留“今日用车”一个入口，由系统按绑定状态自动分流；原型为便于评审保留两个入口 |
| `vehicle-unbound.html` | 未绑定车辆状态页 | 顶部导航、未绑定空状态卡片、操作按钮区、绑定前状态卡片、今日流程预览卡片、独立功能区、个人码弹窗 | 当前司机无有效人车绑定时展示，不进入完整工作台 |

#### 3.1.2 数据展示字段

| 页面区域 | 字段/元素 | 示例 | 说明 |
| -------- | --------- | ---- | ---- |
| 首页入口 | 入口标题 | 今日用车 | 已绑定或正式入口 |
| 首页入口 | 入口说明 | 接车、日检、任务、异常、交车 | 概括今日用车主流程 |
| 首页入口 | 状态标签 | 日检待完成 | 展示当前演示状态 |
| 未绑定入口 | 入口标题 | 未绑定车辆状态 | 原型评审入口 |
| 未绑定入口 | 状态标签 | 请先绑定、状态演示 | 提示当前为未绑定演示状态 |
| 未绑定页空状态 | 状态文案 | 今日流程未开启 | 表示尚未进入主流程 |
| 未绑定页空状态 | 主标题 | 请先扫码绑定车辆 | 明确主动作 |
| 当前环节 | 当前环节标题 | 等待接车绑定 | 绑定成功后进入车辆日检 |

#### 3.1.3 前置校验

| 校验条件 | 提示信息 | 阻断操作 |
| -------- | -------- | -------- |
| 司机存在有效人车绑定 | 无需提示 | 允许进入今日用车工作台 |
| 司机无有效人车绑定 | 请先扫码绑定车辆 | 不允许展示完整今日用车工作台，进入未绑定车辆状态页 |
| 车辆端扫码绑定成功 | 绑定成功，进入今日用车 | 允许跳转至今日用车工作台 |
| 车辆已被他人绑定 | 车辆已被占用，请更换车辆或联系管理员 | 阻断绑定 |
| 当前司机已绑定其他车辆 | 请先完成当前车辆交车 | 阻断换车绑定 |
| 车辆可用性校验不通过 | 根据具体原因提示，如证照到期、故障未修复、保险到期 | 阻断进入主流程 |

#### 3.1.4 操作按钮

| 按钮 | 所属页面 | 触发行为 | 可见角色 |
| ---- | -------- | -------- | -------- |
| 今日用车 | 首页 | 进入今日用车入口分流；已绑定进入工作台，未绑定进入未绑定状态页 | 作业车辆驾驶员 |
| 未绑定车辆状态 | 首页 | 进入未绑定状态页原型演示 | 作业车辆驾驶员 |
| 出示个人码 | 未绑定状态页 | 打开个人码弹窗，用于车辆端扫码接车 | 作业车辆驾驶员 |
| 返回工作台 | 未绑定状态页 | 返回 `home.html` | 作业车辆驾驶员 |
| 去绑定 | 未绑定状态页当前环节 | 打开个人码弹窗 | 作业车辆驾驶员 |
| 加油/加水/充电/记录 | 未绑定状态页独立功能区 | 进入对应独立功能；功能内必须选择车辆 | 作业车辆驾驶员 |

#### 3.1.5 交互流程
1. 司机进入城市管家工作台。
2. 系统展示“用车监管”分组。
3. 司机点击“今日用车”：
   - 已绑定车辆 → 进入 `vehicle-workbench.html`。
   - 未绑定车辆 → 进入 `vehicle-unbound.html`。
4. 司机在未绑定状态页点击“出示个人码”或“去绑定”。
5. 页面弹出个人码弹窗。
6. 车辆端扫码并完成绑定：
   - 绑定成功 → Toast 提示“绑定成功，进入今日用车”，跳转今日用车工作台。
   - 绑定失败 → 展示失败原因，停留在未绑定状态页。
7. 司机点击“返回工作台” → 返回 `home.html`。
8. 司机点击独立功能入口 → 进入对应功能页面，对应功能页必须单独选择车辆。
#### 3.1.6 弹窗规格

| 属性 | 值 |
| ---- | -- |
| 弹窗名称 | 个人码弹窗 |
| 触发入口 | 出示个人码、去绑定 |
| 位置 | 居中弹出 |
| 遮罩 | 半透明遮罩 |
| 标题 | 个人码 |
| 内容 | 二维码占位图 + 说明文案 |
| 主按钮 | 绑定完成，进入工作台 |
| 次按钮 | 稍后绑定 |
| 关闭规则 | 点击“稍后绑定”或遮罩关闭；正式产品可按安全策略配置遮罩是否可关闭 |

### 3.2 F02 今日用车工作台页
#### 3.2.1 页面布局

页面文件为 `vehicle-workbench.html`，适用于司机已完成车辆绑定后的状态，自上而下分为 7 个区域：

1. **顶部导航**：标题“今日用车”，左侧返回工作台，不显示底部 Tab。
2. **车辆信息卡片**：展示当前车辆、车辆基础信息、运行状态、三格统计、状态标签和主操作按钮。
3. **今日流程 - 当前环节卡片**：上方展示五个流程节点，下方展示当前环节轻量信息。
4. **待办任务卡片**：展示今日排班任务和动态任务。
5. **异常与提醒卡片**：展示移动异常提醒、停靠超时待确认等异常事项。
6. **常用功能卡片**：提供加油、加水、充电、记录入口。
7. **弹层容器**：包含个人码弹窗、今日流程详情弹层、交车检查弹层。
#### 3.2.2 数据展示字段

| 区域 | 字段/元素 | 示例 | 说明 |
| ---- | --------- | ---- | ---- |
| 车辆信息 | 车牌号 | 粤 B·D2856 | 当前绑定车辆主标识 |
| 车辆信息 | 车辆描述 | 湾区项目 · 洗扫车 | 展示项目和车型 |
| 车辆信息 | 车辆状态 | 使用中 | 表示司机当前已绑定并使用该车 |
| 三格统计 | 接车 | 07:42 | 当天接车时间 |

| 状态标签 | 日检待完成 | 日检待完成 | 表示当前主流程卡在日检前 |

| 校验条件 | 提示信息 | 阻断操作 |

#### 3.2.7 交互流程
1. 司机完成接车绑定后进入今日用车工作台。
2. 系统展示当前绑定车辆、今日状态标签、流程节点、待办任务、异常提醒和常用功能。
3. 司机点击“展示个人码” → 打开个人码弹窗。
4. 司机点击任一流程节点：
   - 被点击节点展示当前高亮。
   - 排在当前节点之前的节点展示已完成态。
   - 当前环节区展示对应标题、说明和按钮。
5. 司机点击“查看全部” → 打开今日流程详情弹层。
6. 司机点击“交车检查”或交车环节的“去交车” → 打开交车检查弹层。
7. 司机点击异常卡片“提醒” → Toast 提示已提醒司机自纠。
8. 司机点击异常卡片“确认” → Toast 提示进入异常确认，正式产品应跳转异常确认页。

## 4. 业务规则汇总
### 4.1 入口分流规则

| 当前状态 | 系统行为 |
| -------- | -------- |
| 司机已绑定车辆 | 进入今日用车工作台 |
| 司机未绑定车辆 | 进入未绑定车辆状态页，引导扫码绑定 |
| 原型评审状态 | 首页保留”今日用车”和”未绑定车辆状态”两个入口便于展示 |
| 用车管理页今日用车卡片（已绑定且可用） | loading → 跳转地图工作台 `map-workbench.html` |
| 用车管理页今日用车卡片（未绑定） | 卡片右侧展示”当前未绑定车辆”，点击后弹窗提示”暂未绑定车辆”，不跳转 |
| 用车管理页今日用车卡片（已绑定但不可用） | 卡片右侧仍展示车牌号，点击后弹窗提示具体不可用原因 |

### 4.2 人车绑定规则

| 当前状态 | 扫码车辆 | 系统动作 |
| -------- | -------- | -------- |
| 驾驶员无绑定车辆，车辆也未被绑定 | 当前车辆 | 判定为接车，进行车辆可用性校验 |
| 驾驶员无绑定车辆，但车辆已被他人绑定 | 当前车辆 | 禁止接车，提示车辆已被占用 |
| 驾驶员已绑定 A 车，B 车扫描该驾驶员个人码 | B 车 | 不自动换车，提示需先交 A 车 |
| 驾驶员已绑定 A 车，但 A 车存在未结束任务 | A 车 | 进入交车检查，阻断交车 |
| 驾驶员已绑定 A 车，无阻断项 | A 车 | 触发交车确认，确认后进入未完成事项检查 |

### 4.3 状态流转规则

```text
未绑定
  -> 扫码接车
  -> 车辆可用性校验
      -> 不通过：保持未绑定或提示更换车辆
      -> 通过：已绑定/使用中
  -> 车辆日检
      -> 禁止出车：停止主流程
      -> 允许出车：进入任务接受执行
  -> 任务/动态事项/异常处理/补给上报
  -> 交车检查
      -> 存在阻断项：保持已绑定
      -> 无阻断项：解除绑定
```

### 4.4 日检强制规则

| 场景 | 规则 |
| ---- | ---- |
| 已绑定车辆后进入主流程 | 日检作为每日任务前的强制步骤 |
| 日检未完成 | 不允许接受或执行任务 |
| 日检结果为禁止出车 | APP 不进入下一步业务 |
| 日检允许出车但需报修 | 允许继续出车，同时生成报修或维修预约 |

### 4.5 异常监控处理规则

| 异常大类 | 异常事件 | 司机端处理 | 管理端处理 |
| -------- | -------- | ---------- | ---------- |
| 使用异常 | 车辆行驶未关联驾驶员 | 司机端无绑定对象时不推送或提示绑定 | 推送项目经理核查 |
| 使用异常 | 车辆长时间未交车 | 提醒交车 | 推送项目经理核查 |
| 合规异常 | 年检/保险/牌照到期 | 接车强拦截 | 推送管理处置 |
| 日检异常 | 行驶车辆未日检 | 提醒并记录 | 后台复核 |
| 任务异常 | 轨迹偏差、覆盖度不足 | 轻微提醒，严重记录 | 任务完成复核 |
| 安全异常 | 超速、限行区行驶 | 强提醒自纠 | 多次可推送项目经理核查 |
| 停靠异常 | 超时停靠 | 提醒并记录 | 按项目规则处理 |
| 动态任务异常 | 未响应/未闭环 | 提醒处理 | 推送项目经理核查 |

### 4.6 轨迹异常适用规则

| 规则项 | 说明 |
| ------ | ---- |
| 移动异常 | 与任务无关，校验车辆是否与驾驶员绑定 |
| 轨迹异常 | 仅驾驶员执行任务期间校验 |
| 非任务期间 | 不比较计划路线与实际路线，不做轨迹异常校验 |
| 任务期间 | 可比较计划路线、实际路线、覆盖度、偏差程度 |

### 4.7 交车规则

| 未完成事项类型 | 是否允许交车 | 处理方式 |
| -------------- | ------------ | -------- |
| 未结束任务 | 否 | 阻断交车，要求先结束或异常关闭任务 |
| 禁止交车类动态任务 | 否 | 阻断交车，要求先处理 |
| 异常待确认 | 是 | 提醒司机，可交车并保留记录 |
| 补给记录照片待补充 | 是 | 提醒司机，可交车并保留待办 |
| 无未完成事项 | 是 | 解除人车绑定并生成今日回顾 |

### 4.8 考勤与人车绑定关系

| 动作 | 人车绑定处理 | 考勤处理 |
| ---- | ------------ | -------- |
| 当天首次成功接车 | 创建人车绑定关系 | 如无上班考勤记录，可生成或更新上班考勤事件 |
| 当天成功交车 | 关闭人车绑定关系 | 可作为下班考勤候选时间，按最晚交车时间更新 |
| 独立功能使用 | 不强制创建人车绑定关系 | 不直接影响考勤 |

### 4.9 本期不跟踪用车目的规则

| 规则项 | 说明 |
| ------ | ---- |
| 用车目的 | 当前版本不要求司机选择或填写用车目的 |
| 后台标签 | 当前版本不通过司机动作自动推断用车目的 |
| 原因 | 降低系统复杂度，避免自动分析标签不真实、不准确 |

### 4.10 留痕规则

| 留痕节点 | 记录内容 |
| -------- | -------- |
| 接车成功 | 驾驶员、车辆、时间、位置、校验结果 |
| 个人码扫码 | 扫码车辆、扫码时间、扫码结果、失败原因 |
| 日检结果 | 检查项、异常项、照片、是否禁止出车 |
| 异常提醒 | 异常类型、触发时间、提醒结果、是否确认 |
| 交车检查 | 阻断项、提醒项、司机操作、交车结果 |
