## 1. 业务背景与使用角色
### 1.1 业务背景
- 模块定位：城市管家以统一地图承载不同项目角色的现场执行与项目监管场景。
- 当前问题：仅通过地图标记或专题名称区分角色，无法体现一线人员的任务操作与项目经理的管理决策差异。
- 核心特点：地图底图与基础控制保持一致，活动角色决定业务图层、数据范围和角色操作面板；项目经理在其角色内再切换专题图。
- 关联模块关系：驾驶员任务信息复用今日用车地图工作台的任务卡片口径；项目经理的作业、人员、车辆信息来自项目级运营数据；品质巡查、安全员分别关联巡查问题与机器人告警。
### 1.2 使用角色
| 角色 | 该模块中的职责 | 客户端 |
| ---- | ------------ | ------ |
| 项目经理 | 查看全项目作业、人员、车辆总体情况并切换专题图。 | 移动端 APP |
| 驾驶员 | 查看本人车辆任务、路线和任务操作入口。 | 移动端 APP |
| 环卫工 | 查看本人保洁任务、作业路段和事件上报入口。 | 移动端 APP |
| 品质巡查 | 查看本人巡查任务、问题点与问题上报入口。 | 移动端 APP |
| 安全员 | 查看项目机器人状态、告警和处置入口。 | 移动端 APP |
### 1.3 核心目标与价值
| 目标维度 | 说明 |
| -------- | ---- |
| 角色辨识 | 让同一地图入口明确呈现不同角色的工作目标与可操作事项。 |
| 执行效率 | 一线人员进入地图后直接获取当前任务、路线和高频操作入口。 |
| 管理效率 | 项目经理通过专题图快速了解项目级作业、人员和车辆整体状态。 |
| 权限表达 | 通过角色数据范围区分个人视角与项目级视角，避免将全部信息混合展示。 |

## 3. 功能详细设计
### 3.1 F01 活动角色地图场景
#### 3.1.1 功能目标与范围
| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 使用户在统一地图入口中获得与当前角色匹配的业务视图和操作入口。 |
| 使用角色 | 项目经理、驾驶员、环卫工、品质巡查、安全员。 |
| 触发条件 | 用户进入地图并选择或切换活动角色。 |
| 功能边界 | 包含地图业务要素、角色数据范围说明和单一角色操作面板；不包含多角色面板同时操作。 |
| 成功结果 | 地图业务要素和操作面板同步切换至目标角色。 |
#### 3.1.2 使用条件与权限
| 角色 | 可执行操作 | 数据范围 | 前置条件 |
| ---- | ---------- | -------- | -------- |
| 项目经理 | 切换专题图、查看项目总体数据、进入监控明细入口。 | 当前项目全部作业、人员、车辆的汇总与位置要素。 | 已拥有当前项目管理权限。 |
| 驾驶员 | 查看本人任务、导航及任务操作入口。 | 当前驾驶员本人及绑定车辆的任务信息。 | 已拥有任务执行权限。 |
| 环卫工 | 查看本人保洁任务、开始作业及事件上报入口。 | 当前环卫工本人任务与关联作业路段。 | 已拥有保洁任务执行权限。 |
| 品质巡查 | 查看本人巡查任务、开始巡查及问题上报入口。 | 当前巡查员本人任务、巡查点和待处理问题。 | 已拥有巡查任务权限。 |
| 安全员 | 查看机器人状态、定位告警设备及告警处置入口。 | 当前项目机器人与告警信息。 | 已拥有机器人安全监控权限。 |
#### 3.1.3 数据与字段规则
| 字段 | 业务含义 | 数据来源 | 格式/口径规则 | 空值处理 |
| ---- | -------- | -------- | ------------- | -------- |
| 活动角色 | 当前地图数据与操作的权限上下文。 | 用户角色配置或演示角色选择。 | 枚举值：项目经理、驾驶员、环卫工、品质巡查、安全员。 | 无角色时不展示地图场景。 |
| 数据范围 | 当前角色可查看的人员、车辆、任务、问题或告警集合。 | 角色权限与项目归属。 | 项目经理与安全员按项目范围，其余一线角色按本人范围。 | 无数据时显示对应业务的空状态。 |
| 地图业务要素 | 任务路线、作业点、人员、车辆、问题点、机器人或告警点。 | 对应业务数据。 | 仅展示当前活动角色有权查看的要素。 | 无要素时保留底图与数据状态说明。 |
#### 3.1.4 业务规则与状态变化
| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| R01 | 切换活动角色 | 切换后必须同时刷新业务要素、数据范围说明和角色操作面板。 | 当前角色上下文更新，原角色操作面板不再显示。 |
| R02 | 多角色账号切换 | 地图基础视角保持连续，角色面板互斥；不可将多角色动作同时呈现为可执行状态。 | 仅保留最后一次选择的活动角色。 |
| R03 | 角色权限变化 | 无权角色不可进入对应地图场景，不展示其项目或个人数据。 | 保持当前有权角色或提示权限已变更。 |
#### 3.1.5 交互流程
1. 用户进入城市管家地图。
2. 系统依据当前活动角色加载对应的数据范围、地图业务要素和角色操作面板。
3. 用户切换活动角色时，系统切换至该角色场景并保留地图基础视角。
4. 处理结果：
   - 成功 → 展示目标角色的地图场景与操作入口，并给出切换反馈。
   - 失败 → 无权限或角色失效时提示原因，原有角色场景保持不变。
#### 3.1.6 异常处理
| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 角色无地图场景 | 当前角色不配置地图能力。 | 不加载业务地图数据。 | 提示该角色无需使用地图。 | 切换至其他角色或服务模块。 |
| 角色权限失效 | 进入或切换时权限校验失败。 | 阻止加载无权数据。 | 提示角色权限已变更。 | 刷新角色配置后重新进入。 |
### 3.2 F02 项目经理专题监控
#### 3.2.1 功能目标与范围
| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 让项目经理在地图中按监控对象查看全项目运行概况并进入对应明细入口。 |
| 使用角色 | 项目经理。 |
| 触发条件 | 项目经理进入地图或切换监控专题。 |
| 功能边界 | 包含作业、人员、车辆三类专题和总体统计；不包含在原型内直接调度资源或修改业务数据。 |
| 成功结果 | 当前专题的地图要素、统计项和明细入口保持一致。 |
#### 3.2.2 数据与字段规则
| 专题 | 总体数据 | 地图业务要素 | 数据范围 |
| ---- | -------- | ------------ | -------- |
| 作业监控 | 任务总数、进行中、已完成、异常或超时数量。 | 作业路线、作业点、待调度任务、异常任务。 | 当前项目全部作业任务。 |
| 人员监控 | 应到人数、当前在岗、作业中、定位异常数量。 | 作业组、巡查组、休息人员、定位异常人员。 | 当前项目全部相关人员。 |
| 车辆监控 | 车辆总数、设备在线、作业中、离线或故障数量。 | 作业车辆、在线车辆、离线或故障车辆。 | 当前项目全部作业车辆。 |
#### 3.2.4 业务规则与状态变化
| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| R04 | 切换项目经理专题 | 必须成组切换专题名称、地图业务要素、总体数据和明细入口文案。 | 当前专题更新。 |
| R05 | 指标统计 | 同一专题的统计项按当前项目和当前数据时间点统计。 | 总体数据与地图要素保持同一范围。 |
#### 3.2.5 交互流程
1. 项目经理进入地图后，系统默认加载作业监控专题。
2. 用户选择作业、人员或车辆专题。
3. 系统展示所选专题的地图业务要素和总体数据。
4. 用户触发专题明细入口。
5. 处理结果：
   - 成功 → 进入对应监控明细的演示反馈，当前专题保持不变。
   - 失败 → 专题数据不可用时提示数据暂不可用，并保留已加载专题。
### 3.3 F03 一线角色任务操作示意
#### 3.3.1 功能目标与范围
| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 为一线角色说明地图中的当前工作对象、工作状态和高频操作路径。 |
| 使用角色 | 驾驶员、环卫工、品质巡查、安全员。 |
| 触发条件 | 一线角色进入地图。 |
| 功能边界 | 提供任务、巡查或告警摘要及操作入口示意；不在原型中提交真实业务单据或改变真实任务状态。 |
| 成功结果 | 用户可识别当前工作对象及其后续可执行操作。 |
#### 3.3.2 数据与字段规则
| 角色 | 当前工作对象 | 展示信息 | 高优先级操作 |
| ---- | ------------ | -------- | ------------ |
| 驾驶员 | 当前车辆任务。 | 路线、车辆、任务状态、时间、里程、任务完成情况。 | 导航、查看今日任务、开始任务。 |
| 环卫工 | 当前保洁任务。 | 作业路段、任务状态、任务完成情况、待上报事件。 | 定位作业路段、上报事件、开始作业。 |
| 品质巡查 | 当前巡查任务。 | 巡查范围、巡查状态、检查项、待复查和待处理问题。 | 定位巡查路线、上报问题、开始巡查。 |
| 安全员 | 当前高优先级机器人告警。 | 告警设备、告警状态、位置、设备在线与待处置情况。 | 定位设备、联系现场、查看告警。 |
#### 3.3.5 交互流程
1. 一线角色进入地图，系统加载本人任务或项目告警数据。
2. 系统展示当前工作对象的摘要及匹配的高频操作入口。
3. 用户触发导航、查看清单、上报、开始或处置入口。
4. 处理结果：
   - 成功 → 原型展示对应入口的操作反馈，用于说明后续业务去向。
   - 失败 → 数据缺失、无当前任务或权限不足时提示原因，不生成业务记录。
#### 3.3.6 异常处理
| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 无当前任务 | 当前一线角色没有可执行任务。 | 不展示任务操作入口。 | 提示暂无待执行任务。 | 刷新任务或查看任务列表。 |
| 无告警 | 安全员当前无待处置告警。 | 不展示告警处置入口。 | 提示当前无告警。 | 刷新机器人监控数据。 |

## 4. 业务规则汇总
### 4.1 角色与数据范围规则
| 规则项 | 说明 |
| ------ | ---- |
| 角色上下文 | 地图仅按一个活动角色呈现操作面板，切换角色后立即使用目标角色的数据范围。 |
| 项目范围 | 项目经理与安全员查看当前项目范围内的授权数据。 |
| 个人范围 | 驾驶员、环卫工、品质巡查仅查看本人被分配的任务及关联业务要素。 |
### 4.2 专题与面板联动规则
| 触发字段 | 触发条件 | 联动行为 |
| -------- | -------- | -------- |
| 活动角色 | 用户切换角色。 | 切换地图业务要素、数据范围说明和角色操作面板。 |
| 项目经理专题 | 用户选择作业、人员或车辆监控。 | 切换对应的总体数据、地图业务要素和明细入口。 |
### 4.3 操作反馈规则
| 操作 | 权限范围说明 |
| ---- | ------------ |
| 任务、巡查、告警操作入口 | 仅在对应活动角色及其授权数据范围内可触发；本期原型仅反馈后续业务去向。 |
| 项目经理监控明细入口 | 仅项目经理可触发；本期原型不进入真实管理系统。 |
### 4.4 演示数据规则
- 静态原型数据仅用于表达角色权限、状态与操作路径，不作为业务台账、统计报表或任务执行记录。
- 操作反馈不产生真实任务状态、人员状态、车辆状态、问题记录或告警处置记录。
