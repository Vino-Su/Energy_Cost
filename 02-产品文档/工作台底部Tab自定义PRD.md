## 名词解释

| 名词/缩写 | 解释 |
| ---------- | ---- |
| 业务Tab | 底部导航中除「更多」以外的Tab，包含「首页」位与普通功能Tab，数量上限4个 |
| 首页Tab | 业务Tab中排在第一位的Tab，其内容由用户选定的某个小程序具体功能决定，名称随所选功能动态显示 |
| 更多Tab | 固定在底部最后一位的Tab，不可移除、不可移动位置，点击唤起更多功能弹窗 |
| 具体功能 | 小程序内部的一个可独立进入的功能单元（如用车管理小程序下的“地图页”“常规任务”），是Tab配置的最小粒度，由后端配置 |
| 更多弹窗 | 点击「更多」Tab唤起的底部弹窗，集中展示用户权限范围内所有小程序的具体功能 |
| 编辑态 | 在更多弹窗中点击「编辑」进入的状态，此状态下可对业务Tab进行移除、添加、排序操作 |

## 1. 业务背景与使用角色

### 1.1 业务背景
- 模块定位：将工作台底部导航由静态固定结构改造为用户可自定义的结构，支持用户把高频功能提到底部直达，并通过「更多」集中承载全部权限功能。
- 核心特点：底部Tab内容与顺序由用户配置；「首页」位内容由用户选定的具体功能决定并以该功能名命名；「更多」作为功能全集入口与Tab编辑入口。
- 关联模块关系：与各小程序（用车管理、品质巡查、考勤、审批等）存在跳转关系，Tab/弹窗中的功能项点击后进入对应小程序具体功能页；权限范围数据由权限模块提供。
- 当前现状：原底部Tab为静态「消息/工作台/我的」三项，无自定义能力，用户无法把常用功能提到导航直达。

### 1.2 使用角色

| 角色 | 该模块中的职责 | 客户端 |
| ---- | ------------ | ------ |
| 城市管家用户 | 在自身权限范围内查看、选取、移除、排序底部业务Tab，配置首页功能 | 车机APP |

### 1.3 核心目标与价值

| 目标维度 | 说明 |
| -------- | ---- |
| 效率提升 | 用户可将高频具体功能直达底部Tab，减少进入小程序后再选功能的层级 |
| 个性化 | 首页位与业务Tab组合由用户按习惯自定义 |
| 功能收敛 | 「更多」集中承载权限内全部功能，避免底部Tab数量膨胀 |

## 3. 功能详细设计

### 3.1 F01 首页Tab

#### 3.1.1 功能目标与范围

| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 让用户把最常用的一个具体功能设为首位直达入口，进入APP即可落在该功能 |
| 使用角色 | 城市管家用户 |
| 触发条件 | 用户进入工作台，底部第一位业务Tab即为首页Tab（已配置时） |
| 功能边界 | 首页Tab本质为业务Tab之一，仅位置在第一位；其内容、名称由所绑定的具体功能决定；不含「更多」Tab |
| 成功结果 | 首页Tab显示所绑定功能名与图标，点击进入该功能页 |

#### 3.1.2 使用条件与权限

| 角色 | 可执行操作 | 数据范围 | 前置条件 |
| ---- | ---------- | -------- | -------- |
| 城市管家用户 | 查看、设为首页（拖至最左）、移除首页 | 用户权限范围内的具体功能 | 该功能在用户权限范围内 |

#### 3.1.3 数据与字段规则

**展示与输出字段：**

| 字段 | 业务含义 | 数据来源 | 格式/口径规则 | 空值处理 |
| ---- | -------- | -------- | ------------- | -------- |
| 首页Tab名称 | 首页位显示名 | 所绑定具体功能的名称 | 等于所绑定具体功能名，随功能变化动态更新 | 未绑定时不存在首页Tab |
| 首页Tab图标 | 首页位图标 | 所绑定具体功能的图标 | 等于所绑定具体功能图标 | 未绑定时不存在首页Tab |
| 跳转目标 | 点击首页Tab进入的页面 | 所绑定具体功能的跳转地址 | 与该功能在更多弹窗中单击跳转一致 | — |

#### 3.1.4 业务规则与状态变化

| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| R01-1 | 用户将某业务Tab拖至最左 | 该Tab成为首页Tab | 首页Tab名称/图标/跳转目标更新为该功能 |
| R01-2 | 首页Tab被移除 | 首页位空出，剩余业务Tab向左靠拢，原最左业务Tab成为新首位 | 原首页功能回到更多弹窗 |
| R01-3 | 首页Tab被拖离最左 | 该Tab变为普通业务Tab，新到达最左的Tab成为首页Tab | 首页Tab名称随之更新 |

#### 3.1.5 交互流程

1. 用户进入工作台，底部第一位业务Tab即为当前首页Tab。
2. 系统按当前配置渲染首页Tab名称、图标。
3. 用户点击首页Tab。
4. 处理结果：
   - 成功 → 跳转至首页Tab所绑定的具体功能页 + 后续可在该功能内操作
   - 失败（功能已无权限或目标不可达） → 提示失败原因 + 保留在工作台

#### 3.1.6 异常处理

| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 首页功能权限丢失 | 用户权限变化致首页Tab所绑功能不在权限范围 | 演示阶段不处理；正式阶段应将该Tab移回更多弹窗或提示重新选择 | — | — |

### 3.2 F02 更多Tab与功能弹窗

#### 3.2.1 功能目标与范围

| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 以弹窗集中承载用户权限范围内全部小程序的具体功能，支持单击直达，并提供编辑入口 |
| 使用角色 | 城市管家用户 |
| 触发条件 | 用户点击底部末位「更多」Tab |
| 功能边界 | 弹窗展示功能全集与编辑入口；单击跳转属本功能，编辑操作详见F03 |
| 成功结果 | 弹窗展示按小程序分组、一行四宫格的全部权限功能；单击进入对应功能 |

#### 3.2.2 使用条件与权限

| 角色 | 可执行操作 | 数据范围 | 前置条件 |
| ---- | ---------- | -------- | -------- |
| 城市管家用户 | 打开弹窗、单击功能跳转、进入编辑态 | 用户权限范围内全部小程序及其具体功能 | 至少拥有一个小程序权限 |

#### 3.2.3 数据与字段规则

**展示与输出字段：**

| 字段 | 业务含义 | 数据来源 | 格式/口径规则 | 空值处理 |
| ---- | -------- | -------- | ------------- | -------- |
| 小程序分组 | 功能按所属小程序归类展示 | 功能所属小程序字段 | 每个小程序为一个分组，分组内功能一行四宫格排列 | 无权限小程序不展示 |
| 功能图标 | 功能入口图标 | 具体功能配置的图标 | 与该功能在底部Tab展示时一致 | — |
| 功能名称 | 功能入口名称 | 具体功能配置的名称 | 与该功能在底部Tab展示时一致 | — |
| 是否已在底部Tab | 标识该功能是否已占用业务Tab位 | 当前Tab配置 | 已占用与未占用功能均展示在弹窗；同一具体功能不可重复占位（见4.1） | — |

#### 3.2.4 业务规则与状态变化

| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| R02-1 | 打开弹窗 | 展示用户权限范围内全部小程序的具体功能，按小程序分组、一行四宫格 | 弹窗列表加载 |
| R02-2 | 单击某功能 | 直接跳转进入该功能页 | 离开弹窗进入功能页 |
| R02-3 | 点击「编辑」 | 进入编辑态（见F03） | 弹窗切换为编辑态 |

#### 3.2.5 交互流程

1. 用户点击底部末位「更多」Tab。
2. 系统加载用户权限范围内全部小程序的具体功能。
3. 弹窗以小程序分组、一行四宫格展示功能图标与名称。
4. 处理结果：
   - 单击功能 → 跳转进入该功能页 + 弹窗关闭
   - 点击「编辑」 → 进入编辑态 + 弹窗切换为编辑态
   - 点击弹窗外/关闭 → 弹窗关闭 + 不改变Tab配置

#### 3.2.6 异常处理

| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 无任何权限功能 | 用户权限范围为空 | 弹窗展示空状态 | 提示无可配置功能 | 联系管理员分配权限 |
| 功能跳转失败 | 目标页不可达 | 阻止跳转 | 提示该功能暂不可用 | 保留弹窗打开 |

### 3.3 F03 Tab编辑（移除/添加/排序）

#### 3.3.1 功能目标与范围

| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 让用户自定义底部业务Tab的组成与顺序，包含移除、添加、排序，完成后保存生效 |
| 使用角色 | 城市管家用户 |
| 触发条件 | 在更多弹窗中点击「编辑」进入编辑态 |
| 功能边界 | 仅可对业务Tab操作；「更多」Tab不可移除、不可移动；编辑未点「完成」不保存 |
| 成功结果 | 点击「完成」后底部业务Tab按编辑结果更新并保存配置 |

#### 3.3.2 使用条件与权限

| 角色 | 可执行操作 | 数据范围 | 前置条件 |
| ---- | ---------- | -------- | -------- |
| 城市管家用户 | 移除业务Tab、添加业务Tab、拖拽排序、保存 | 用户权限范围内具体功能 | 已进入编辑态 |

#### 3.3.3 数据与字段规则

**输入与查询条件：**

| 字段/条件 | 业务含义 | 取值方式或数据来源 | 默认值 | 校验/匹配规则 |
| --------- | -------- | -------------------- | ------ | ------------- |
| 待添加功能 | 从弹窗长按选取加入底部Tab的功能 | 更多弹窗功能列表 | 无 | 同一具体功能不可重复占位（见4.1） |
| Tab位置 | 业务Tab在底部的排列顺序 | 用户拖拽决定 | 维持进入编辑前顺序 | 「更多」固定末位不参与排序 |

#### 3.3.4 业务规则与状态变化

| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| R03-1 | 编辑态下业务Tab显示删除角标 | 除「更多」外业务Tab可被移除 | 业务Tab进入可删除状态 |
| R03-2 | 点击某业务Tab删除角标 | 该Tab移除，回到更多弹窗；除「更多」外至少保留1个业务Tab | 业务Tab数量减1，原功能回到弹窗 |
| R03-3 | 业务Tab仅剩1个时再点删除 | 禁止移除 | 不发生数量变化 |
| R03-4 | 弹窗中长按某功能 | 将该功能添加为底部业务Tab | 业务Tab数量加1，该功能在弹窗标记为已占用 |
| R03-5 | 拖拽业务Tab改变顺序 | 顺序按拖拽结果更新；拖至最左即为设为首页 | 业务Tab顺序与首页位更新 |
| R03-6 | 点击「完成」 | 保存当前编辑结果并退出编辑态 | 底部Tab按新配置渲染 |
| R03-7 | 编辑中未点「完成」关闭弹窗/退出 | 放弃本次改动，恢复进入编辑前配置 | Tab配置回滚 |

#### 3.3.5 交互流程

1. 用户在更多弹窗点击「编辑」进入编辑态。
2. 系统将底部业务Tab置为可删除、可拖拽状态，「更多」Tab保持固定。
3. 用户执行以下操作之一或组合：
   - 点击某业务Tab删除角标移除该Tab；
   - 在弹窗中长按某功能将其添加为业务Tab；
   - 拖拽业务Tab调整顺序（拖至最左即设为首页）。
4. 用户点击「完成」。
5. 处理结果：
   - 成功 → 保存编辑后的业务Tab组成与顺序 + 退出编辑态 + 底部Tab按新配置渲染
   - 校验失败（如仅剩1个仍尝试移除） → 阻止操作 + 提示至少保留1个 + 维持当前状态
   - 未点「完成」退出 → 放弃改动 + 恢复原配置 + 底部Tab不变

#### 3.3.6 异常处理

| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 移除至最后一个业务Tab | 业务Tab仅剩1个时点删除 | 禁止移除 | 提示至少保留1个Tab | 维持该Tab |
| 添加已达业务Tab上限 | 业务Tab已达4个再长按添加 | 演示阶段不做特殊处理；正式阶段应阻止添加 | — | — |
| 编辑中异常退出 | 未点完成即关闭 | 放弃改动 | 不提示或轻提示改动未保存 | 恢复进入前配置 |

#### 3.3.7 外部依赖

| 依赖模块/服务 | 输入 | 输出 | 调用时机 | 失败处理 |
| ----------- | ---- | ---- | -------- | -------- |
| 权限模块 | 用户标识 | 用户权限范围内的小程序及具体功能清单 | 打开弹窗、保存配置时 | 演示阶段用静态数据兜底 |

### 3.4 F04 Tab配置数据模型

#### 3.4.1 功能目标与范围

| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 定义底部业务Tab配置的数据结构，支撑渲染、编辑、保存与回滚 |
| 使用角色 | 系统 |
| 触发条件 | 进入工作台渲染底部Tab、进入编辑态、保存配置时 |
| 功能边界 | 仅定义数据结构与字段规则，不含持久化实现（演示阶段不持久化） |
| 成功结果 | 系统按数据模型正确渲染与更新底部Tab |

#### 3.4.3 数据与字段规则

**Tab配置项字段：**

| 字段 | 业务含义 | 数据来源 | 格式/口径规则 | 空值处理 |
| ---- | -------- | -------- | ------------- | -------- |
| tabId | Tab配置项唯一标识 | 系统生成 | 唯一 | 不可空 |
| 功能标识(funcKey) | 绑定的具体功能标识 | 具体功能配置 | 同一具体功能不可重复占位（见4.1） | 不可空 |
| 所属小程序(appKey) | 该功能所属小程序 | 具体功能配置 | 用于弹窗分组 | 不可空 |
| 显示名称(name) | Tab显示名 | 具体功能名称 | 等于所绑定功能名，随功能动态更新 | 不可空 |
| 图标(icon) | Tab图标 | 具体功能图标 | 等于所绑定功能图标 | 不可空 |
| 跳转目标(target) | 点击进入的页面地址 | 具体功能跳转地址 | 与弹窗单击跳转一致 | 不可空 |
| 顺序(order) | 业务Tab排列顺序 | 用户拖拽决定 | 从左至右递增；最左为首页位 | 不可空 |

**配置集合规则：**
- 底部Tab = 业务Tab集合（按order排序）+ 末位固定「更多」Tab。
- 业务Tab数量上限4个；「更多」不计入业务Tab数量。
- 初始默认配置（用户未自定义时）：业务Tab为「消息、工作台、我的」三项，末位为「更多」。

#### 3.4.4 业务规则与状态变化

| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| R04-1 | 渲染底部Tab | 业务Tab按order升序排列，「更多」固定末位 | 底部Tab渲染 |
| R04-2 | 保存编辑结果 | 更新业务Tab集合与order | 配置更新生效 |
| R04-3 | 放弃编辑 | 回滚至编辑前快照 | 配置不变 |
| R04-4 | 跳转其他页面 | 读取 sessionStorage 配置渲染，配置保留 | 底部Tab按存储配置渲染 |

## 4. 业务规则汇总

### 4.1 唯一性规则
- 同一具体功能（funcKey）在底部业务Tab中不可重复占位，即一个功能最多占用一个业务Tab位。
- 已占用业务Tab的功能在更多弹窗中标记为已占用，编辑态下不可再次添加（演示阶段由不可重复规则约束）。

### 4.2 删除规则
- 可删除对象：业务Tab（含首页Tab）。
- 不可删除对象：「更多」Tab。
- 删除方式：编辑态下点击业务Tab删除角标。
- 下限校验：除「更多」外至少保留1个业务Tab，仅剩1个时禁止再删除。
- 删除后行为：被删Tab所绑功能回到更多弹窗（标记为未占用）。

### 4.3 状态流转
- Tab项占用状态枚举值：已占用（当前在底部业务Tab中）、未占用（仅在更多弹窗中）。
- 流转：未占用 →（长按添加）→ 已占用 →（删除移除）→ 未占用。
- 编辑态枚举值：非编辑态、编辑态；流转：非编辑态 →（点编辑）→ 编辑态 →（点完成）→ 非编辑态；编辑态 →（未保存退出）→ 非编辑态（配置回滚）。

### 4.4 字段联动规则

| 触发字段 | 触发条件 | 联动行为 |
| -------- | -------- | -------- |
| 业务Tab顺序(order) | 某Tab被拖至最左 | 该Tab名称/图标/跳转目标作为首页位展示 |
| funcKey绑定 | 业务Tab绑定某功能 | Tab名称、图标、跳转目标随该功能联动更新 |
| 业务Tab数量 | 添加/移除 | 弹窗中该功能的占用标记同步更新 |

### 4.5 计算规则
- 首页位判定：业务Tab按order升序排列后，第一位即为首页Tab，其显示内容由该Tab所绑功能决定。
- 业务Tab数量上限：4个；底部Tab总数 = 业务Tab数量 + 1（更多）≤ 5。

### 4.6 校验规则

| 校验场景 | 校验规则 | 失败处理 |
| -------- | -------- | -------- |
| 添加业务Tab | funcKey不可与现有业务Tab重复 | 阻止添加 |
| 移除业务Tab | 移除后业务Tab数量≥1 | 阻止移除并提示 |
| 业务Tab数量上限 | 业务Tab数量≤4 | 演示阶段不做特殊处理 |

### 4.7 初始默认与持久化规则
- 初始默认业务Tab：消息、工作台、我的；末位更多。
- 演示阶段用 sessionStorage 跨页保留配置：编辑保存后跳转其他页面配置不变，关闭浏览器标签页后丢失恢复默认。
- 编辑保存当前会话生效，全站底部Tab共享同一配置；各页面均支持编辑。
