## 1. 业务背景与使用角色

### 1.1 业务背景
- 模块定位：车机APP是巡查员-机动车的主要任务执行载体，聚焦执行任务的实时显示与问题查看，与手机移动端共用一套数据库
- 核心特点：以16:9横屏承载，遵循低分心、快速扫读、稳定布局的车机交互原则；任务执行与问题展示在车机完成，问题上报由车载外设+t-box负责，车机不承担上报
- 关联模块关系：与环卫云平台共用任务与问题数据库；与手机移动端APP同源数据，手机端负责扫码绑车与日常事务办理，车机端负责任务执行
- 业务痛点：原巡查通过纸质/对讲机/微信上报，缺乏完整数字化执行体系；机动车巡查若在手机端执行存在行车安全隐患，故任务执行下沉至车机

### 1.2 使用角色

| 角色 | 该模块中的职责 | 客户端 |
| ---- | ------------ | ------ |
| 巡查员-机动车 | 扫码绑车、执行巡查任务、查看问题、交车、查看今日回顾 | 车机APP |

### 1.3 核心目标与价值

| 目标维度 | 说明 |
| -------- | ---- |
| 安全执行 | 机动车巡查任务在车机横屏执行，降低行车中操作手机的安全风险 |
| 实时展示 | 任务执行过程中实时展示任务作业区域、重点点位、车辆位置、实际轨迹、作业里程与作业时长 |
| 闭环管理 | 覆盖绑车→推荐任务详情（可打开今日任务清单）→执行→结束返回清单→交车→今日回顾的完整当日闭环 |
| 问题可见 | 执行过程中可查看由外设上报的问题详情、处理结果与处理日志 |

## 3. 功能详细设计

### 3.1 C01 车辆绑定

#### 3.1.1 功能目标与范围

| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 在车机未绑定用户时展示二维码，供巡查员用手机APP扫码完成人车使用关系绑定，绑定后进入推荐任务详情 |
| 使用角色 | 巡查员-机动车 |
| 触发条件 | 车机APP启动且当前车辆未绑定用户 |
| 功能边界 | 包含二维码展示、绑车说明、扫码后人车关系校验、绑定记录；不含交车（见3.5） |
| 成功结果 | 完成人员与车辆使用关系绑定，记录人员+时间+车辆+位置，进入推荐任务详情 |

#### 3.1.2 使用条件与权限

| 角色 | 可执行操作 | 数据范围 | 前置条件 |
| ---- | ---------- | -------- | -------- |
| 巡查员-机动车 | 扫码绑定 | 当前车辆 | 车机未绑定用户 |

#### 3.1.3 数据与字段规则

**展示字段：**

| 字段 | 业务含义 | 数据来源 | 格式/口径规则 | 空值处理 |
| ---- | -------- | -------- | ------------- | -------- |
| 车辆二维码 | 供手机APP扫码的绑定凭据 | 车机生成 | 关联当前车辆标识 | 不为空 |
| 绑车说明 | 指引用户完成扫码绑车 | 固定文案 | 静态文本 | 不为空 |
| 绑定人员 | 完成绑定的巡查员 | 扫码结果 | 姓名 | 扫码前为空 |
| 绑定时间 | 完成扫码绑车的时间 | 系统 | yyyy-MM-dd HH:mm | 扫码前为空 |
| 绑定位置 | 完成绑车时的车辆位置 | 车机定位 | 经纬度+位置描述 | 定位失败标注未知 |

#### 3.1.4 业务规则与状态变化

| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| C01-R1 | 车机启动 | 若车辆未绑定用户，显示绑定二维码页 | 进入绑定态 |
| C01-R2 | 手机APP扫码完成 | 系统进行人车关系校验 | 校验通过→绑定成功；不通过→停留在绑定页 |

#### 3.1.5 交互流程

1. 巡查员启动车机APP，系统判定当前车辆未绑定用户。
2. 系统展示车辆二维码与绑车说明。
3. 巡查员使用手机APP扫描二维码。
4. 系统进行人车关系校验。
5. 处理结果：
   - 成功 → 完成人员与车辆使用关系绑定，记录人员+时间+车辆+位置，进入推荐任务详情。
   - 失败 → 提示失败原因，停留在绑定二维码页。

#### 3.1.6 异常处理

| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 人车关系校验失败 | 扫码后人车关系不成立 | 停留在绑定页 | 提示失败原因 | 重新扫码或检查人车配置 |
| 定位异常 | 绑定时车机定位不可用 | 绑定可继续，位置标注为未知 | 提示定位异常 | 恢复定位后下次绑定补全 |

#### 3.2.1 功能目标与范围

| 项目 | 说明 |

| 触发条件 | 车辆已绑定用户 |

#### 3.2.2 使用条件与权限

| 角色 | 可执行操作 | 数据范围 | 前置条件 |

#### 3.2.4 业务规则与状态变化

| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| C02-R1 | 进入任务首页 | 加载当前绑定用户当日任务；优先选中进行中任务，其次选中待开始任务，任务清单默认收起；任务按进行中、待开始、已完成分组排序，同组按计划时间排序 | 默认展示选中任务详情；用户打开右侧清单后，展示任务区域、状态、作业类型、计划时间与问题数量（如有） |
| C02-R2 | 点击任务卡片 | 打开对应任务详情；地图展示该任务作业区域、重点点位、当前车辆位置与实际轨迹（如有），不展示计划路线 | 任务详情与地图按所选任务加载 |
| C02-R3 | 存在进行中任务 | 进行中任务置顶并作为推荐任务；进入详情后仅提供结束任务操作 | 不允许其他待开始任务进入执行态 |
| C02-R4 | 点击今日任务入口 | 打开今日任务清单，同时展示当日全部任务作业区域；再次点击同一入口时收起清单并恢复当前选中任务地图 | 任务清单与任务区域总览同步显示或收起 |
| C02-R5 | 点击今日问题入口 | 打开当前绑定用户当日全部上报问题，可按问题状态筛选；同时展示全部问题点位，点位标识按问题状态区分；再次点击同一入口时收起清单并恢复当前选中任务地图 | 问题清单与问题点位总览同步显示或收起；点击问题卡片或点位进入对应问题详情 |
| C02-R6 | 今日任务或今日问题清单已打开 | 用户点击另一类清单入口时，关闭原清单及其地图总览，打开目标清单及对应地图总览 | 同一时刻仅存在一种清单与一种地图总览 |
| C02-R7 | 从今日回顾打开今日问题清单 | 加载交车前绑定用户在当日上报的问题；仅允许查看问题清单、问题点位和问题详情，不开放任务执行操作 | 关闭问题清单后返回今日回顾 |

#### 3.2.5 交互流程

1. 巡查员扫码绑定成功，系统进入默认选中的推荐任务详情。
2. 系统加载当前绑定用户今日巡查任务，优先选中进行中任务，其次选中待开始任务；右侧任务清单默认收起。
3. 巡查员按需打开今日任务清单；清单按进行中、待开始、已完成分组展示，地图同步展示全部任务作业区域；点击同一入口可收起清单和总览，点击问题入口则切换至问题清单与问题点位总览。
4. 巡查员按需打开今日问题清单；系统默认展示全部当日问题，巡查员可按待确认、待分配、待处理、已完成筛选，地图同步展示全部问题点位；点击同一入口可收起清单和总览。
5. 巡查员点击任务卡片后系统切换对应任务详情；点击问题卡片或问题点位后系统打开对应问题详情。
6. 任务详情按任务名称、状态、任务类型、作业类型、计划时段、执行指标、作业要求和关联问题展示；待开始、进行中任务展示作业要求，已完成任务不展示作业要求；关联问题统一展示问题编号、状态、位置和当前节点；地图展示作业区域、重点点位、当前车辆位置与实际轨迹（如有）。
7. 待开始任务可点击开始任务；进行中任务详情仅可结束任务；已完成任务可返回今日任务列表并保留该任务为当前选中项。
8. 处理结果：
   - 成功 → 进入任务执行页。
   - 失败 → 提示失败原因，停留在首页。

#### 3.2.6 异常处理

| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 无待办任务 | 当日无巡查任务 | 展示空任务状态 | 提示无待办任务 | 任务派发后刷新 |
| 定位异常 | 车机定位不可用 | 保留最后有效位置并标注更新时间 | 提示定位异常 | 恢复定位后实时刷新 |

#### 3.3.5 交互流程

1. 巡查员在任务详情点击开始任务，系统校验开始任务条件。
2. 校验通过，进入任务执行页。
3. 系统在左侧地图展示作业区域、重点点位、持续更新的当前车辆位置与实际轨迹，不展示计划路线，并展示作业里程、作业时长与问题上报数；右屏展示当前任务信息和作业要求摘要，再展示上报问题清单。
4. 收到外设问题上报时，系统为每条问题在地图增加对应问题点位，按上报时间倒序写入清单并刷新问题上报数。
5. 巡查员点击地图问题点位或右侧问题卡片。
6. 系统打开问题详情页，展示问题信息、处理结果与处理日志。
7. 行驶中收到普通新派发任务时，系统展示轻提醒并语音播报；巡查员点击查看任务后进入与今日任务清单一致的该任务详情，未操作时提醒在展示1分钟后自动关闭，当前执行任务保持进行中。
8. 巡查员点击结束任务，系统进行任务完成情况校验。
9. 处理结果：
   - 校验通过且有待开始任务 → 结束当前任务，提示"任务已结束，已返回今日任务列表"，列表刷新当前任务状态，巡查员自行选择下一条任务。
   - 校验通过且无待开始任务 → 结束当前任务，返回今日任务列表并提示"今日任务均已完成，可在归还车辆后交车"。
   - 校验不通过 → 提示阻断原因，停留在任务执行页。

#### 3.3.6 异常处理

| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |

| C06-R1 | 进入今日回顾 | 展示交车成功提示与当日回顾指标 | 无状态变化 |
| C06-R2 | 展示待办 | 展示今日未完成巡查任务与明日待办巡查任务；明日待办任务状态统一标记为待开始 | 无状态变化 |
| C06-R3 | 点击问题上报数或查看今日问题 | 打开既有今日问题清单，按交车前绑定用户和当日范围加载问题 | 进入只读问题清单；关闭后返回今日回顾 |

#### 3.6.5 交互流程

1. 巡查员交车成功，系统进入今日回顾页。
2. 展示交车成功提示。
3. 展示当日回顾指标：任务完成数、轨迹里程、出车时长、问题上报数。
4. 展示今日未完成巡查任务。
5. 展示明日待办巡查任务。
6. 巡查员点击问题上报数或查看今日问题，系统打开既有今日问题清单（只读）。
7. 巡查员关闭问题清单后返回今日回顾。

#### 3.6.6 异常处理

| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 无今日未完成任务 | 当日任务全部完成 | 今日未完成区域展示空态 | 提示无未完成任务 | 无需恢复 |
| 无明日待办任务 | 次日无计划任务 | 明日待办区域展示空态 | 提示无明日待办 | 任务派发后刷新 |
| 指标数据加载失败 | 云端服务不可用 | 保留最后有效数据并标注更新时间 | 提示数据异常 | 服务恢复后刷新 |

#### 3.6.7 外部依赖

| 依赖模块/服务 | 输入 | 输出 | 调用时机 | 失败处理 |
| ----------- | ---- | ---- | -------- | -------- |
| 云端任务服务 | 用户+日期 | 当日完成与未完成任务、明日待办任务 | 进入今日回顾 | 保留最后有效数据并标注更新时间 |
| 云端问题服务 | 交车前绑定用户+日期 | 当日外设上报问题数与问题清单 | 进入今日回顾或查看今日问题 | 保留最后有效数据并标注更新时间 |
| 轨迹计算服务 | 当日绑车到交车 | 轨迹里程与出车时长 | 进入今日回顾 | 标注数据异常 |

## 4. 业务规则汇总

### 4.1 状态流转

**任务状态机：** 待开始 → 进行中 → 已完成，与常规任务、动态任务状态机一致。
**问题状态机：** 待确认 → 待分配 → 待处理 → 已完成，以环卫云平台状态机为准。注：需求7.3.3问题卡片中的"已分配"统一按本状态机的"待处理"呈现。

### 4.2 校验规则

| 校验场景 | 校验条件 | 通过结果 | 不通过结果 |
| -------- | -------- | -------- | -------- |
| 绑定扫码 | 人车关系校验 | 完成绑定并进入推荐任务详情，任务清单可按需打开 | 提示失败原因并停留在绑定页 |
| 开始任务 | 满足常规任务开始条件（时间范围、无其他进行中任务、位置在路段范围） | 进入任务执行页 | 提示阻断原因并停留 |
| 结束任务 | 任务完成情况校验 | 结束任务并返回今日任务列表，刷新当前任务状态 | 提示阻断原因并停留 |
| 交车 | 未完成任务校验（存在进行中未结束任务则阻断） | 展示交车二维码 | 提示存在进行中任务并显示该任务 |

### 4.3 计算规则

| 指标 | 计算口径 |
| ---- | -------- |
| 作业里程 | 开始任务时间到当前时间的轨迹长度，单位km，保留2位小数 |
| 作业时长 | 当前时间减开始任务时间，单位分钟，保留整数 |
| 轨迹里程 | 当日绑车到交车的轨迹总里程，单位km，保留2位小数 |
| 出车时长 | 当日绑车到交车的时长，单位分钟，保留整数 |
| 问题上报数 | 本次任务/当日通过外设上报的问题数量 |

### 4.4 字段联动规则

| 触发字段 | 触发条件 | 联动行为 |
| -------- | -------- | -------- |
| 任务卡片 | 在今日任务列表点击任务卡片 | 打开对应任务详情并加载该任务地图数据 |
| 进行中任务 | 进入任务首页存在进行中任务 | 进行中任务作为默认选中推荐任务，并在打开清单后置顶 |
| 新派发任务 | 任务执行中收到普通新任务 | 展示轻提醒并语音播报；点击查看任务进入与今日任务清单一致的对应任务详情，提醒展示1分钟后自动关闭 |
| 结束任务 | 任务完成校验通过 | 返回今日任务列表，当前任务更新为已完成，不自动进入下一任务 |

### 4.5 记录规则

| 记录节点 | 记录字段 | 说明 |
| -------- | -------- | ---- |
| 绑定 | 人员+时间+车辆+位置 | 扫码绑定完成时记录 |
| 交车 | 人员+时间+车辆+位置 | 扫码交车完成时记录 |

### 4.6 驾驶安全规则

| 场景 | 规则 |
| ---- | ---- |
| 行驶受限 | 仅保留高优先级信息、语音反馈与少量大尺寸操作，禁用输入、长滚动、复杂筛选与高风险操作 |
| 不可用操作 | 就地禁用并说明原因，不使用全屏蒙层遮挡核心信息 |
| 语音与视觉同步 | 高优先级状态使用语音与视觉摘要同步反馈，语音不得是获取关键信息的唯一方式 |
