## 1. 业务背景与使用角色

### 1.1 业务背景
- 模块定位：车机APP是巡查员-机动车的主要任务执行载体，聚焦执行任务的实时显示与事件查看，与手机移动端共用一套数据库
- 核心特点：以16:9横屏承载，遵循低分心、快速扫读、稳定布局的车机交互原则；任务执行与事件展示在车机完成，事件上报由车载外设+t-box负责，车机不承担上报
- 关联模块关系：与环卫云平台共用任务与事件数据库；与手机移动端APP同源数据，手机端负责扫码绑车与日常事务办理，车机端负责任务执行
- 业务痛点：原巡查通过纸质/对讲机/微信上报，缺乏完整数字化执行体系；机动车巡查若在手机端执行存在行车安全隐患，故任务执行下沉至车机

### 1.2 使用角色

| 角色 | 该模块中的职责 | 客户端 |
| ---- | ------------ | ------ |
| 巡查员-机动车 | 扫码绑车、执行巡查任务、查看事件、交车、查看今日回顾 | 车机APP |

### 1.3 核心目标与价值

| 目标维度 | 说明 |
| -------- | ---- |
| 安全执行 | 机动车巡查任务在车机横屏执行，降低行车中操作手机的安全风险 |
| 实时展示 | 任务执行过程中实时展示任务作业区域、重点点位、车辆位置、实际轨迹、作业里程与作业时长 |
| 闭环管理 | 覆盖绑车→推荐任务详情（可打开今日任务清单）→执行→结束返回清单→交车→今日回顾的完整当日闭环 |
| 事件可见 | 执行过程中可查看由外设上报的事件发生信息与关联任务 |

## 3. 功能详细设计

### 3.1 C01 车辆绑定

#### 3.1.1 功能目标与范围

| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 在车机未绑定用户时，先确保当前车辆已录入唯一的车辆牌照；牌照录入完成后展示二维码，供巡查员用手机APP扫码完成人车使用关系绑定，绑定后进入推荐任务详情 |
| 使用角色 | 巡查员-机动车 |
| 触发条件 | 车机APP启动且当前车辆未绑定用户 |
| 功能边界 | 包含车辆牌照手动录入与修改、牌照合法性与唯一性校验、二维码展示、绑车说明、扫码后人车关系校验、绑定记录，以及手机端主动断开后的退出处理；当前仅支持大陆民用普通号牌及新能源号牌，不含特殊车辆号牌、拍照识别、车架号录入、交车（见3.5） |
| 成功结果 | 完成人员与车辆使用关系绑定，记录人员+时间+车辆+位置，进入推荐任务详情 |

#### 3.1.2 使用条件与权限

| 角色 | 可执行操作 | 数据范围 | 前置条件 |
| ---- | ---------- | -------- | -------- |
| 巡查员-机动车 | 录入或修改车辆牌照、扫码绑定 | 当前车辆 | 车机未绑定用户；扫码绑定还需已录入车辆牌照 |

#### 3.1.3 数据与字段规则

**展示字段：**

| 字段 | 业务含义 | 数据来源 | 格式/口径规则 | 空值处理 |
| ---- | -------- | -------- | ------------- | -------- |
| 车辆二维码 | 供手机APP扫码的绑定凭据 | 车机生成 | 关联当前车辆标识 | 不为空 |
| 车辆牌照 | 当前车辆用于绑定与交车记录的牌照信息 | 车辆基础信息 | 手动录入；忽略空格及分隔点；仅接受大陆民用普通号牌（7位）或新能源号牌（8位），英文字母不允许I、O；格式通过后再按平台内车辆数据校验唯一性 | 未录入时为空，并阻断扫码绑定 |
| 绑车说明 | 指引用户完成扫码绑车 | 固定文案 | 静态文本 | 不为空 |
| 绑定人员 | 完成绑定的巡查员 | 扫码结果 | 姓名 | 扫码前为空 |
| 绑定时间 | 完成扫码绑车的时间 | 系统 | yyyy-MM-dd HH:mm | 扫码前为空 |
| 绑定位置 | 完成绑车时的车辆位置 | 车机定位 | 经纬度+位置描述 | 定位失败标注未知 |

#### 3.1.4 业务规则与状态变化

| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| C01-R1 | 车机启动 | 若车辆未绑定用户且未录入牌照，阻断二维码与扫码绑定，提示录入牌照 | 进入待录入牌照状态 |
| C01-R2 | 录入或修改牌照后保存 | 系统依次校验牌照非空、合法格式、未被其他车辆使用；修改时唯一性校验排除当前车辆自身 | 校验通过→保存最新牌照并进入可绑定状态；校验不通过→保留当前输入并提示原因 |
| C01-R3 | 车辆已录入牌照 | 在绑定页右上角提供修改牌照入口，修改成功后不解除当前人车使用关系 | 车辆牌照更新 |
| C01-R4 | 手机APP扫码完成 | 系统进行人车关系校验 | 校验通过→绑定成功；不通过→停留在绑定页 |
| C01-R5 | 手机端确认断开当前车机连接 | 系统向与当前车辆关联的车机发送退出通知；车机收到通知后立即结束登录，不执行交车校验 | 清除当前人车使用关系，车机跳转至绑定页；后续使用需重新扫码绑定 |

#### 3.1.5 交互流程

1. 巡查员启动车机APP，系统判定当前车辆未绑定用户并读取车辆牌照。
2. 若未录入牌照，系统提示录入车辆牌照并阻断二维码与扫码绑定；巡查员手动输入牌照并保存。
3. 系统先进行牌照合法性校验，再进行唯一性校验。校验通过后保存牌照并展示车辆二维码与绑车说明；任一校验失败时保留输入并提示原因。
4. 已录入牌照时，巡查员可通过绑定页右上角入口修改牌照；保存后返回绑定页并展示最新牌照。
5. 巡查员使用手机APP扫描二维码。
6. 系统进行人车关系校验。
7. 处理结果：
   - 成功 → 完成人员与车辆使用关系绑定，记录人员+时间+车辆+位置，进入推荐任务详情。
   - 失败 → 提示失败原因，停留在绑定二维码页。
8. 已绑定期间，若手机端确认断开当前车机连接，车机接收退出通知后结束登录并返回绑定页。

#### 3.1.6 异常处理

| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 人车关系校验失败 | 扫码后人车关系不成立 | 停留在绑定页 | 提示失败原因 | 重新扫码或检查人车配置 |
| 牌照未录入 | 进入绑定页时当前车辆无牌照 | 阻断二维码与扫码绑定 | 提示先录入车辆牌照 | 进入牌照录入并保存 |
| 牌照重复 | 保存的牌照已被其他车辆使用 | 不保存，保留当前输入 | 提示该牌照已被其他车辆录入 | 核对后重新输入 |
| 牌照格式不合法 | 保存的牌照不符合大陆民用普通号牌或新能源号牌格式 | 不保存，保留当前输入 | 提示输入合法的大陆民用车辆牌照 | 按支持的号牌格式重新输入 |
| 定位异常 | 绑定时车机定位不可用 | 绑定可继续，位置标注为未知 | 提示定位异常 | 恢复定位后下次绑定补全 |
| 手机端主动断开 | 手机端确认断开当前车机连接 | 结束当前登录会话并回到绑定页，不执行交车校验 | 提示移动端已断开连接 | 使用手机端重新扫码绑定 |

### 3.2 C02 今日任务、今日事件与任务详情

#### 3.2.1 功能目标与范围

| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 扫码绑定成功后默认展示当前绑定用户的推荐任务详情；巡查员可在同一页面分别打开今日巡查任务清单和今日上报事件清单，完成任务切换或跨任务事件查看 |
| 使用角色 | 巡查员-机动车 |
| 触发条件 | 车辆已绑定用户 |
| 功能边界 | 包含默认任务详情、今日任务清单、今日事件清单、任务地图展示、开始任务入口；今日回顾来源可只读打开今日事件清单；任务执行态见3.3；不包含跨日期任务与事件查询 |
| 成功结果 | 巡查员查看推荐或清单中指定任务并开始任务，进入任务执行页 |

#### 3.2.2 使用条件与权限

#### 3.2.5 交互流程

1. 巡查员扫码绑定成功，系统进入默认选中的推荐任务详情。
2. 系统加载当前绑定用户今日巡查任务，优先选中进行中任务，其次选中计划时间最早的待接收任务；右侧任务清单默认收起。
3. 巡查员按需打开今日任务清单；清单按待接收、进行中、已完成、已转派、已终止、已失效分组展示，地图同步展示全部任务区域名称及事件聚合；点击聚合项展开具体事件点位。
4. 巡查员按需打开今日事件清单；系统按待判别、待分配、待处理、处理中、待核查、已完成分组展示全部当日事件，地图同步展示全部事件点位。
5. 巡查员点击任务卡片后系统切换对应任务详情；点击事件卡片主体后地图聚焦对应点位，点击卡片圆形进入图标或事件点位后系统打开对应事件详情。
6. 任务详情展示任务编号、区域名称、任务日期、作业时间、作业资源、作业类型、状态、执行指标和关联事件；待接收任务不展示执行指标；关联事件展示事件地点、上报时间、发现类型、状态、问题类型和事件描述，不展示事件编号；地图展示作业区域、重点点位、车辆与手机位置及轨迹（如有）。
7. 待接收任务详情提供“开始任务”“返回任务列表”和“更多”操作；进行中任务详情提供“结束任务”“返回任务列表”和“更多”操作；更多操作仅包含“转派任务”和“终止任务”。
8. 巡查员选择转派或终止后，系统打开原因填写流程；转派填写转派原因，终止填写终止原因，原因不能为空。提交成功后分别更新为“已转派”或“已终止”，记录操作原因和操作时间，并返回今日任务列表；取消或校验失败时保持原任务状态。
9. 已完成、已转派、已终止、已失效任务详情仅提供“返回任务列表”单按钮。
10. 首页地图右上固定展示今日任务、今日事件圆头胶囊文字入口，任务与事件角标固定在对应入口右上方并使用红底白字；打开任务或事件清单时，整个入口显示蓝底白字选中态。右下固定展示复位、辅助设施图层、全屏图标工具，地图辅助工具不与业务入口混排。退出登录（扫码交车解绑）入口固定在顶栏右上角 meta 右侧，点击后进入扫码交车页。
11. 处理结果：
   - 成功 → 进入任务执行页。
   - 失败 → 提示失败原因，停留在首页。

#### 3.2.6 异常处理

| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 无待办任务 | 当日无巡查任务 | 展示空任务状态 | 提示无待办任务 | 任务派发后刷新 |
| 定位异常 | 车机定位不可用 | 保留最后有效位置并标注更新时间 | 提示定位异常 | 恢复定位后实时刷新 |
| 操作原因为空 | 转派或终止提交时未填写原因 | 阻止提交并保留已填写内容 | 提示必须填写对应操作原因 | 补充原因后重新提交 |
| 任务状态已变化 | 提交前任务已被其他流程更新为终态 | 阻止本次操作并刷新任务状态 | 提示任务状态已变化 | 返回任务列表后重新查看 |

#### 3.3.4 业务规则与状态变化

| -------- | -------- | -------- | ------------- |
| C03-R1 | 任务执行中 | 地图展示作业区域、重点点位、车辆与手机位置及实时轨迹；右屏展示当前任务信息、紧凑执行摘要和事件清单，完整任务字段通过任务信息入口查看；紧凑执行摘要仅展示开始时间、作业里程与作业时长；事件按上报时间倒序，以“上报时间 + 事件地点”为主标识，并展示问题类型、发现类型、状态和事件描述，不展示事件编号及上报后的等待时长 | 实时刷新车辆与手机位置及轨迹、作业里程与作业时长 |
| C03-R2 | 行驶过程中收到新派发任务 | 系统在任务执行页展示最新任务的“新任务 + 作业类型 - 任务区域 - 任务计划时间”；存在其他未查看新任务时展示待查看数量；同步语音播报作业类型、任务区域与计划时间；点击查看任务进入对应任务详情 | 提醒展示1分钟后自动关闭；不改变当前执行任务状态，新任务继续保留在今日任务清单 |

#### 3.3.5 交互流程

1. 巡查员在任务详情点击开始任务，系统校验开始任务条件。
2. 校验通过，进入任务执行页。
3. 系统在左侧地图展示作业区域、重点点位、持续更新的车辆与手机位置及轨迹，并展示作业里程、作业时长与事件上报数；右屏展示当前任务信息，再展示上报事件清单。
4. 收到外设事件上报时，系统为每条事件在地图增加对应事件点位，按上报时间倒序写入清单并刷新事件上报数。
5. 巡查员点击右侧事件卡片主体后，地图聚焦对应事件点位；点击卡片圆形进入图标或地图事件点位后进入详情。
6. 系统在右侧打开事件详情页，展示事件发生信息与关联任务。
7. 行驶过程中收到新派发任务时，系统在任务执行页展示消息提醒并语音播报；提醒按“新任务 + 作业类型 - 任务区域 - 任务计划时间”展示并提供待查看数量。巡查员点击查看任务后进入对应任务详情；手动关闭或展示1分钟后自动关闭仅结束提醒，当前执行任务保持进行中。
8. 巡查员点击结束任务，系统进行任务完成情况校验。
9. 处理结果：
   - 校验通过且有待接收任务 → 结束当前任务，自动选中计划时间最早的下一条待接收任务，提示“已结束当前任务，已自动推送下一条”。
   - 校验通过且无待接收任务 → 结束当前任务，返回今日任务列表并提示“今日任务均已完成，可在归还车辆后交车”。
   - 校验不通过 → 提示阻断原因，停留在任务执行页。
10. 巡查员点击交车时，系统校验是否存在进行中任务；当前任务未结束时阻断，任务结束且无其他进行中任务时进入交车页。

| C06-R2 | 展示待办 | 展示今日待接收巡查任务与明日待接收巡查任务；任务数据来自交车前绑定用户 | 无状态变化 |
| C06-R3 | 点击事件上报数或查看今日事件 | 打开既有今日事件清单，按交车前绑定用户和当日范围加载事件 | 进入只读事件清单；可返回今日回顾继续查看当日汇总，或返回绑定页开始新的绑定流程 |

#### 3.6.5 交互流程

1. 巡查员交车成功，系统进入今日回顾页。
2. 展示巡查员、车牌号、交车时间和交车成功提示。
3. 展示当日回顾指标与待判别、待分配、待处理、处理中、待核查、已完成六类事件状态统计。
4. 展示今日未完成巡查任务。
5. 展示明日待办巡查任务。
6. 巡查员点击事件上报数或查看今日事件，系统打开既有今日事件清单（只读）。
7. 巡查员点击“返回今日回顾”后返回今日回顾；点击“返回绑定页”后进入绑定页。

#### 3.6.6 异常处理

| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 无今日未完成任务 | 当日任务全部完成 | 今日未完成区域展示空态 | 提示无未完成任务 | 无需恢复 |
| 无明日待办任务 | 次日无计划任务 | 明日待办区域展示空态 | 提示无明日待办 | 任务派发后刷新 |
| 指标数据加载失败 | 云端服务不可用 | 保留最后有效数据并标注更新时间 | 提示数据异常 | 服务恢复后刷新 |

| ----------- | ---- | ---- | -------- | -------- |

#### 3.7.1 功能目标与范围

| 项目 | 说明 |
| ---- | ---- |

#### 3.7.3 数据与字段规则

| 通话状态 | 通话当前或最终结果 | 通话服务 | 枚举值：请求中、待接听、连接中、通话中、已接通、未接听、已拒接、已取消、失败 | 不为空 |

| 结束原因 | 通话结束的原因 | 通话服务 | 包含车机挂断、调度中心挂断、车机取消、车机拒接、无应答、网络失败、退出登录、移动端断开 | 未结束时为空 |
| 关联范围 | 通话所属业务上下文 | 绑定会话 | 项目ID+车辆ID+用户ID | 不为空 |

#### 3.7.4 业务规则与状态变化

| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| C07-R1 | 外部硬件发起请求 | 车机展示主动发起的通话请求；巡查员可在接通前取消 | 请求中→通话中，或请求中→已取消/失败 |
| C07-R2 | 已绑定期间收到云端呼入 | 车机展示云端呼入，巡查员可接听或挂断；未绑定时不接收呼入 | 待接听→连接中→通话中，或待接听→已拒接/未接听 |
| C07-R3 | 车辆已绑定或通话接通 | 通话入口在已绑定车机的业务页面持续可用；通话接通后默认收起并持续展示人数与时长，巡查员可展开查看成员姓名、人数、详细状态或直接挂断 | 页面跳转、展开或收起不改变通话状态 |
| C07-R4 | 通话进行中 | 任务、轨迹、作业里程、作业时长和事件接收继续运行；暂停新任务语音播报并保留视觉提醒 | 通话与任务状态相互独立 |
| C07-R5 | 已存在请求、呼入或通话 | 同一时间只允许一路通话，新请求按忙线处理 | 保留当前通话，不建立第二路通话 |
| C07-R6 | 通话中退出登录或收到移动端断开通知 | 系统先自动挂断并保存结束记录，再继续交车或清除绑定 | 通话中→已结束；绑定会话随后结束 |
| C07-R7 | 查看通话记录 | 仅返回同时匹配当前项目、当前车辆和当前绑定用户的通话；不提供回拨 | 无通话状态变化 |
| C07-R8 | 通话与其他消息同时到达 | 通话请求、云端呼入和通话中状态优先于网络异常、新任务提醒和一般反馈，但不得遮挡系统安全告警 | 低优先级消息暂停语音或延后展示 |
| C07-R9 | 云端在通话中加入或退出成员 | 更新当前成员姓名与人数；不改变通话ID、通话时长和任务状态，且不展示会议控制操作 | 同一路通话持续进行，历史记录在结束时保存最终成员及人数 |

#### 3.7.5 交互流程
1. 外部硬件发起通话请求后，系统校验人车绑定并展示等待调度中心接听的状态。
2. 巡查员可取消未接通请求；调度中心接听后系统进入通话中。
3. 已绑定期间收到云端呼入时，系统展示对端与接听、挂断操作。
4. 巡查员接听后系统建立通话；挂断或超时未处理时分别记录为已拒接或未接听。
5. 通话接通后默认以收起状态持续展示人数与时长，巡查员可展开查看成员姓名、人数、详细状态、收起或挂断。
6. 云端成员加入或退出时，系统更新当前成员姓名与人数，不中断当前通话。
7. 通话结束后系统保存通话方向、成员、人数、时间、结果、时长、结束原因及业务关联范围。
8. 巡查员可通过已绑定车机业务页面的持续入口查看当前项目、车辆和用户共同关联的历史通话；每条记录展示参与人数摘要，行驶中不开放长列表浏览。

#### 3.7.6 异常处理

| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 未建立人车绑定 | 收到云端呼入或硬件请求 | 不建立通话，不展示通话操作 | 必要时提示需先绑定车辆 | 完成绑定后重新发起 |
| 重复通话事件 | 同一通话ID的信令重复到达 | 按通话ID幂等处理 | 不重复展示或记录 | 无需恢复 |
| 成员事件异常 | 成员姓名为空、成员重复或非当前通话ID的成员事件到达 | 忽略无效成员；按成员姓名去重；不更新非当前通话 | 保留当前有效成员与人数 | 等待下一次有效成员事件 |
| 忙线 | 已存在活跃通话时收到新请求 | 拒绝新请求并保留当前通话 | 必要时提示当前正在通话 | 当前通话结束后可重新发起 |
| 网络或设备连接失败 | 请求、接听或通话期间连接异常 | 结束或尝试恢复当前通话，保留任务页面状态 | 展示连接异常或正在恢复 | 网络恢复后重新请求 |
| 退出时挂断确认超时 | 退出或断开时未在限时内收到挂断确认 | 记录结束原因并继续退出，不阻塞解绑 | 按原退出流程反馈 | 后台补偿同步通话结果 |
| 历史记录加载失败 | 通话服务不可用 | 保留最后一次有效数据并标注更新时间 | 提示通话记录暂不可用 | 服务恢复后刷新 |

| ----------- | ---- | ---- | -------- | -------- |

## 4. 业务规则汇总

### 4.1 状态流转

**任务状态机：** 待接收 → 进行中 → 已完成；旁路状态包括已转派、已终止、已失效，与云端任务状态机一致。
待接收或进行中任务可因转派操作进入已转派，也可因终止操作进入已终止；已完成、已转派、已终止、已失效为终态，不允许再次执行转派或终止。
**事件状态机：** 待判别 → 待分配 → 待处理 → 处理中 → 待核查 → 已完成，以环卫云平台状态机为准。
**通话状态机：** 硬件发起为请求中 → 连接中 → 通话中 → 已接通，旁路结果为已取消或失败；云端呼入为待接听 → 连接中 → 通话中 → 已接通，旁路结果为已拒接或未接听。

### 4.2 校验规则

| 校验场景 | 校验条件 | 通过结果 | 不通过结果 |
| -------- | -------- | -------- | -------- |
| 绑定扫码 | 人车关系校验 | 完成绑定并进入推荐任务详情，任务清单可按需打开 | 提示失败原因并停留在绑定页 |
| 开始任务 | 满足常规任务开始条件（时间范围、无其他进行中任务、位置在路段范围） | 进入任务执行页 | 提示阻断原因并停留 |
| 结束任务 | 任务完成情况校验 | 结束任务并返回今日任务列表，刷新当前任务状态 | 提示阻断原因并停留 |
| 转派任务 | 当前任务状态为待接收或进行中，且已填写转派原因 | 更新为已转派并返回今日任务列表 | 原因为空或任务状态已变化时阻止提交并保留原状态 |
| 终止任务 | 当前任务状态为待接收或进行中，且已填写终止原因 | 更新为已终止并返回今日任务列表 | 原因为空或任务状态已变化时阻止提交并保留原状态 |
| 交车 | 未完成任务校验（存在进行中未结束任务则阻断） | 展示交车二维码 | 提示存在进行中任务并显示该任务 |
| 通话 | 车辆已绑定、通话ID有效且当前无其他活跃通话 | 建立或更新当前通话；通话中保持任务与轨迹业务继续 | 未绑定、忙线、重复通话ID或连接失败时拒绝或结束请求 |

### 4.3 计算规则

| 指标 | 计算口径 |
| ---- | -------- |
| 作业里程 | 开始任务时间到当前时间的轨迹长度，单位km，保留2位小数 |
| 作业时长 | 当前时间减开始任务时间，单位分钟，保留整数 |
| 轨迹里程 | 当日绑车到交车的轨迹总里程，单位km，保留2位小数 |
| 出车时长 | 当日绑车到交车的时长，单位分钟，保留整数 |
| 事件上报数 | 本次任务/当日通过外设上报的事件数量 |

### 4.4 字段联动规则

| 触发字段 | 触发条件 | 联动行为 |
| -------- | -------- | -------- |
| 任务卡片 | 在今日任务列表点击任务卡片 | 打开对应任务详情并加载该任务地图数据 |
| 进行中任务 | 进入任务首页存在进行中任务 | 进行中任务作为默认选中推荐任务，并在打开清单后置顶 |
| 新派发任务 | 车辆已绑定期间收到普通新任务 | 展示全局任务消息提醒并语音播报；点击查看任务进入今日任务清单并选中该任务；手动关闭或展示1分钟后自动关闭仅结束提醒，新任务继续保留在清单 |
| 结束任务 | 任务完成校验通过 | 当前任务更新为已完成；存在待接收任务时自动选中计划时间最早的下一条任务，否则提示今日任务均已完成 |
| 转派/终止任务 | 待接收或进行中任务提交对应原因成功 | 更新任务状态为已转派或已终止，记录操作原因与时间，返回今日任务列表 |
| 通话请求 | 车辆已绑定且收到硬件或云端通话事件 | 展示通话请求；主动发起请求可取消，云端呼入可接听或挂断；同一时间仅保留一路通话 |
| 通话成员变更 | 当前通话收到云端成员加入或退出事件 | 更新成员姓名和人数；车机仅展示，不提供会议控制 |
| 通话结束 | 通话被任一方挂断、取消、拒接、超时或连接失败 | 保存通话结果、最终成员及人数并刷新通话记录；退出登录或移动端断开时先自动挂断再继续原流程 |

### 4.5 记录规则

| 记录节点 | 记录字段 | 说明 |
| -------- | -------- | ---- |
| 绑定 | 人员+时间+车辆+位置 | 扫码绑定完成时记录 |
| 交车 | 人员+时间+车辆+位置 | 扫码交车完成时记录 |
| 通话 | 通话ID、方向、项目、车辆、用户、成员、参与人数、请求/接通/结束时间、结果、时长、结束原因 | 通话结束后生成；同一通话ID幂等保存，通话记录列表展示参与人数摘要 |

### 4.6 驾驶安全规则

| 场景 | 规则 |
| ---- | ---- |
| 行驶受限 | 仅保留高优先级信息、语音反馈与少量大尺寸操作，禁用输入、长滚动、复杂筛选与高风险操作 |
| 不可用操作 | 就地禁用并说明原因，不使用全屏蒙层遮挡核心信息 |
| 语音与视觉同步 | 高优先级状态使用语音与视觉摘要同步反馈，语音不得是获取关键信息的唯一方式 |
