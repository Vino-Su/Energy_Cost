- [ ] 车辆使用全程监控体系：以车辆为维度，串联起来司机、安全员、任务、车务等内容，并进行全程监控。要形成一套管理机制
- [ ] 人有两种：有固定任务的，无固定任务的
- [ ] 在任务执行过程中，围绕着计划任务、实际执行情况、水电油上报等节点进行串联，形成司机的任务执行场景
- [ ] 车辆分为很多种，需要搞清楚不同类型车辆的作业执行情况是否一致，看轨迹吻合程度即可？
- [ ] 用车场景：
	1. 司机出车前需打卡，（执行任务），交车前需打卡，保证车与人之间的关联关系。
	2. 如有任务，接受任务，任务执行过程中，对比任务完成度（时间、空间）。任务完成
	3. 用车过程中，水电油的上报等事项
	4. 对于用车过程中出现的异常予以关注，如对于无主车辆的启动或运行需要予以预警；未按时出车；路线偏差较大等
- [ ] 作业路线：需要定义打卡、脱勤、异常情况等行为，为管理提供依据
- [ ] 以上是关于作业车辆的管理，实际上与车辆关联的安全员、环卫工也是类似的业务流程
