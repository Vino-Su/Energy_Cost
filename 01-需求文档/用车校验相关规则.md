**绑车前校验**

| 校验类型     | 校验条件                          | 可能的配置项 | 操作     |
| -------- | ----------------------------- | ------ | ------ |
| 人车关系校验   | 1. 当前车辆未被他人绑定<br>2. 当前司机未绑定他车 |        | 不进入下一步 |
| 车辆在线状态校验 | 当前车辆网联装置在线                    |        | 可进入下一步 |

**开始任务前校验**

| 校验类型        | 校验条件                      | 可能的配置项                      | 操作     |
| ----------- | ------------------------- | --------------------------- | ------ |
| 绑定关系校验      | 校验当前司机已绑定车辆；校验司机当日是否已扫码绑车 | 是否要求跨日扫码                    | 不进入下一步 |
| 开始时间校验      | 校验是否开始时间是否满足要求            | 是否允许提前开始<br>开始时间距离计划时间的前后阈值 |        |
| 未完成任务校验     | 当前司机 + 当前车辆没有处于进行中的任务     | 任务跨日未结束，是否自动做异常结束           | 不进入下一步 |
| 车辆 - 任务匹配校验 | 车辆与执行任务的分配车辆相一致           | 是否允许更换车辆                    | 不进入下一步 |
| 车辆在线状态校验    | 当前车辆网联装置在线                | 不在线是否允许执行任务                 | 可进入下一步 |
| 车辆位置校验      | 校验车辆位置在任务路段范围内            | 路段范围的阈值                     | 不进入下一步 |

**结束任务前校验**

| 校验类型     | 校验条件       | 可能的配置项        | 操作     |
| -------- | ---------- | ------------- | ------ |
| 任务完成情况校验 | 校验里程数是否为 0 | 完成条件：里程、时长、位置 | 不进入下一步 |

**交车前校验**

| 校验类型    | 校验条件                  | 可能的配置项 | 操作     |
| ------- | --------------------- | ------ | ------ |
| 未完成任务校验 | 当前司机 + 当前车辆没有处于进行中的任务 |        | 不进入下一步 |
