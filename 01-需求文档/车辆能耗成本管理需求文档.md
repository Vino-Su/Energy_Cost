## 1 背景

 公司目前有大量的车辆在运营中，包括自研的车辆和外采的车辆，这些车辆在运行过程中会产生能耗费用，包括油、电、水等类型。目前这些数据并未有标准化的线上采集流程，导致单车的能耗费用数据难以精准收集。因此，基于酷哇 APP 这一平台，围绕着车辆能耗成本的线上登记，进行能耗管理的需求分析与功能设计。

## 2 主要用户与权限

| ---- | -------------------------------------- | ----- | -------------------- | ------------- |

## 3 功能架构

本功能主要搭载在两个端，移动端和 WEB 端

**移动端：** 移动端主要搭载在酷哇 APP 工作台中，搭载在成本上报应用中。支撑司机等角色进行现场的费用上报，支持查看已填报的记录；支持项目经理等人员查看已填报的记录

**WEB 端：** WEB 端主要搭载在车辆管理平台中。对已上报的记录进行明细查看

### 3.1 与现有系统的关系

| 系统名称     | 关系                      | 备注      |
| -------- | ----------------------- | ------- |
| 酷哇 APP   | 移动端的搭载平台                |         |

| basis 平台 | 从 basis 平台中接入车辆信息、项目信息  |         |

| 权限系统     | 调用权限和用户信息               |         |

## 4 移动端功能需求

在酷哇 APP- 工作台页面中，新增“车辆成本”应用，点击“车辆成本”应用，进入到本应用。

本应用中目前共有四个子功能

- 加油上报
- 加水上报
- 充电上报

### 4.5 上报记录

- 以卡片的形式展示当前用户权限范围内的填报记录，默认按照填报时间倒序排列，滚动显示，可上拉加载更多
- 支持按照项目、上报记录类型等条件对记录进行筛选，默认为当前用户所属权限范围内的所有上报记录
- 卡片内容包括：
	- 费用类型 - 车牌号 - 金额
	- 上报时间 - 上报人 - 项目
- 点击卡片后，能够进入对应记录详情查看页面
- 详情页面支持对记录的编辑，其中车牌号、车架号、所属项目、上报人字段不可编辑。编辑的字段均需记录，并在 WEB 端的变更记录中显示
- 支持删除己上报记录，删除前需要二次确认，点击后提示 " 确定删除该信息吗？删除后数据不可恢复。"，用户点击 " 确定 " → 执行逻辑删除 + 列表刷新；用户点击 " 取消 " → 关闭确认弹窗，不执行删除；删除权限为该条记录的上报用户、项目经理或管理员
## 5 WEB 端功能需求
### 5.1 加油记录明细

以列表形式对司机上报的加油记录进行汇集展示。

**查询条件：**

| 元素   | 类型      | 配置说明       |
| ---- | ------- | ---------- |
| 加油时间 | 时间范围选择框 | 精确到日，默认近半年 |
| 车牌号  | 文本框     | 支持模糊搜索     |
| 车架号  | 文本框     | 支持模糊搜索     |
| 上报人  | 文本框     | 支持模糊搜索     |
| 项目名称 | 下拉单选    |            |

**列表字段：**

- 复选框
- 车牌号
- 车架号
- 所属项目
- 上报人
- 加油时间
- 加油单价（元）
- 加油量（L）
- 加油金额（元）
- 当前里程数（km）
- 仪表盘里程照片：显示缩略图，点击可查看具体照片
- 交易凭证：显示缩略图，点击可查看具体照片
- 操作栏
	- 编辑：点击后打开编辑弹窗，预填当前已有信息，其中车牌号、车架号、所属项目不可编辑。编辑的字段均需记录，并在变更记录中显示
	- 删除：点击后提示 " 确定删除该信息吗？删除后数据不可恢复。"，用户点击 " 确定 " → 执行逻辑删除 + 列表刷新；用户点击 " 取消 " → 关闭确认弹窗，不执行删除
	- 变更记录：点击后打开变更记录弹窗，弹窗中有变更记录列表，列表字段依次为：字段名称、变更前、变更后、变更时间、变更人，按照变更时间倒序排列
列表默认按照加油时间倒序排列，底部分页，每页条数选项 10、20、50、100，默认 10，支持上下页翻页
**操作按钮**

- **新增记录：** 点击后打开新增加油记录弹窗，弹窗字段信息同 APP 中加油记录上报页面，其中仪表盘里程照片和交易凭证均支持从设备本地上传
- **导入：** 点击后打开导入弹窗，弹窗中支持导入模版下载和文件上传
	- 导入时需要对文件进行合规校验
	- 如果存在校验失败的记录，则 toast 提示失败原因 + 对应行数，该批数据不做导入
- **导出：** 若用户有选中记录，导出用户选择的数据，不支持跨页选择导出；若用户未选中数据，提示：" 是否导出所有数据？"，用户选择 " 是 " 则导出当前筛选条件下的所有数据

	- 编辑：点击后打开编辑弹窗，预填当前已有信息，其中车牌号、车架号、所属项目不可编辑。编辑的字段均需记录，并在变更记录中显示
	- 删除：点击后提示 " 确定删除该信息吗？删除后数据不可恢复。"，用户点击 " 确定 " → 执行逻辑删除 + 列表刷新；用户点击 " 取消 " → 关闭确认弹窗，不执行删除
	- 变更记录：点击后打开变更记录弹窗，弹窗中有变更记录列表，列表字段依次为：字段名称、变更前、变更后、变更时间、变更人，按照变更时间倒序排列
列表默认按照充电时间倒序排列，底部分页，每页条数选项 10、20、50、100，默认 10，支持上下页翻页

**操作按钮**

- **新增记录：** 点击后打开新增充电记录弹窗，弹窗字段信息同 APP 中充电记录上报页面，其中仪表盘里程照片和支付照片均支持从设备本地上传
- **导入：** 点击后打开导入弹窗，弹窗中支持导入模版下载和文件上传
	- 导入时需要对文件进行合规校验
	- 如果存在校验失败的记录，则 toast 提示失败原因 + 对应行数，该批数据不做导入
- **导出：** 若用户有选中记录，导出用户选择的数据，不支持跨页选择导出；若用户未选中数据，提示：" 是否导出所有数据？"，用户选择 " 是 " 则导出当前筛选条件下的所有数据
