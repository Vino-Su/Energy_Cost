## 1 背景

巡查人员是环卫作业中的重要一环，主要是对作业后的路面进行质量检查，其作业模式一般采用巡查人员在收到巡查任务后，搭载机动车或者电瓶车等进行巡查，在这其中可能会发现质量问题，则进行事件上报，派发至相关责任人进行处置。目前巡查人员主要通过对讲机、微信等的形式进行问题上报，尚未完整的巡查数字化体系。

本应用主要针对采用机动车进行巡查的场景，该类场景中一般会配备有机动车，在巡查区域驾驶过程中进行事件的上报，考虑到交通安全和使用便捷性，因此采用将巡查 APP 安装在车机中，巡查 APP 支持巡查任务的查收、执行和结束，同时搭配车辆套件进行巡查过程中的拍照、事件上报

## 3 产品定义与说明
### 3.1 产品定义

品质巡查移动端主要涉及两个部分内容，一个是手机移动端品质巡查应用，一个是车机端品质巡查应用。

**手机移动端品质巡查应用：** 作为品质巡查的主要移动载体，其中不仅涉及到巡查任务的具体执行，还会涉及到巡查人员这一角色的其他功能，如水电油上报等

**车机端品质巡查应用：** 考虑到机动车安全问题，因此如果是机动车巡查，在车机中集成此 APP，主要聚焦于执行任务的实时显示和问题查看，并搭配车辆套件进行事件的上报。该应用按照 16:9 的尺寸设计。

手机移动端品质巡查应用与车机端品质巡查应用均是巡查员执行任务的工具，两个应用共用一套数据库，支持通过手机扫码绑定车机应用的方式来实现多端实时共享任务及事件数据

## 4 流程 + 规则 + 状态
### 4.1 巡查任务状态机

任务状态机与常规任务、动态任务相同

| **状态名称** | **业务释义**                                                 | 是否终态 |
| -------- | -------------------------------------------------------- | ---- |
| 待下发      | 云端创建任务，保存，尚未推送车辆/APP                                     | 否    |
| 待接收      | 云端已下发任务；等待目标司机在 APP 确认接收                                 | 否    |
| 进行中      | 正式启动作业，正在执行清扫任务                                          | 否    |
| 已完成      | 任务正常跑完，作业闭环                                              | 是    |
| 已转派      | 原接收方发起转派，等待新目标接收                                         | 否    |
| 已终止      | 管理员云端/APP 人工强制终止任务，非正常闭环；<br><br>进行中超时未上报完成，系统自动终止，非正常闭环 | 是    |
| 已失效      | 超时无人接收、车辆离线无法执行，任务超过最晚可开始时间没开始，自动失效                      | 是    |

### 4.2 事件状态机

以环卫云平台中提供的状态机为准，参照动态任务的状态机

待判别、待分配、待处理、处理中、待核查、已完成

### 4.3 校验规则

**绑车前校验**

| 校验类型     | 校验条件                          | 失败提示信息                                                  | 操作     |
| -------- | ----------------------------- | ------------------------------------------------------- | ------ |
| 人车关系校验   | 1. 当前车辆未被他人绑定<br>2. 当前司机未绑定他车 | toast 提示：当前车辆已被【用户名】绑定，请绑定其他车辆！   您当前已绑定【车牌号】，请交车后重新绑定！ | 不进入下一步 |
| 车辆在线状态校验 | 当前车辆网联装置在线                    | toast 提示：“当前车辆网联装置离线，请检查”                               | 可进入下一步 |

**开始任务前校验**

| 校验类型     | 校验条件                  | 失败提示信息                      | 操作     |
| -------- | --------------------- | --------------------------- | ------ |
| 开始时间校验   | 校验是否开始时间是否满足要求        | toast 提示：“当前不在开始时间范围内”；     | 不进入下一步 |
| 未完成任务校验  | 当前司机 + 当前车辆没有处于进行中的任务 | toast 提示：当前存在进行中任务          | 不进入下一步 |
| 车辆在线状态校验 | 当前车辆网联装置在线            | toast 提示：“当前车辆网联装置离线，请检查”   | 可进入下一步 |
| 车辆位置校验   | 校验车辆位置在任务路段范围内        | toast 提示：“任务车辆不在任务路段范围，请检查” | 不进入下一步 |

**结束任务前校验**

| 校验类型     | 校验条件       | 失败提示信息                        | 操作     |
| -------- | ---------- | ----------------------------- | ------ |
| 任务完成情况校验 | 校验里程数是否为 0 | toast 提示：“当前任务里程数为 0 ，无法结束任务” | 不进入下一步 |

**交车前校验**

| 校验类型    | 校验条件                  | 失败提示信息               | 操作     |
| ------- | --------------------- | -------------------- | ------ |
| 未完成任务校验 | 当前用户 + 当前车辆没有处于进行中的任务 | toast 提示：“当前存在进行中任务” | 不进入下一步 |

## 6 车机应用功能需求

车机 APP 是巡查人员 - 机动车的主要任务执行页面。其界面尺寸按照 16:9 进行设计

### 6.1 车辆绑定/交车页面

车辆的绑定/交车实际是与车机应用的登录是关联的，车机查询的任务是当前车辆绑定的用户的巡查任务。

1. 用户扫码——车辆绑定用户——车机应用登录
2. 用户扫码——车辆解绑用户——车机应用退出

#### 6.1.1 车辆绑定页
1. 在车机未绑定用户下，打开应用后则显示车辆绑定页面，显示车辆本身二维码
2. 用户使用酷哇 APP 扫码成功后，进行**人车关系校验**
	- 校验通过，完成用户与车辆的使用关系绑定
	- 校验不通过，toast 提示失败原因
3. 扫码完成后系统记录人员 + 时间 + 车辆 + 位置信息

#### 6.1.2 交车页
1. 车机已绑定车辆下，用户点击交车按钮，进行**未完成任务校验**，
	- 校验通过，打开二维码页面
	- 校验不通过，toast 提示：存在进行中任务，无法交车
2. 用户使用酷哇 APP 扫码完成后系统记录人员 + 时间 + 车辆 + 位置信息，并解除人与车使用关系的绑定
3. 打开今日回顾页面
### 6.2 系统首页

扫码成功后，进入系统首页，首页是用户的主要操作界面，采用左右分屏设计。

应用右上角显示：当前绑定用户名称 - 车辆牌照 - 系统时间

#### 6.2.1 左屏地图

1. 地图中默认显示右侧对应任务的作业区域、当前车辆位置、绑定用户的手机 APP 位置以及轨迹、事件点位。
	- 任务区域的颜色按照任务的状态显示不同的颜色，包括待接收、进行中、已完成和其他（已终止、已转派、已失效）
2. 地图右侧中有以下工具按钮：
	- 今日任务：角标显示该用户当天巡查任务数，点击图标后图标呈选中状态
		- 右侧打开**今日任务清单**
		- 左侧地图显示今日所有任务的作业区域，显示作业区域名称。
		- 区域中按照任务中上报事件进行聚合展示，地图放大或者点击聚合图标，则取消聚合图标，展示具体时间点位
	- 今日事件：角标显示当前任务上报的事件数，点击图标后图标呈选中状态
		- 右侧打开**今日上报事件清单**
		- 左侧地图显示今日所有上报的事件点位
	- 复位：回正到车辆当前位置
	- 图层：辅助设施图层（图层点位及功能与用车管理地图页面中的一致）
	- 全屏：地图全屏展示
	- 交车：解除人车绑定关系（仅在已绑定车辆状态下才会显示）
#### 6.2.2 右屏当前任务
1. 右侧显示该用户排序最前的任务或者正在执行中的任务信息
	- 此时如果没有进行中的任务，默认显示该用户作业时间排序最早的任务信息，地图中默认显示当前人员位置 + 任务卡片中的任务计划区域 + 重点点位（如有）
	- 如果此时有进行中的任务，默认显示进行中的任务信息，地图中默认显示当前人员位置和车辆位置及轨迹 + 任务卡片中的任务计划区域 + 重点点位（如有）
2. 点击任务卡片显示信息详见 6.3 章节内容
3. 任务信息底部有以下按钮：
	- 开始任务：针对待接收任务
	- 结束任务：针对进行中任务
	- 返回今日任务列表：点击后打开今日任务清单

### 6.3 今日任务清单
1. 触发条件：点击“今日任务”按钮，呈选中状态
2. 默认展示当前用户今天的所有的巡查任务，并按照任务状态进行分组，优先级依次为：待接收>进行中>已完成>已转派>已终止>已失效。若某一分组内无数据，可不显示该分组。分组内按照计划作业时间按顺序排列
3. 任务卡片显示信息：
	- 片区名称 - 任务日期 - 作业时间 - 任务状态
	- 作业类型 - 作业资源
4. 点击卡片，左侧地图聚焦展示该任务区域、事件点位（如有），右侧展示任务详情，展示字段有
	- 任务信息：
		- 任务编号：如 CGRW2026042800001
		- 片区名称：如石井社区一号片区
		- 任务日期：如 2026-04-28
		- 作业时间：如 06:30~10:00
		- 作业资源：如张三丰
		- 作业类型：如品质巡查
	- 任务执行信息：（如果任务为待接收状态，无需显示该信息）
		- 开始时间：任务开始的时间
		- 作业里程：任务过程中的里程数，单位 km，保留 2 位小数
		- 作业时长：结束任务时间或者当前时间 - 开始时间，单位 min，保留整数
		- 事件上报：该任务期间上报的问题数
	- 事件上报列表：展示该任务关联的事件列表，列表中的事件卡片支持点击交互
5. 点击关闭，关闭当前清单，“今日任务”按钮呈非选中状态
### 6.4 今日上报事件清单
1. 触发条件：点击“今日事件”按钮，呈选中状态
2. 默认展示当前用户今天的所有的巡查任务中关联的事件列表，并按照事件状态进行分组
3. 事件卡片显示信息：
	- 事件地点 - 上报时间 - 事件发现类型 - 事件状态
	- 问题类型 - 事件描述
4. 点击卡片，左侧地图聚焦该事件点位，呈选中状态；点击详情按钮，右侧展示问题详情，展示字段有
	- 事件信息：
		- 事件发生时间
		- 事件来源：监控中心、机器人采样、AI 监控采样、对讲机采样、无人机采样、车载监控采样 (巡查车属于这一类)、第三方
		- 事件发现类型：AI、人工，人工触发方式的为人工，其余全部记为 AI
		- 事件发现方：具体的人、车，如巡查员张三、独角兽 10032、摄像头 A
		- 经纬度
		- 事件地点
		- 详细地点
		- 问题类型：明显垃圾。未清洗则是“未知”
		- 事件描述
		- 事件图片
	- 处置节点，高亮展示当前节点
		- 待判别 - 待分配 - 待处理 - 处理中 - 待核查 - 已完成
	- 点击返回按钮，返回事件列表
5. 点击关闭，关闭当前清单，“今日事件”按钮呈非选中状态
### 6.5 任务执行页面
1. 点击开始任务后，需要进行开始任务前校验，具体参照 4.3 章节内容。若满足开始任务条件，则进入到任务执行页面
2. 左侧地图会展示车辆的实时轨迹、手机的实时轨迹和上报的事件点位，左上角显示该任务的开始时间、作业里程、作业时长和事件上报数；右侧列表会展示当前任务的基本信息，及实时更新的事件卡片列表，按照上报时间倒序排列
3. 事件卡片中包含信息：
	- 事件地点 - 上报时间 - 事件发现类型 - 事件状态
	- 问题类型 - 事件描述
4. 用户点击地图事件点位或者事件卡片，能够查看事件详情，具体参考 6.4 章节内容
5. 用户在行驶过程中如果收到新的任务，则在应用顶部上方显示 banner 轻提醒，并进行语音播放，播放内容：收到新的任务，【任务类型】-【任务区域】-【任务计划时间】
6. 用户点击“结束任务”，点击后进行**任务完成情况校验**，若通过，则完成任务。
	- 若当前用户中有待开始的任务，则 toast 提示：已结束当前任务，已自动推送下一条。地图和任务卡片效果等同于选中该任务
	- 若均无待开始任务，则 toast 提示：今日任务均已完成，可在归还车辆后交车
7. 用户点击地图右侧工具栏“交车”按钮，点击后先进行**未完成任务校验**，若通过，则
	 - 当前仍存在进行中未结束任务：无法交车。地图和任务卡片中显示该任务信息
	- 校验通过，则打开“交车”页面由用户进行扫码交车
8. 交车成功后，打开今日回顾页

### 6.6 今日回顾页
1. 触发条件：交车成功
2. 本页面主要是对司机今日的任务完成情况进行回顾，并列出明日待办任务，便于司机更好的安排工作。
3. 分为以下内容：
	- 交车信息：包括用户名、车牌号、交车时间
	- 今日工作成果：任务完成数、轨迹里程、出车时长、事件上报数
	- 今日事件状态：按照状态统计事件数量
	- 今日待办：今日该用户待接收的巡查任务
	- 明日待办：明日该用户待接收的巡查任务
4. 有以下按钮：
	- 返回首页：点击后返回车辆绑定页
	- 查看今日事件：打开地图页，左侧显示所有的事件点位，右侧显示所有的事件列表，参 6.4 章节内容，支持点击卡片或者地图点位查看具体信息
