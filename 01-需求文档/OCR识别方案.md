
## 1 OCR 服务

本次测试采用的是阿里官方的高精版 OCR 文字识别/图像识别/图片识别服务，其特点如下：

1. 多功能场景识别：集表格识别、旋转识别、生僻字识别等多功能为一体；
2. 多类型覆盖：支持多格式版面、复杂文档背景和光照环境的精准识别；
3. 印章、手印处理：对于有印章、手印的文档，可实现印章擦除后识别；
4. 高阶功能：支持覆盖文字编辑、低置信度过滤、图案检测等等。
### 1.1 接口信息

调用地址：[https://gjbsb.market.alicloudapi.com/ocrservice/advanced](https://gjbsb.market.alicloudapi.com/ocrservice/advanced)

请求方式：POST

返回类型：JSON

API 调用：APPCODE

请求参数（Body）：

```
{
  //图像数据：base64编码，要求base64编码后大小不超过25M，最短边至少15px，最长边最大8192px，支持jpg/png/bmp格式，和url参数只能同时存在一个
  "img": "",
  //图像url地址：图片完整URL，URL长度不超过1024字节，URL对应的图片base64编码后大小不超过25M，最短边至少15px，最长边最大8192px，支持jpg/png/bmp格式，和img参数只能同时存在一个
  "url": "",
  //是否需要识别结果中每一行的置信度，默认不需要。 true：需要 false：不需要
  "prob": false,
  //是否需要单字识别功能，默认不需要。 true：需要 false：不需要
  "charInfo": false,
  //是否需要自动旋转功能，默认不需要。 true：需要 false：不需要
  "rotate": false,
  //是否需要表格识别功能，默认不需要。 true：需要 false：不需要
  "table": false,
  //字块返回顺序，false表示从左往右，从上到下的顺序，true表示从上到下，从左往右的顺序，默认false
  "sortPage": false,
  //是否需要去除印章功能，默认不需要。true：需要 false：不需要
  "noStamp": false,
  //是否需要图案检测功能，默认不需要。true：需要 false：不需要
  "figure": false,
  //是否需要成行返回功能，默认不需要。true：需要 false：不需要
  "row": false,
  //是否需要分段功能，默认不需要。true：需要 false：不需要
  "paragraph": false,
  // 图片旋转后，是否需要返回原始坐标，默认不需要。true：需要  false：不需要
  "oricoord": true
}
```

### 1.2 推荐配置

```
{
  "img": "图片Base64",
  "url": "",
  "prob": true,
  "charInfo": false,
  "rotate": true,
  "table": false,
  "sortPage": false,
  "noStamp": false,
  "figure": false,
  "row": true,
  "paragraph": false,
  "oricoord": true
}
```

其中 prod 指的是单字的置信度，建议取置信度在 90% 以上的内容进行填充

## 3 问题
1. 现场可能会要求使用水印相机拍照，可能会干扰识别效果
2. 接口可能会限制照片大小，会出现体积过大返回超时的问题，是否需要在拍照时予以控制
