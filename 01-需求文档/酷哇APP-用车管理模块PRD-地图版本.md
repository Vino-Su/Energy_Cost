# 名词解释

| 名词     | 解释                                                                            | 备注  |
| :----- | :---------------------------------------------------------------------------- | :-- |
| 绑车     | 司机在开始使用某车辆时，通过扫码的方式，建立司机与车辆的使用关系                                              |     |
| 交车     | 司机在结束使用某车辆时，通过扫码的方式，解除司机与车辆的使用关系                                              |     |
| 当前车辆任务 | 今日用车模块，指司机与绑定车辆今日需要完成的任务。检索条件为：司机 + 车牌号 + 今日时间 + 任务类型（待开始、进行中、已完成）            |     |
| 其他车辆任务 | 今日用车模块，指司机与其他车辆（剔除绑定车辆）今日需要完成的任务。检索条件为：司机 + 今日时间 + 任务类型（待开始、进行中、已完成），剔除当前车辆任务 |     |

## 1 背景

在环卫作业中，车辆是一个重要的主体，围绕着车辆的使用全过程，能够串联起人（驾驶员或安全员）、任务、事件、成本费用等环节。因此，针对车辆进行全过程的监控管理是一个很重要的场景，目前公司在车辆使用过程中存在以下问题：

1. 车辆使用不规范，无法追踪车辆状态及使用情况
2. 车辆使用场景无配套 APP，数据仅停留在纸质台账
3. 部分已建设的子功能较为分散，且学习成本高
基于以上问题，希望从驾驶员和监管的角度出发，梳理非自动驾驶车辆使用的全过程，形成一套车辆使用过程监管方案。

## 3 产品定义与说明
### 3.1 产品定义

功能主要搭载在移动端 - 酷哇 APP 应用中，主要面向非自动驾驶作业车辆驾驶员，目标是通过**场景化流程**，把驾驶员一天中围绕车辆发生的关键动作串起来，包括接车、任务执行、动态任务、水电油上报、故障报修、交车和工作回顾。在此基础上，实现管理层对驾驶员车辆使用过程的监管。

驾驶员有两种使用路径：

| 路径        | 说明                                        |
| --------- | ----------------------------------------- |
| 场景化主流程 - 地图 | 先接车绑定车辆，直接进入任务页面，引导任务完成，其中可以穿插补给、报修、交车等动作 |
| 独立功能入口 - 服务 | 未绑定车辆或者不进入场景化主流程，也可以单独进入任务、报修、水电油等功能      |

**接车绑定不是所有功能的绝对前置条件**，但它是场景化主流程的起点。未绑定时使用独立功能，必须在功能内明确车辆对象。

### 3.2 与现有系统的关系

| 系统名称     | 关系                             | 备注              |
| -------- | ------------------------------ | --------------- |
| basis 平台 | 从 basis 平台中接入车辆信息、车型信息、项目信息    |                 |
| 环卫云平台    | 与环卫云平台对接作业排班、任务派发等信息           | 需要与环卫云目前开发功能相匹配 |
| 售后平台     | 调用售后 APP 保修功能，与售后平台对接车辆维修工单的信息 | 本次暂不接入          |
| 权限系统     | 调用权限和用户信息                      |                 |

### 3.3 产品边界
1. 本方案仅针对非自动驾驶的作业车辆进行场景拆解
2. 本方案仅针对车辆状态为正常的项目作业车辆，对于研发测试、维修中的车辆，不在此方案范畴

## 4 流程 + 规则 + 状态
### 4.1 驾驶员工作日流程图

```
进入地图
  -> 接车绑定
  -> 查看任务列表
  -> 开始任务
  -> 执行任务
	  -> 处理动态任务
      -> 补给上报
	  -> 故障报修
  -> 结束任务
  -> 推送下一任务
  -> 交车
      -> 检查未完成事项
      -> 提醒项：允许交车
      -> 阻断项：不允许交车
  -> 今日回顾 + 今日任务 + 明日待办
```

### 4.2 任务状态机

参见环卫云平台相关文件。

### 4.3 校验规则

**绑车前校验**

| 校验类型     | 校验条件                          | 失败提示信息                                                  | 操作     |
| -------- | ----------------------------- | ------------------------------------------------------- | ------ |
| 人车关系校验   | 1. 当前车辆未被他人绑定<br>2. 当前司机未绑定他车 | toast 提示：当前车辆已被【用户名】绑定，请绑定其他车辆！   您当前已绑定【车牌号】，请交车后重新绑定！ | 不进入下一步 |
| 车辆在线状态校验 | 当前车辆网联装置在线                    | toast 提示：“当前车辆网联装置离线，请检查”                               | 可进入下一步 |

**开始任务前校验**

| 校验类型        | 校验条件                    | 失败提示信息                                        | 操作     |
| ----------- | ----------------------- | --------------------------------------------- | ------ |
| 绑定关系校验      | 校验当前司机已绑定车辆；校验司机当日是否已扫码 | toast 提示：“当前司机未绑定车辆”；“当前司机今日未扫码，请扫码”，打开车辆绑定页面 | 不进入下一步 |
| 开始时间校验      | 校验是否开始时间是否满足要求          | toast 提示：“当前不在开始时间范围内”；                       | 不进入下一步 |
| 未完成任务校验     | 当前司机 + 当前车辆没有处于进行中的任务   | toast 提示：当前存在进行中任务                            | 不进入下一步 |
| 车辆 - 任务匹配校验 | 车辆与执行任务的分配车辆相一致         | 打开更换车辆弹窗                                      | 不进入下一步 |
| 车辆在线状态校验    | 当前车辆网联装置在线              | toast 提示：“当前车辆网联装置离线，请检查”                     | 可进入下一步 |
| 车辆位置校验      | 校验车辆位置在任务路段范围内          | toast 提示：“任务车辆不在任务路段范围，请检查”                   | 不进入下一步 |

**结束任务前校验**

| 校验类型     | 校验条件       | 失败提示信息                        | 操作     |
| -------- | ---------- | ----------------------------- | ------ |
| 任务完成情况校验 | 校验里程数是否为 0 | toast 提示：“当前任务里程数为 0 ，无法结束任务” | 不进入下一步 |

**交车前校验**

| 校验类型    | 校验条件                  | 失败提示信息               | 操作     |
| ------- | --------------------- | -------------------- | ------ |
| 未完成任务校验 | 当前司机 + 当前车辆没有处于进行中的任务 | toast 提示：“当前存在进行中任务” | 不进入下一步 |

### 4.4 车辆状态定义

| 车辆状态 | 定义           | 备注  |
| ---- | ------------ | --- |
| 在线   | 车辆网联装置在线     |     |
| 作业中  | 车辆在线 + 任务进行中 |     |

## 6 地图 tab 页功能设计

地图 tab 页是司机执行日常任务的主要工作页面，能够实现路线导航、任务接收与执行、水电油上报、故障报修等功能。

### 6.1 页面布局
- 顶部胶囊信息栏显示：固定显示
- 轻提醒 banner：接收到新任务时显示，默认停留 1min
- 地图
- 任务卡片
- 今日任务清单：默认收起，支持拉起

### 6.2 已绑定车辆

以下情形针对驾驶员已绑定车辆的情形

#### 6.2.1 当日有待办任务

1. 初次进入今日用车模块后，此时还没有开始的任务
	- 顶部胶囊信息栏显示：绑定车辆车牌信息、车辆类型、任务情况、车辆状态（见 4.4 章节）
	- 底部显示任务卡片，默认显示该车辆 + 该司机时间排序最早的任务
	- 地图中默认显示当前车辆位置 + 任务卡片中的任务计划路线（如果无计划路线，可忽略）
2. 任务卡片中显示选中的任务的主要信息，包括路线、计划时间、类型、要求等。
	- 常态任务/临时任务
		- 路线名称
		- 任务车牌号 - 任务状态
		- 任务类型 - 作业类型 - 计划时间段
		- 开始任务时间：HH:MM
		- 作业里程：单位 km，保留 2 为小数，计算开始任务时间到当前时间的轨迹长度
		- 作业时长：单位为分钟，保留整数，当前时间 - 开始任务时间
	- 动态任务
		- 问题地点
		- 任务车牌号 - 任务状态
		- 问题类型 - 问题重要程度 - 任务派发时间
		- 开始任务时间：HH:MM
		- 作业里程：单位 km，保留 2 为小数，计算开始任务时间到当前时间的轨迹长度
		- 作业时长：单位为分钟，保留整数，当前时间 - 开始任务时间
3. 任务卡片中有以下按钮：
	- 导航按钮：以小图标按钮呈现，点击后调用**高德地图**进行导航；
	- 开始任务：点击后进入需要校验是否满足开始任务条件。满足以下校验条件后，toast 提示：任务已开始。进入任务执行
		- 校验当前时间是否在允许开始时间范围内：阻断项
		- 校验司机是否已绑定车辆：若校验失败，toast 提示失败原因，并打开车辆绑定页面。阻断项
		- 该司机是否有其他正在执行的任务：若校验失败，toast 提示“当前存在进行中任务”，任务卡片跳转为正在进行中的任务。阻断项
		- 校验车辆是否是任务车辆：阻断项。若校验失败，打开弹窗
			- 弹窗提示文字：当前车辆与任务分配车辆不一致，请检查
			- 申请更换本车执行：点击后，将当前任务的实际执行车辆变更为本车，重新校验流程，该变更信息需要在后台记录
			- 关闭：关闭弹窗，不进入下一步
		- 校验车辆是否在线：本校验仅为提醒项，不作为阻断项
		- 校验车辆的位置是否在路段范围：阻断项
	- 任务详情：次按钮，点击后打开对应任务详情页面，查看详细要求
	- ***更多按钮**（不在本期范围内）：点击后显示暂停任务、转派任务、关闭任务按钮*
		- *暂停任务：将当前正在进行中的任务暂停，在此状态下，用户可以开始执行其他任务*
		- *转派任务：点击后将当前任务移交给其他人*
		- *关闭任务：将选中的任务予以关闭*
4. 支持向上拉起打开今日待办任务清单，显示全部该司机的今日待办任务（可覆盖地图，也支持收起），也可以通过点击任务卡片下方“今日任务 X 项”达到相同的效果。
5. 今日待办任务清单顶部按照未完成、进行中、已完成进行分组统计。清单分为**当前车辆任务**和**其他车辆任务**，**当前车辆任务**排序在前。组内清单中进行中任务优先，其次依次展示应急任务、动态任务、常规任务；已完成任务统一移动至组内列表底部。
	- 存在进行中任务 → 默认选中进行中任务。
	- 存在动态任务 → 动态任务优先展示，排在执行者任务后。
	- 仅存在常规任务 → 按计划开始时间排序展示。
	- 无待办任务 → 展示空任务状态和交车引导。
6.  司机选中当前车辆某任务时，地图上显示该任务计划路线信息，任务卡片变为该任务的详细信息
7. 司机点击开始任务按钮，系统校验通过后，任务开始。此时收起今日待办任务清单
8. 任务执行状态下，地图上显示任务的计划路线信息（蓝色虚线）、车辆的实际移动轨迹（红色实线）、车辆位置，图层优先级递增。车辆位置点实时刷新，并在任务卡片中更新作业里程、已作业时长。有以下按钮：
	- 结束任务：主按钮，点击后进行**任务完成情况校验**
		- 校验通过后，结束任务。
			- 若**当前车辆任务**中有待开始的任务，则 toast 提示：已结束当前任务，已自动推送下一条。地图和任务卡片效果等同于选中推送的任务
			- 若**其他车辆任务**中有待开始的任务，则 toast 提示：当前车辆任务已结束，可交车或查看其他车辆任务
			- 若**当前车辆任务**和**其他车辆任务**中均无待开始任务，则 toast 提示：今日任务均已完成，可在归还车辆后交车
		- 校验未通过，无法结束任务，toast 提示原因
9. 司机在地图模块，若收到新派发的任务（常规、应急、动态任务）：
	- 轻提醒 → 地图上方 banner 提示，宽度与顶部车牌信息卡一致，信息靠左排列，内容格式为“任务类型 任务名称 距离 ”，默认显示时间为 1min
	- 语音播报任务信息：收到新的【任务类型】，【任务标题】
	- 右侧固定“查看”按钮，点击后，展开今日待办任务清单，并选中该任务
10. 司机点击辅助按钮：
	- 复位：点击后地图焦点回到当前车辆位置
	- 图层：
		- 点击后打开底部弹窗，默认图层均关闭，支持图层全选和用户自定义勾选，按用户记录上一次图层打开情况
		- 支持控制站点类型，默认显示全部站点，支持切换为自营站点、协议站点、其他站点（按照站点类型字段予以区分）
		- 包含清洗点、充电点、停车点、中转站、清水补给点、维修点、加油站、其他设施 8 种点位类型
			- 充电点：名称、位置、快充桩数目、慢充桩数目、接入总功率、浩克停车位、麒麟停车位、独角兽停车位、适配车型、现场图片
			- 停车点：名称、位置、类型（停车场、独角兽之家、停车点）、浩克停车位、麒麟停车位、独角兽停车位、适配车型、现场图片
			- 中转站：名称、位置、类型（地埋式中转站、移动式中转站、垃圾池中转站、压缩式中转站）、适配车型、现场图片
			- 补水点：名称、位置、类型、是否商业计费、水压、接口尺寸、适配车型、现场图片
			- 维修点：名称、位置、适配车型、现场图片
			- 清洗点：名称、位置、运维负责人、电气接口、排水条件、适配车型、现场图片
			- 加油站：名称、位置、适配车型、现场图片
			- 其他设施：名称、位置、类型、适配车型、现场图片
		- 点位图标参照环卫云现有图标，其中自营站点在图标上予以区分，右上角增加“自”角标；协议站点在图标上予以区分，右上角增加“协”角标
		- 点击点位图标，地图放大聚焦并居中，底部弹窗展示相应的信息；站点类型在站点名称后的标签中展示；支持显示距离当前位置的距离并导航至相应位置，其中对于加油站、充电点、清水补给点、维修点，分别支持加油上报、充电上报、加水上报和故障报修的快捷入口
	- 水电油上报按钮：点击后打开底部弹窗，支持选择加油上报、加水上报、充电上报类型，点击后打开相应的上报页面。如绑定车辆，则自动带入当前绑定的车牌号，不支持修改
	- *故障报修按钮：点击后打开故障报修页面（不在本次开发范围）*

### 6.5 今日回顾页面

触发条件：司机交车成功

本页面主要是对司机今日的任务完成情况进行回顾，并列出明日待办任务，便于司机更好的安排工作。

#### 6.5.1 今日回顾卡片

展示任务完成数、轨迹里程、出车时长、水电油上报数、报修数。时间范围均限制在当日

- 任务完成数：指当前车辆任务完成数，不包含其他车辆
- 轨迹里程：指当前车辆从绑车 - 交车的轨迹里程数
- 出车时长：指当前车辆从绑车 - 交车的时长
- 水电油上报数：指当前车辆从绑车 - 交车的水电油上报单数

3. 任务卡片分为两组
	- 当前车辆组：交车时**当前车辆任务**+ 任务状态为待开始、进行中
	- 其他车辆组：交车时**其他车辆任务**+ 任务状态为待开始、进行中

### 6.6 绑车/交车页面

司机在绑定车辆和交车时，均需要使用到二维码来绑定/接触人与车的使用关系，考虑到酷哇 APP 中已有“我的二维码“功能，因此该二维码页面可以进行复用。

具体应用在以下场景：

1. 车辆绑定页：用户点击今日用车时，检测到未绑定车辆，在未绑定引导弹窗进行调用，用来建立用户与车辆的绑定关系
2. 交车：用户点击交车按钮后，若满足交车条件，进行调用，用来解除用户与车辆的绑定关系

#### 6.6.1 车辆绑定页
1. 在未绑定车辆下，打开二维码页面，二维码顶部为绑车说明
2. 扫码成功后，进行**人车关系校验**
	- 校验通过，完成司机与车辆的使用关系绑定
	- 校验不通过，toast 提示失败原因
3. 扫码完成后系统记录人员 + 时间 + 车辆 + 位置信息

#### 6.6.2 交车页
1. 已绑定车辆下，司机点击交车按钮，进行**未完成任务校验**，
	- 校验通过，打开二维码页面，二维码顶部为交车说明
	- 校验不通过，toast 提示：存在进行中任务，无法交车
2. 扫码完成后系统记录人员 + 时间 + 车辆 + 位置信息，并解除人与车使用关系的绑定
3. 打开今日回顾页面
