# 车机端 APP UI Design 通用规范（16:9）

## 0. 规范定位

本规范用于 16:9 车机屏幕或车内固定安装横屏设备的 APP 高保真 HTML 原型与前端实现，不限定具体业务类型。

适用范围：

- 车机工作台、地图、列表详情、状态监测、表单和设置类 APP。
- 触控屏、旋钮、D-pad、键盘和语音等输入方式。
- 默认使用白天浅色主题；夜间主题需建立独立设计令牌，不通过简单反色生成。

规范继承关系：

1. 车机 APP 优先遵循本文档。
2. 本文档未定义的颜色、字体和状态反馈继承 `UI_design_APP.md`。
3. 横屏信息组织可参考 `UI_design_WEB.md`，但不复用 WEB 端的小尺寸控件、密集导航和依赖 hover 的交互。
4. 业务流程、状态、权限和驾驶限制以对应需求文档为准。

## 1. 核心设计原则

### 1.1 低分心

- 首屏仅展示当前场景必需信息，非当前内容使用次级视图或收纳面板。
- 一个视图只保留一个主操作，危险操作与高频操作不得相邻。
- 行驶中的信息以“短标题 + 关键数值 + 明确结果”表达，禁止要求用户持续阅读长文字。

### 1.2 快速扫读

- 通过字号、字重、图标、状态色和稳定位置建立层级。
- 关键内容在不滚动时可见，不将主状态、主按钮或风险信息放在滚动容器底部。
- 不仅使用颜色表达状态，同时使用文字、图标或形状。
- 所有文字字符间距为 `0`，关键标题最多两行，超出后省略。

### 1.3 稳定布局

- 加载、状态变化、数值长度和图片异常不得改变主布局尺寸。
- 固定工具栏、标题区、操作区和核心内容区的边界，内容替换仅发生在对应容器内。
- 禁止卡片嵌套卡片；卡片仅用于重复数据项、可点摘要或需要独立语义的小型模块。

### 1.4 一致与可预期

- 相同功能在不同页面使用相同图标、名称、位置和反馈。
- 返回操作回到上一层业务视图，不意外退出登录、连接或会话。
- 权限不足或前置条件未满足时，优先保留禁用操作并说明原因。

## 2. 驾驶环境与安全

### 2.1 使用状态

| 状态 | 界面策略 |
|:---|:---|
| 停车可操作 | 开放完整浏览、筛选、输入、设置和确认操作 |
| 行驶受限 | 仅保留高优先级信息、语音反馈和少量大尺寸操作 |
| 系统阻断 | 安全告警或系统级界面优先于 APP，APP 不得遮挡关键系统信息 |

驾驶状态的判定条件由宿主系统或项目需求确定，本规范不固定车速阈值。

### 2.2 行驶受限规则

| 能力 | 停车可操作 | 行驶受限 |
|:---|:---|:---|
| 查看核心状态与摘要 | 可用 | 可用 |
| 单步、高频、低风险操作 | 可用 | 按业务允许，必须使用大尺寸控件 |
| 切换主视图 | 可用 | 仅允许在少量固定视图间切换 |
| 长列表滚动与翻页 | 可用 | 不可用 |
| 文字输入、复杂筛选和设置 | 可用 | 不可用 |
| 查看大图、长文字和长日志 | 可用 | 不可用 |
| 删除、退出、解绑等高风险操作 | 符合业务校验时可用 | 不可用 |

- 行驶受限时不使用全屏蒙层遮挡核心信息，只对不可用操作就地禁用。
- 行驶中不弹出需要阅读长文字或多步确认的模态窗口。
- 高优先级状态优先使用语音与视觉摘要同步反馈。

## 3. 尺寸与适配

### 3.1 基准画布

| 类型 | 分辨率 | 用途 |
|:---|:---|:---|
| 主设计稿 | `1280 × 720` | 高保真原型与主要验收视口 |
| 小屏车机 | `1024 × 576` | 最小支持视口 |
| 常见横屏 | `1366 × 768` | 兼容近似 16:9 设备 |
| 大屏车机 | `1920 × 1080` | 高分辨率验收视口 |

- 低于 `1024 × 576` 的设备不在默认支持范围内。
- 布局始终保持横屏，禁止折叠为手机单列布局。
- 字号不随视口宽度线性缩放，使用固定字号和离散断点。

### 3.2 安全区与间距

| 项目 | 1280 基准值 | 1024 小屏值 | 说明 |
|:---|:---|:---|:---|
| 外围安全区 | `24px` | `16px` | 兼容圆角屏、物理遮挡和安装偏差 |
| 全局顶栏 | `56px` | `52px` | 导航、身份、连接状态和时间 |
| 主区域间距 | `16px` | `12px` | 并列内容区的间距 |
| 内容区内边距 | `20px` | `16px` | 列表、详情和表单容器 |
| 组件间距 | `8 / 12 / 16 / 24px` | `8 / 12 / 16px` | 以 `4px` 为基础单位 |

### 3.3 响应式策略

| 宽度范围 | 适配方式 |
|:---|:---|
| `1024–1279px` | 使用紧凑间距，次要文字省略，主操作尺寸不缩小 |
| `1280–1599px` | 使用标准间距和标准组件尺寸 |
| `1600–1920px` | 增加主内容面积和列表可见数量，不等比放大字体与按钮 |

## 4. 通用布局模式

### 4.1 主次分屏

- 适用于地图 + 信息、主画面 + 控制、监测 + 列表等场景。
- 左侧主区域与右侧工作区按约 `64:36` 分配。
- 右侧工作区最小 `360px`，`1280px` 视口建议 `420–460px`，大屏最大 `560px`。
- 左右尺寸不随内容变化，局部内容在自身容器内滚动。

### 4.2 等宽双栏

- 适用于两组同等重要性的数据、记录或设置项。
- 两栏使用 `1fr 1fr`，栏间距 `16px`，各自独立滚动。
- 小屏不堆叠为上下布局，应减少字段数量或切换为列表详情模式。

### 4.3 列表详情

- 左侧为稳定宽度的列表或导航，右侧为弹性详情区。
- 左侧列表建议占 `32–38%`，最小 `320px`，详情区占其余宽度。
- 选中项变化时只替换详情区，不整页跳转；返回后保留列表滚动位置。

### 4.4 全屏主内容

- 适用于地图、媒体、导航、实时可视化等需要最大画布的场景。
- 主内容全幅铺开，工具以边缘工具栏或简洁浮层呈现，不放入装饰性预览卡片。
- 全屏状态必须保留退出入口、核心状态和高优先级告警。

### 4.5 单页内容

- 适用于结果页、设置页、说明页和需要聚焦的单流程页。
- 内容最大宽度 `960px`，水平居中；不使用左右两张大卡片拼接页面。
- 简短结果页将状态、核心结果和主操作置于首屏视觉中心。

### 4.6 推荐网格

```css
.car-main-split {
  display: grid;
  grid-template-columns: minmax(0, 1fr) minmax(360px, 36%);
  gap: var(--car-gap);
  min-width: 0;
  min-height: 0;
}

.car-list-detail {
  display: grid;
  grid-template-columns: minmax(320px, 36%) minmax(0, 1fr);
  gap: var(--car-gap);
  min-width: 0;
  min-height: 0;
}

@media (min-width: 1600px) {
  .car-main-split {
    grid-template-columns: minmax(0, 1fr) minmax(460px, 560px);
  }
}
```

## 5. 颜色与主题

### 5.1 基础色

| 名称 | 色值 | 用途 |
|:---|:---|:---|
| 主色 | `#1677ff` | 主按钮、选中态、链接和关键图标 |
| 按下色 | `#4096ff` | 触控按下反馈 |
| 主色浅底 | `#e6f4ff` | 选中条目、信息标签 |
| 页面背景 | `#f2f5f8` | APP 基底 |
| 主表面 | `#ffffff` | 内容区、弹窗、浮层 |
| 次表面 | `#f7f9fc` | 分组、非交互摘要、禁用区域 |
| 主文字 | `#000000d9` | 标题、正文、关键数值 |
| 次文字 | `#00000073` | 辅助信息、时间、单位 |
| 禁用文字 | `#00000040` | 禁用操作和占位文字 |
| 分割线 | `#dfe5ec` | 容器边界和列表分隔 |

### 5.2 功能色

| 语义 | 主色 | 浅底 | 用途 |
|:---|:---|:---|:---|
| 成功 | `#52c41a` | `#f6ffed` | 成功、正常、已完成 |
| 警告 | `#faad14` | `#fffbe6` | 待处理、非阻断异常、需注意 |
| 错误 | `#ff4d4f` | `#fff2f0` | 失败、阻断、危险 |
| 信息 | `#1677ff` | `#e6f4ff` | 进行中、新信息、一般提示 |
| 中性 | `#86909c` | `#f2f3f5` | 已结束、不可用、历史状态 |

- 主界面不使用大面积渐变、高饱和多色背景或装饰性发光元素。
- 高优先级告警可使用错误色，但不使用持续闪烁。
- 业务自定义颜色必须经过对比度校验，不得破坏通用状态色语义。

## 6. 字体与排版

### 6.1 字体

- 中文：`PingFang SC`、`Microsoft YaHei`。
- 英文：`SF UI Text`、`Arial`。
- 数字：`DIN`，无 DIN 时回退到 `Arial`。
- 不引入与现有 APP 不一致的装饰性字体。

### 6.2 字号层级

| 层级 | 字号 | 字重 | 行高 | 适用场景 |
|:---|:---|:---|:---|:---|
| 关键数值 | `28px` | `600` | `36px` | 核心指标、计数器、重要数值 |
| 页面标题 | `24px` | `600` | `32px` | 一级页面和单页结果标题 |
| 工作区标题 | `20px` | `600` | `28px` | 面板标题和详情标题 |
| 列表标题 | `18px` | `500` | `26px` | 列表主信息和卡片标题 |
| 正文 | `16px` | `400` | `24px` | 字段内容、按钮和常规文本 |
| 辅助文字 | `14px` | `400` | `20px` | 时间、单位和辅助说明 |

- 主操作区不使用小于 `14px` 的文字。
- 主按钮使用 `18px / 500`，其他按钮使用 `16px / 500`。
- 数值和单位分层展示，单位使用辅助文字层级。

## 7. 导航与页面框架

### 7.1 全局顶栏

- 在安全区内展示 APP 标识、页面名称、必要身份信息、系统状态和时间。
- 左侧使用返回、关闭或首页图标，中部显示当前页面，右侧放置全局状态和不超过两个全局操作。
- 顶栏不放置长搜索框、多层菜单或需要持续注视的控件。

### 7.2 主导航

- 功能较少时，优先使用顶栏入口或工作台内的分段控件。
- 功能较多时，可使用左侧窄导航栏，建议宽度 `72px`，使用图标 + 短文字，顶级入口不超过 5 个。
- 默认不使用手机底部 Tab；若宿主系统要求底部导航，必须保证不与 APP 固定操作区重叠。
- 同级内容切换使用分段控件或页签。

### 7.3 内容区

- 内容区使用稳定的标题区、滚动内容区和固定操作区。
- 滚动内容不得将固定操作挤出视口，操作区高度不随文案长度变化。
- 长文本、图片组和详细日志仅在停车可操作状态开放完整浏览。

## 8. 触控与通用组件

### 8.1 可点区域

- 停车可操作状态的最小可点区域为 `56 × 56px`。
- 行驶受限状态保留的可用操作，最小可点区域为 `64 × 64px`。
- 相邻操作间距不小于 `12px`，不依赖 hover 发现或说明操作。
- 图标按钮优先使用 Lucide 图标，陌生图标必须带可见文字或在停车态提供明确提示。

### 8.2 按钮

| 类型 | 尺寸 | 圆角 | 用途 |
|:---|:---|:---|:---|
| 主按钮 | 高 `56px` | `8px` | 当前页面唯一主操作 |
| 次按钮 | 高 `56px` | `8px` | 返回、取消、次要命令 |
| 图标按钮 | `56 × 56px` | `8px` | 复位、关闭、缩放、全屏等工具 |
| 危险按钮 | 高 `56px` | `8px` | 不可逆或高风险操作 |

- 禁用按钮保留文字，并通过页内说明或点击反馈告知原因。
- 按下反馈使用背景色变化和短暂 `0.98` 缩放，不使用弹跳动画。

### 8.3 卡片与列表项

- 卡片圆角 `8px`，内边距 `16px`，仅对重复条目使用。
- 普通列表项最小高度 `72px`，带两行信息的摘要项最小高度 `96px`。
- 首行展示标题和状态，次行展示时间、类型或关键属性，非关键字段进入详情。
- 选中项使用主色浅底和左侧 `4px` 主色指示条，不改变列表项尺寸。

### 8.4 状态标签

- 高度 `28px`，水平内边距 `10px`，圆角 `4px`，字号 `14px`。
- 标签文字不换行，最宽 `112px`，长状态名使用经业务确认的短文案。
- 不同类型的状态分开展示，不在一个标签中合并多种含义。

### 8.5 分段控件、选项卡与切换

- 分段控件高度 `44px`，单项最小宽度 `96px`，最多 4 项。
- 两个互斥模式使用分段控件，二值设置使用开关，颜色选择使用色块，数值使用滑块、步进器或输入框。
- 超过 4 个选项时使用停车态的独立选择面板，不在行驶中展开复杂菜单。

### 8.6 表单与输入

- 表单默认仅在停车可操作状态开放。
- 使用左侧外置标签 + 右侧控件的横向表单，标签宽度 `120–160px`，控件高度 `52px`。
- 整页表单最多两列，强关联字段保持同列，不使用过度密集的多栏栅格。
- 必填、错误和辅助说明位于对应控件附近，提交后自动定位到第一个错误字段。
- 已输入表单返回时提示保存或放弃，失败后保留当前输入。

### 8.7 图片与媒体

- 缩略图必须设定稳定尺寸和宽高比，加载失败使用占位符，不改变周边布局。
- 用户需要检查的图片必须清晰展示主体，不使用模糊、过度裁剪或纯氛围图替代业务内容。
- 图片大图、视频选集和复杂媒体操作仅在停车可操作状态开放。

## 9. 弹层与反馈

### 9.1 横幅与页内告警

- 安全告警、连接异常和高优先级新信息使用页内横幅，建议高度 `64px`。
- 同一时间只显示一条主横幅，优先级为安全告警 > 系统异常 > 业务异常 > 一般信息。
- 未解除的阻断与高风险信息持续可见，不仅依赖自动消失。

### 9.2 Toast

- Toast 位于顶栏下方、屏幕水平居中，不覆盖固定主操作。
- 字号 `16px`，最小高度 `48px`，单行优先，最多两行。
- 一般反馈 `2–3s` 自动消失；阻断原因使用弹窗或页内告警。

### 9.3 确认弹窗

- 基准宽度 `440px`，最大不超过屏幕宽度的 `60%`，圆角 `8px`。
- 标题 `20px / 600`，正文 `16px / 24px`，按钮高度 `52px`。
- 按钮排列为左侧取消、右侧确认；危险操作使用错误色确认按钮。
- 禁止弹窗再打开第二层弹窗或在弹窗内嵌套卡片。

### 9.4 Loading、空状态和错误状态

- 首次加载使用保留主布局的骨架屏，不显示空白全屏。
- 局部加载只替换对应区域，不阻断其他无关内容。
- 空状态展示清晰原因和必要的单一后续操作，不使用装饰性大插画挤压信息。
- 网络、定位或外部连接异常时，保留最后一次有效数据并标注更新时间。
- 操作失败后保留当前输入、选择和滚动位置，禁止无理由跳回首页。

## 10. 地图与实时可视化

本章仅在 APP 包含地图或实时可视化时适用。

- 地图或主可视化区在对应容器内全幅铺开，不使用外层装饰卡片。
- 复位、缩放、图层和全屏等工具使用图标按钮，沿区域边缘单列或单行排列。
- 浮层最多展示标题、距离、状态和一个操作，详细内容在独立工作区或详情区展示。
- 图层使用颜色、线型、图标和透明度组合区分，不只使用两种接近颜色。
- 高优先级告警、导航和新信息使用顶部横幅，不遮挡主体、当前位置或下一步信息。
- 实时点位和路径更新使用平滑过渡，异常大距离跨越时不播放跨屏移动动画。

## 11. 动效与性能

- 按钮、标签和面板切换时长为 `120–200ms`，使用 ease-out，不使用弹簧、视差和大幅缩放。
- 禁止背景模糊、大面积渐变、装饰粒子、闪烁和循环装饰动画。
- 动态内容更新只改变内容，不改变容器尺寸，不触发页面抖动。
- 尊重 `prefers-reduced-motion`，减少动效时仍保留文字、颜色和图标状态反馈。
- 滚动、触摸跟手、地图拖动和实时内容更新优先保持流畅，低性能设备上减少阴影和同时动画数量。

---

## 12. 可访问性

- 正文与背景对比度不低于 `4.5:1`，大文字和关键图形不低于 `3:1`。
- 所有图标按钮提供可读名称，图片提供与内容相关的替代文本。
- 兼容触控、旋钮、D-pad 和键盘焦点，焦点态使用 `2px` 主色外轮廓。
- 焦点顺序按顶栏、主导航、主内容、辅助内容、固定操作排列，不进入纯展示元素。
- 语音不得是获取关键信息的唯一方式，屏幕上必须保留对应摘要。
- 状态使用颜色、文字和图标的组合表达，适配色觉缺陷。

## 13. HTML 原型实现规范

### 13.1 技术栈

- 使用 `HTML5 + CSS + 原生 JavaScript`，不引入外部 CDN 依赖。
- 颜色、尺寸、字号和层级定义为 CSS 变量，同一 APP 的所有页面复用同一公共样式文件。
- 主布局使用 CSS Grid，局部组件使用 Flex，禁止用绝对定位组装主布局。
- 字号不使用 `vw`，文字不使用负字间距，不使用 `transform: scale()` 缩放整页。
- 图标优先使用项目已启用的图标库或 Lucide，不重复手绘常见功能 SVG。

### 13.3 原型状态

每个高保真页面必须按适用范围实现：

- 默认、选中、按下、禁用和焦点状态。
- 加载、空数据、成功、一般失败和阻断失败状态。
- 网络异常、定位异常、外部连接异常和数据过期状态。
- 停车可操作与行驶受限状态，以及受限操作的禁用反馈。
- 导航、弹窗、Toast、横幅和语音替代信息的不重叠展示。

## 14. 验收清单

### 14.1 视口与布局

- [ ] `1024 × 576`、`1280 × 720`、`1366 × 768`、`1920 × 1080` 视口均无非预期横向滚动。
- [ ] 顶栏、导航、主内容、辅助内容和固定操作区在状态切换时不跳动。
- [ ] 最长标题、四位数计数、网络错误和加载文案不造成溢出或遮挡。
- [ ] 弹窗、Toast、横幅、工具栏和主操作不互相覆盖。
- [ ] 滚动内容不将标题区和固定操作区挤出视口。

### 14.2 组件与状态

- [ ] 所有交互组件具备默认、按下、禁用和焦点状态。
- [ ] 加载、空数据、错误、断网和外部连接异常不显示空白页面。
- [ ] 图片、视频和实时内容的加载与失败状态不改变组件尺寸。
- [ ] 弹窗不嵌套弹窗，卡片不嵌套卡片，页面分区不伪装成浮动卡片。

### 14.3 驾驶安全与可用性

- [ ] 行驶受限状态下的不可用操作无法执行，且用户能够知道原因。
- [ ] 所有主要可点元素满足触控尺寸和间距要求。
- [ ] 核心状态和高优先级告警无需滚动即可看到。
- [ ] 状态不仅依赖颜色，图标名称、焦点顺序、语音替代和图片替代文本完整。
- [ ] 断网、数据过期和 APP 重启后界面不进入空白或不可恢复状态。
